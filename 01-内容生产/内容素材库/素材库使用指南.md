# 素材库使用指南

> [!important] 核心原则
> **AI 写文稿前，先检索素材库。找到相关内容后，建议复用。每次创作都在给素材库添砖加瓦。**

## 素材库结构

```
内容素材库/
├── 核心概念库/    # 可复用的理论框架
├── 金句库/        # 高质量表达
├── 爆款文稿库/    # 已验证的内容结构
└── 推文库/        # 社交媒体内容存档
```

## 检索流程

写新文稿时，AI 按以下顺序检索：

1. **核心概念库** → 有没有相关理论框架可以引用？
2. **金句库** → 有没有高质量表达可以复用？
3. **爆款文稿库** → 有没有已验证的内容结构可以参考？
4. **已发布选题** → 有没有写过类似内容？

## 入库标准

### 核心概念库
- 自己原创或深度消化的理论框架
- 被反复使用超过 2 次的概念
- 能独立成文的核心观点

### 金句库
- 自己原创的好句子
- 引用他人的经典表达（注明出处）
- 数据验证过的高传播句子

### 爆款文稿库
- 数据表现 Top 10% 的内容
- 内容结构有复用价值的文稿
- 读者反馈特别好的内容

## 维护频率

- **每次创作后**：检查是否有新素材值得入库
- **每周**：整理和归类新增素材
- **每月**：复盘素材使用情况，淘汰低价值素材
