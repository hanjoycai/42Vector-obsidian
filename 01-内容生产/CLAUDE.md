# 内容生产系统 - AI 工作流指南

> 本文件定义了 AI 助手在内容生产流程中的行为规范和自动化能力。
> 核心理念：**系统化创作 > 碎片化创作。每次创作都在给系统添砖加瓦。**

## 项目结构

```
01-内容生产/
├── CLAUDE.md                    ← 你正在阅读的文件
├── 选题管理/
│   ├── 00-选题记录.md            # 碎片想法收集箱
│   ├── 01-待深化的选题/          # 待深入开发的选题
│   ├── 02-制作中的选题/          # 正在制作的内容
│   └── 03-已发布的选题/          # 已发布的内容归档
├── 内容素材库/
│   ├── 素材库使用指南.md         # 素材库的使用规范
│   ├── 核心概念库/              # 可复用的理论框架
│   ├── 金句库/                  # 高质量表达
│   ├── 爆款文稿库/              # 已验证的内容结构
│   └── 推文库/                  # 社交媒体内容存档
├── 内容数据统计/
│   ├── 内容数据统计表.md         # 所有内容的数据表现
│   └── 短视频开头数据.md         # 短视频开头的完播率数据
├── 方法论沉淀/
│   ├── 标题方法论.md             # 基于数据的标题规律
│   └── 选题-标题-开头的关系详解.md
└── 选题研究/
    ├── 对标账号选题/             # 对标账号的选题分析
    └── 选题对比分析.md           # 流量好 vs 差的选题对比
```

## AI 自动化能力

### 1. 记录选题

**触发词**：「记录选题」「我有个想法」「选题想法」

**执行流程**：
1. 将用户的想法追加到 `选题管理/00-选题记录.md`
2. 格式：`- [ ] \`{日期}\` | {想法内容}`
3. 如果用户提到了平台，标注平台
4. 确认记录完成

### 2. 深化选题

**触发词**：「深化选题」「展开这个选题」「写一下这个」

**执行流程**：
1. **检索素材库**（这是关键！）
   - 先查 `内容素材库/核心概念库/`：有没有相关理论框架？
   - 再查 `内容素材库/金句库/`：有没有高质量表达？
   - 然后查 `选题管理/03-已发布的选题/`：有没有写过类似内容？
   - 再查 `内容素材库/爆款文稿库/`：有没有可参考的结构？
2. **报告检索结果**
   - 告诉用户找到了哪些相关素材
   - 建议哪些可以复用
3. **生成文稿**
   - 基于用户风格和素材库生成文稿
   - 保存到 `选题管理/01-待深化的选题/{选题名}.md`

### 3. 生成标题

**触发词**：「生成标题」「帮我起标题」「小红书标题」

**执行流程**：
1. 读取 `方法论沉淀/标题方法论.md`
2. 根据方法论生成 3-5 个标题选项
3. 标注每个标题使用的公式
4. 说明标题逻辑

### 4. 优化开头

**触发词**：「优化开头」「改进开头」「提高完播率」

**执行流程**：
1. 读取 `内容数据统计/短视频开头数据.md`
2. 分析高完播率开头的共同特征
3. 基于数据规律优化当前开头
4. 提供 2-3 个优化版本

### 5. 检索素材

**触发词**：「找素材」「有没有相关的」「之前写过吗」

**执行流程**：
1. 在 `内容素材库/` 全目录中搜索相关内容
2. 在 `选题管理/03-已发布的选题/` 中搜索
3. 返回所有相关素材，按相关度排序
4. 建议复用方式

### 6. 数据复盘

**触发词**：「记录数据」「数据复盘」「更新数据」

**执行流程**：
1. 将数据追加到 `内容数据统计/内容数据统计表.md`
2. 如果是短视频，同时更新 `短视频开头数据.md`
3. 分析数据表现，给出改进建议
4. 检查是否需要更新方法论

### 7. 发布归档

**触发词**：「已发布」「归档」「发布完成」

**执行流程**：
1. 将文稿从 `02-制作中的选题/` 移动到 `03-已发布的选题/`
2. 更新文稿的 frontmatter（添加发布日期、平台等）
3. 提醒用户记录数据
4. 检查是否有素材值得入库

## 创作原则

1. **先检索再创作**：每次写新内容前，必须先检索素材库
2. **复用优于重造**：能复用的框架、表达、案例，优先复用
3. **数据驱动**：所有方法论必须有数据支撑
4. **持续沉淀**：每次创作后检查是否有新素材值得入库
5. **保持一致**：复用已验证的框架保持内容风格一致

## 注意事项

- 文件使用中文命名，方便检索
- 使用 Obsidian 双链 `[[]]` 关联相关文件
- frontmatter 中的字段保持一致性
- 定期清理和整理素材库
