# 选题、标题、开头的关系详解

## 三者关系模型

```
选题（WHAT）→ 标题（WHY CLICK）→ 开头（WHY STAY）
   ↓                ↓                  ↓
 决定天花板        决定点击率          决定完播率
```

## 选题：决定天花板

- **好选题**：受众广、痛点强、有差异化
- **差选题**：受众窄、无痛点、同质化严重

> 选题决定了内容的流量上限。标题和开头再好，选题不行也白搭。

### 选题筛选标准

| 维度 | 高潜力 | 低潜力 |
|------|--------|--------|
| 受众 | 广泛，能引发共鸣 | 小众，只有少数人关心 |
| 痛点 | 强烈，读者急需解决 | 弱，可看可不看 |
| 差异 | 有独特角度或信息 | 已被说烂 |
| 时效 | 蹭到热点或常青话题 | 过时话题 |

## 标题：决定点击率

标题的唯一使命：**让用户停下来，点进去**。

### 标题与选题的关系
- 标题是选题的「销售话术」
- 同一个选题，不同标题，点击率可以相差 5-10 倍
- 标题要突出选题中最有吸引力的部分

## 开头：决定完播率

开头的使命：**在 3-5 秒内说服用户继续看下去**。

### 开头公式

1. **痛点开头**：「你是不是也遇到过 [痛点]？」
2. **结果开头**：「我用这个方法，实现了 [结果]」
3. **反差开头**：「大多数人以为 [A]，但其实 [B]」
4. **故事开头**：「上个月，我遇到了一个问题...」

### 短视频开头优化要点

- 前 3 秒必须抓住注意力
- 不要放废话（「大家好我是 xxx」）
- 直接切入核心冲突或结果
- 用画面/文字辅助强化

## 协同优化策略

```
1. 先确定选题 → 找到最有吸引力的角度
2. 再写标题   → 用最少的字传达最大的好奇心
3. 最后优化开头 → 用最短的时间 hook 住观众
4. 数据验证   → 根据点击率和完播率反向优化
```
