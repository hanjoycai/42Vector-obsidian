### 搭建舞台

### 1: 挑战

- 关注最大的问题
- 生成大量解决方案。确定测试的优先顺序，可以测试多个项目，但需要在一天内全部完成
- 挑战越大，冲刺越好。要有高风险。没有足够的时间，就没有创造力。
- 解决最重要的问题
- 对于斯普林特来说，没有什么问题是解决不了的。
- 先解决表面问题。关注产品的客户交互部分。先做好人与人之间的互动，然后再解决后台系统和流程的问题。

### 2: 团队

- 完成冲刺需要合适的团队
- 人数限制在 7 人以内，否则速度会减慢
    - 您需要一些建设者（项目管理人员、设计师、工程师）
    - 汇集具有不同专长的人员
    - 一些具有专业知识的专家也可以提供帮助（财务、销售、运营、支持）。

| 团队角色 |   |
| --- | --- |
| 决定 | 对问题有深刻理解的官方决策者。<br>你需要一个决定者，让他们进来。<br>如果你不能在必要时下放决策权。<br>如果只是部分，则需要在周一、周三下午和周五下午提供。 |
| 金融专家 | 谁能解释钱的来源和去向？ |
| 营销专家 | 谁能为客户精心设计信息 |
| 客户专家 | 谁经常与您的客户交谈？ |
| 技术/物流专家 | 谁最了解您能建造和交付什么 |
| 设计专家 | 贵公司生产的产品由谁设计 |

- 带上麻烦制造者。最好让他们感觉到对项目的投入
- 安排专家周一前来分享他们的观点
- 挑选一名协调人，以便按计划开展工作并组织大家。
- 不要将决定者和协调者合二为一。因此，外部协调人效果很好。

### 3: 时间与空间

- 整周清空
- 从 10:00 到 17:00，用一个小时吃午饭，上下午各休息一会儿。这样就有 6 个小时。
- 不允许使用设备 → 它们会分散注意力
    - 您可以在休息时间查看。
    - 您可以离开房间检查设备
- 你需要大量的白板空间（至少两块大白板）。如果需要更多空间，请携带带轮子的白板、创意颜料或纸张。
- 呆在同一个房间里。
- 开始前准备好各种用品（便条、记号笔、钢笔、计时器、纸张、健康零食）
- 使用时钟让每个人都向前迈进

### 星期一

### 从终点开始

- 慢下来，分享你所知道的，分清轻重缓急，否则你就会在问题的错误部分上浪费时间和精力。我们需要组织起来，在开始解决问题之前理清我们的优先事项。
- 从终点开始练习
    1. 设定长期目标：我们为什么要做这个项目？我们希望在 6 个月、1 年甚至 5 年后达到什么目标？
    2. 哪些是必须回答的难题？要想取得成功，哪些假设必须成立？我们的项目可能失败的原因是什么？将障碍转换为问题

### 地图

- 用简单的图表表示复杂的内容
- 稍后将利用该地图把广泛的挑战缩小到具体目标上
- 地图可以帮助您了解事物之间的联系，并减轻每个人的记忆力。
- 无论问题多么复杂，都可以用几个词和箭头来描绘
- 你在绘制重要时刻的地图，谁与谁互动做什么？
- 地图以客户为中心。
- 每张地图都有一个故事，有开头、中间和结尾。
- 创建地图的步骤：
    - 列出左边的演员
    - 把结尾写在右边
    - 在中间添加文字和箭头
    - 保持简单
    - 寻求帮助
    - 只需 30-60 分钟

### 专家问答

- 知识分布在整个组织中。没有人无所不知。
- 利用周一下午的大部分时间向专家提问
- 与 Sprint 团队和业务部门的人员进行一次性访谈
    - 找人谈谈战略、客户心声、工作方式和以往的努力
- 形式：介绍冲刺阶段，查看白板，让他们告诉你一切，让大家提问并修复白板
- 让每个人都做笔记（《我们如何做笔记》）。
- 每个便利贴都是一个 "我们该如何做 "的问题
- 访谈结束后，将访谈内容贴在墙上，分成若干组，并标明组别/主题（包括一个混合主题，以归纳离群值）
- 然后对 HMW 纸条进行投票（给每个人几个点）。
- 投票结束后，将获胜的纸条放在您的地图上

### 目标

- 周一的最后一项任务是为冲刺选择一个目标：
    - 谁是最重要的客户？请选择一个。
    - 客户体验的关键时刻是什么？请选择一个。
- 关注最大的风险或最大的机遇
- 对 HMW 注释进行聚类，更容易选择聚焦点
- 请决定者做出决定。让每个人在便利贴上写下自己的投票，并在需要帮助时交给决定者

### 星期二

### 混音和改进

- 从闪电演示开始寻找灵感：
    - 列出具有相关解决方案的启发性产品或服务清单
        - 在公司和行业内外进行思考
        - 每件事情都应该有值得学习的地方
    - 让每个人在 3 分钟或更短的闪电演示中演示自己的最爱
    - 随时捕捉重大创意 → 创建创意白板
    - 将想法与 HMW 或昨天的地图相结合

### 素描

- 周二下午是开始提出解决方案的时间
- 单独工作，慢慢写生
- 从纸上开始（绘画能力并不重要）
- 草图可以帮助你向同事解释你的意思。它是将抽象概念转化为具体解决方案并进行交流的最快、最简单的方法
- 一起单独工作 → 你会产生更多的解决方案，你可以做更多的研究，寻找灵感，思考问题
- 周二创作的草图成为冲刺阶段其余时间的燃料
- 草图应该详细，但不是艺术品
- 从用户需要做的第一个小动作开始，然后依次进行
- 四步素描技法
    1. 以笔记形式收集关键信息{回顾你的灵感}（20 分钟）
    2. 涂鸦粗略解决方案（20 分钟）
    3. 尝试快速变化{使用疯狂的 8 = 将纸折成 8）（8 分钟）
    4. 弄清细节{草绘解决方案}（30 分钟以上）
- 最好的素描是
    - 不言自明
    - 匿名
    - 谨慎选词（文案写作）
    - 有一个朗朗上口的标题
- 每个人都必须制作一份解决方案草图，如果您愿意，也可以制作更多草图
- 在第二天之前，不要对它们做任何事情！

### 星期三

### 决定

- 周三上午决定采用哪种解决方案原型
- 五步流程：
    1. 把草图挂在墙上
    2. 静观解决方案，用点贴标记有趣的部分
    3. 快速讨论每个解决方案的要点（3 分钟），使用便签记录重要观点
    4. 让每个人选择一种解决方案（用贴纸投票）
    5. 决定者做出最终决定（用贴纸投票

### 隆隆声

- 当你有两个很棒的想法时 → 将它们都做成原型，看看哪个测试效果更好
- 周五，两个理念的对决即将拉开帷幕
- 如果可以将两张草图合并成一个产品，那就这样做吧
- 促进简短讨论，以决定是 Rumble 还是创建 All-In-One
- 如果您要创建两个产品，请快速为第二个产品创建第二个测试

### 故事板

- 将获奖草图制作成故事板
- 用大约 10-15 个图板来创作一个连贯的故事
- 使用故事板想象完成后的原型 → 预先找出问题和困惑点
- 绘制你的故事板，加入最佳创意，创作一个人人都能接受的故事
- 将您的想法与竞争对手的想法一起展示（您可以让客户与您的想法一起测试竞争对手的想法）
- 故事板步骤
    1. 绘制网格
    2. 选择开场场景
    3. 填写故事板
        - 利用现有资源
        - 包含足够的细节
        - 让决定者来决定
        - 当有疑问时，要敢于冒险
        - 确保能在 15 分钟或更短时间内完成测试（重点关注最重要的解决方案）

### 星期四

### 伪造

- 周四的主题是幻觉 → 伪造你的解决方案 → 制作一个感觉真实的原型
- 打造门面比你想象的要容易得多→90%的真实度足以检验
- 你已经完成了最困难的部分 → 故事板清楚地说明了要包括哪些内容
    - 您应具备基本要素、文案和细节
- 你可以在原型上花费一天以上的时间，但最好还是尽快从中学到东西。
    - 在某件事情上花费的时间越长，对它的感情就越深
- 原型思维
    - 你可以制作任何原型。
    - 原型是一次性的
    - 建设足够的学习空间，但不要更多
    - 原型必须真实
- 当客户做出自然而诚实的反应时，您的原型就足够真实了
    - 如果展示的东西过于粗糙，客户就会开始提出反馈意见。
    - 反应是金子 → 反馈不是
- 金发姑娘原型的质量......花足够的时间让它足够真实，花太多的时间让你需要打磨它

### 原型

- 帮助您成功制作原型的四个练习
    1. 选择正确的工具：
        - 你的日常工具并不适合原型设计，因为你的原型只需要看起来像真的一样
‣
"我们有 90% 的把握认为您应该使用 Keynote
        - 在屏幕上或纸上使用 Keynote
        - 如果是服务 → 让你的团队充当演员
        - 如果是物理空间 → 修改现有空间
        - 如果是物品 → 使用现有物品、3D 打印或直接制作营销原型
    2. 分而治之
        - 分配不同的角色：
            - 制作者：制作单个组件。
            - 缝合器：收集组件并将其无缝组合
            - 作家：让所有文字都符合现实
            - 资产收集器：抓取图片、图标和示例内容
            - 采访者：撰写采访稿
        - 划分故事板
        - 别忘了开头的场景布置
    3. 缝合
        - 缝制者确保日期、时间和姓名在整个原型中保持一致
    4. 试运行
        - 争取在下午 3 点进行试运行，你会学到一些东西。

### 星期五

### 小数据

- 一个人采访 5 个目标客户。
- 让每个人使用原型完成一项任务 → 同时提问以了解他们的想法
- 其他人都在另一个房间里通过视频观看顾客的反应
- 经过 5 次访谈后，通常会形成一种模式（特别是如果您对目标客户有严格的定义）： 1.
- Neilson Norman 集团：85% 的问题是在 5 人测试后发现的。那么你最好先解决你发现的问题，然后再进行测试......这比让更多人测试以发现更多问题更快
- 通过访谈，您可以在制作实物之前测试产品的外观。
    - 您将获得产品是否有效的信号
    - 您还能了解任何问题背后的 "原因
- 采访很容易：友好、好奇，并愿意让自己的假设被证明是错误的

### 采访

- 五幕访谈
    1. 友好的欢迎
    2. 关于客户的一些一般性开放式背景问题
        - 让客户感觉更舒适，并能发现有用的信息
    3. 介绍原型
        - 有些东西还不能用，如果你遇到了不能用的东西，我会告诉你的
        - 征求坦诚直率的反馈意见（说这不是你设计的，他们不能伤害你的感情）
        - 请他们边走边大声思考，并说如果他们感到困惑
    4. 旨在让客户对原型做出反应的任务
        - 提示：这是什么？你认为这是用来做什么的？你希望它能做什么？
    5. 快速汇报（记录客户的总体想法和印象）
        - 这与你现在的工作相比有何不同？
        - 您会如何向朋友描述该产品？
        - 如果您有 3 个改进产品的愿望，您会怎么做？
        - 如果比较原型......询问哪种最好，优点和缺点，以及如何将它们结合起来。
- AirBnB的早期员工描述说，他们在早期的访谈中发现了很多问题，这让他们既痛苦又深受启发。

### 学习

- 共同观看访谈有助于小组一次性吸收访谈结果，并在事后更容易做出决策
- 在白板上画一个网格。列代表客户，行代表产品或用户体验的各个部分
    - 让每个人将自己在访谈中的引语、观察或解释贴在便签上
- 如果能用颜色标记注释（绿色代表正面，红色代表负面，黑色代表中性）
- 在白板上寻找模式（越多客户以同样的方式做出反应，信号就越强）。将它们列在另一块白板上，并标注为积极、消极或中性。
- 回顾你的长期目标和冲刺问题。你现在能回答它们吗？

> 每一次访谈都会拉近您和您的团队与您希望通过产品或服务帮助的人之间的距离

- 你的每一次冲刺都会拉近与愿景的距离

### 心态：

- 不要急于找到解决方案，先找出问题所在，然后商定目标。
- 独立工作，为可能的解决方案绘制详细草图。
- 使用投票和决定器做出反映团队优先事项的明确决定
- 创建原型，并迅速与客户进行测试，了解他们的真实反应
