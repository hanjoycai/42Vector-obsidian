# 第1章：你可以更快地学习

- 通过实验，我们发现了如何最大化用户研究对早期初创企业的影响——同时让团队更容易尝试、参与并学习如何自己实践的方法。答案是：**Bullseye Customer Sprints（靶心客户冲刺）**。
- Steve Blank（史蒂夫·布兰克）撰写了客户发现领域的经典著作：
- **你的靶心客户** = 目标市场中最有可能率先采用你新产品的特定子集。
- **靶心客户冲刺的步骤**：
    - **靶心客户冲刺的目标**：
        1. 验证并完善关于谁会成为公司靶心客户的假设。
        2. 确定这些客户最看重的功能和独特价值主张。
    - **招募5位靶心客户**：在成功招募5位客户后，你会遇到收益递减的情况——主要收获已经显现。之后，通过改进原型而非仅听取客户反馈，你将获得更多价值。
    - **与他们讨论3个原型（例如：模拟着陆页的优缺点）**：推进3个设计可以避免你因一个设计而过于投入。推进3个设计还会增加你从学习中获得惊喜的几率。客户会讨论每个原型的优缺点（通常会偏向选择其中2个作为最爱）。客户能记住3个示例，但再多就会显得困难。
    - **在一天内完成所有访谈**：将所有访谈安排在一天内，可以通过减少报告和沟通管理的时间，帮助团队更快地就关键发现和下一步计划达成一致。
- **尽早开展靶心客户冲刺**——在团队投入时间、金钱或声誉风险于设计、推出或营销MVP之前。
    - 当构建错误产品的成本很高时，研究的投资回报率（ROI）是最高的。
    - **但**即便可以快速构建MVP，你仍应先测试3个概念，以免陷入对某个概念的“感情陷阱”（沉没成本谬误），而未从中学到任何东西。
    - 在进行其他研究之前，先运行一次靶心客户冲刺，因为这将帮助你提供信息、优化流程并降低后续工作的成本。
- **越早提供洞察越好**——否则你可能会浪费时间、金钱和精力，构建错误的产品并将其营销给错误的人群。
- **将研究分解为小块**，以便更好地接受反馈并进行迭代。
- **不要试图一次性回答所有问题**——专注于最优先的学习目标。
- **定性的一对一访谈具有最佳价值**——你可以从客户故事中获得启发，提出后续问题，深入了解他们答案背后的原因，同时为意外发现留有余地。
- **对比揭示更多信息**——如果让客户比较多个原型，你将获得更丰富的反馈。
- **在客户所在的环境中与他们会面**——他们不会在真空中体验你的产品。
- **为了获得最佳结果，让整个团队参与研究**——亲身参与更具影响力。
- **保持原型的简洁性**——不要过度模拟，仅做必要的设计，并充分利用竞争对手的产品。

# 第2章：就目标和关键问题达成一致

- **优先整理一份关于目标客户和你正在构建的产品的关键问题清单**，明确你想要学习的内容。定义清晰的学习目标可以帮助你更好地规划和执行。
    - **召集团队成员，汇总一份问题清单。这些问题可以提供帮助**：
        - 是什么让你夜不能寐？
        - 你对理想客户及其问题有哪些假设？
        - 你对独特解决方案的假设是什么？
        - 如果你有一个水晶球，你希望从中了解关于理想客户的哪些信息？
        - 团队中有哪些悬而未决的争论？
        - 产品被采用并取得成功的必要条件是什么？
        - 什么能增强你对优先级和产品构建顺序的信心？
        - 如果你已经推出了一款产品，你对令人失望的指标有哪些疑问？
    - **接着优先排序你的问题。这些提示可以帮助你找到关键问题**：
        - 这些问题与你的产品路线图有多相关？
        - 想象一下研究的可能结果。**根据结果你会采取哪些决策或行动？** 如果只是“知道了也无关紧要”，那么它的优先级就很低。
        - 如果现在不回答这个问题会有什么风险？这是单向门，还是可逆的双向门？
        - 一些常见问题可能已经研究过了——通过文献调查来确认。
        - 答案是否已经存在于你的组织中？
        - 研究结果在什么时间点之前仍然有用？
- **保持你的问题清单是最新的**。

# 第3章：定义你的靶心客户

- 从一开始，构建一款适合所有人的新产品是一项困难且罕见的任务。
- 围绕靶心客户进行定义和对齐，可以帮助你优化方法并加速增长。
- 知道谁是你的客户以及谁不是你的客户，有助于你做出艰难的决策。
- 将靶心客户定义为那些最容易赢得的客户，可以让你的营销和销售努力更有效。
- 确保你为冲刺招募的客户符合你的靶心客户标准。
- **定义靶心客户的方法**：采访利益相关者，了解能够识别最有可能采用产品的客户子集的区别特征、行为和过往经历。
    - **触发点**：能够激发人们对产品欲望的近期事件。
        - 例如：结婚是购买人寿保险的一个触发点。
    - **排除标准**：不符合目标客户特征的过往经历或态度，可以帮助你避免浪费时间。
        - 例如：没有手机的人可能会被排除在外（如移动银行应用的发现阶段）。
    - **提示**：在访谈的第一分钟里，你可能会听到哪些内容让你意识到你找错了人？
- **在定义靶心客户时，制定具体、明确、可量化的标准，以便在招募时用于筛选**：
    - 按重要性优先排序标准和客户群体。
    - 如果你已有产品，使用现有的客户数据和分析工具，帮助识别最重要的高价值问题。
    - 如果出现区别明显且同等重要的靶心客户群体，分别记录这些群体，并为每个独立群体单独运行靶心客户冲刺。
    - **以下示例问题可以帮助你更好地聚焦靶心客户**：
        - **基本特征**：哪些关键特征或需求描述了你的靶心客户？
        - **新用户与现有用户**：你的设计对象是已经了解并使用过产品的人，还是对产品完全陌生的人？
        - **B2B：行业或产业**：哪些行业或领域会更容易接受你的产品？哪些行业或业务类型应被排除？
        - **B2B：组织规模**：什么规模的组织最合适？员工数量？客户数量？资金？收入？数据量或数据类型？
        - **使用相关或竞争产品**：参与者必须使用过（或未使用过）哪些相关或竞争产品？他们应该了解哪些相关或竞争产品？
        - **排除的个人经验**：是否有某些相关的个人经历可能让他们成为不太可能的客户？
        - **排除的职业经验**：他们是否有某些公司或行业从未工作过的背景？他们是否曾为地方、州或中央政府工作过？
        - **头衔、角色和职责**：需要哪些类型的职业经验？家庭角色？职位头衔？个人贡献者与经理？职业经验年限？
        - **地域性**：哪些是你最重要的市场？
        - **买家与最终用户**：你是想与买家交谈，还是想与最终用户交谈？
        - **B2B：团队结构和分布**：组织团队是集中式的还是分布式的？你的用户会在办公室、远程还是混合环境中协作？
        - **收入和预算**：目标用户的可支配收入有多少？他们的消费习惯如何？他们对价格敏感吗？
        - **生活和工作环境**：你的产品/服务主要面向城市、乡村还是郊区的人群？公寓还是单户住宅？有孩子、室友还是多代同堂家庭？
        - **触发事件**：哪些近期事件或变化会让潜在客户对你的产品更感兴趣或更不感兴趣？
        - **重要客户**：什么让客户对你的业务更有价值或更无价值？
        - **缺失的客户**：你的目标市场人口特征是什么？
        - **其他排除性问题**：在研究访谈的前几分钟里，你还能想象可能会听到哪些内容会让你说：“哦不！这人不代表我的靶心客户。”

# 第4章：招募五位靶心客户

- 定义靶心客户应该使招募过程更容易。
- 如果你无法为研究招募到五位靶心客户——那你将如何向他们销售产品？
- 使用类似“用户访谈”和“Respondent”之类的服务提供筛选问卷会有所帮助。
- **招募的质量是决定你从靶心客户冲刺中获得洞察的最大因素**——因此，投入精力撰写一份优秀的筛选问卷，并在选择参与者时保持挑剔。
- **五位客户是一个合适的数量，原因如下**：
    - 你可以在一天内完成任务。
    - 数量足够多，能开始听到重复的观点，从而让关键收获变得清晰。
    - 额外的访谈会出现收益递减的情况。
    - 你的团队在完成五次访谈后会想要开始迭代，他们想尽快回到工作中。
- **招募步骤**：
    1. **撰写筛选问卷**：为每一条标准设计一个问题。问题应避免透露正确答案，更多关注过去的行为。目标是设计大约15个问题。
    2. **让人填写问卷**：尽可能让更多人填写问卷（通过用户访谈服务/Respondent平台）。提供足够吸引人的奖励，以确保人们愿意并可靠地参加。
    3. **选择5位客户**：挑选最符合你标准的参与者。保持挑剔，在预定访谈前，快速与他们通电话，验证他们的回答，检查他们是否是良好的沟通者。建立信任并确认他们的时间安排。
    4. **将5次访谈安排在同一天**。
- 如果用户访谈平台或Respondent平台无法满足需求，你需要自己进行招募。利用你的网络、联系潜在参与者寻找更多人，使用LinkedIn，接触职业协会，去他们所在的地方，或雇佣专业招聘人员或专家。
- 通过现有参与者寻找更多潜在客户——询问他们是否知道你可以接触的其他人。
- **为了避免爽约**：
    - 提供有意义的奖励。
    - 不要招募得太早。
    - 提供明确的具体说明（让流程简单易行）。
    - 确保沟通专业。
    - 发送提醒，确保参与者对访谈感到投入和感兴趣。

# 第5章：选择你的价值主张和三个原型

- **展示具体示例可以迫使你明确想要测试的想法**。
- **使用包含产品功能、优势和信息传递的不同组合的三个原型**。
- 模拟精选的首页或应用商店页面——这可以模拟购物体验。
    - 它们看起来应该像实际的网站，或者直接使用真实的网站。
- 这种形式让客户更容易理解并讨论这些选项。
- 在客户访谈中引入三个原型可以促进更丰富的讨论，提供多样性但不会让参与者感到不知所措。
- 使用两个原型时，参与者可能会选择一个最喜欢的，而不进行深入分析；但引入第三个选项可以鼓励他们更批判性地评估具体功能的优缺点。
- **测试什么？**
    - 考虑哪些原型能帮助你从客户那里获得所需的反馈，从而解答你的一些优先问题。
    - 你可以从以下选项中混搭：
        - 使用你已有的内容。
        - 借鉴你的竞争对手。
        - 模拟着陆页。
    - 确保你的原型具有三种不同的价值主张。
        - **例如：墨西哥卷饼案例**
| 功能 | 选项 |
| --- | --- |
| 品牌承诺 | 真实性 |
| 定价模型 | 买6送1 |
| 交付方式 | 自取 |
- **原型设计提示**：
    - **挑战极限**：测试大胆的概念，而不是微小的差异。
    - **使原型在视觉上易于区分**。
    - **直白清晰**：页面应该能够清晰地传递信息。
    - **使用能抓住每个版本核心的标题**。
    - **让它们看起来逼真**。
    - **避免过于复杂的用户界面设计**。
    - **仔细校对**：低质量会削弱原型的可信度。

# 第6章：制定你的访谈指南

- **访谈目标**：
    1. 验证并完善关于谁会成为公司靶心客户的假设。
    2. 确定这些客户最看重的功能和独特价值主张。
- **将访谈分为两部分**：
    1. **探索阶段**：热身和半结构化的开放式访谈
        - 关注客户的过往经历、行为、目标、态度和困难。
        - 半结构化的开放式问题可以帮助我们了解客户的生活，建立同理心，并帮助我们理解他们在第二部分的反应。
        - 引导客户讲述故事和举例，说明他们过去的经历、行为、成功和问题。
        - 提出大量的“谁、什么、哪里、何时、如何以及为什么”的问题，并进行跟进。询问他们描述内容的具体示例。
        - 设计一个访谈框架：从广泛的主题开始，然后逐步聚焦。尽量涵盖团队最紧迫的问题，即使有时会偏离主题。
        - 如果需要促进谈话，可以使用“购物随行”的形式。
        - **B2B示例问题**：
            - **团队和组织契合度**：你的团队如何融入更大的组织中？谁负责制定产品路线图？
            - **购物流程**：
                - 谁决定路线图所需的技术或工具？
                - 你如何识别、评估和选择新技术解决方案？
                - 你使用哪些资源来了解技术趋势？
                - 谁负责评估并说服他人接受候选产品？
                - 在寻找和购买新技术时，你面临哪些挑战？
            - **评估因素**：
                - 在评估新平台时，哪些是关键标准（例如成本、开源性、性能、兼容性、安全性）？
            - **反思**：
                - 在开始这个流程之前，你希望自己知道些什么？
                - 你会给其他升级工具的人提供什么建议？
    2. **比较原型阶段**：依次介绍原型，对比优缺点。
        - 访谈的后半部分用于围绕三个原型进行结构化讨论。
        - **确保客户理解原型**——这不是可用性测试，而是为了获取关于价值主张的反馈。
        - 让客户提供对每个价值主张的反馈，并选择他们最喜欢和最不喜欢的元素。
        - 以每位客户描述他们理想的功能和定位组合结束访谈——引导他们从每个价值主张中取舍并构建自己的方案。
        - **结构化访谈流程**：
            1. 设置原型的背景。
            2. 引导受访者对原型#1进行简要体验。
            3. 获取初步反应、个人喜好和不喜欢的点。
            4. 针对原型#2和#3重复以上步骤（为每位参与者混合介绍原型的顺序）。
            5. 让他们比较所有三个原型的优缺点。
            6. 询问他们如何将三个原型中最喜欢的部分组合成一个理想的方案。
            7. 还有什么遗漏的？他们理想的版本还需要什么？

# 第7章：从每次访谈中学习更多

- 让访谈变得对话式、生动且具有个人化。以优雅的主人身份接待访谈对象，并成为一个好的倾听者。
- **三大关键习惯**：
    1. 微笑并保持眼神交流。
    2. 真正地感到好奇。
    3. 专注于面前的访谈对象，而不是你的笔记。
- 准备好安静倾听——对你的客户感到着迷。
- 不要评判或否定他们的反馈——你的目标是获取尽可能多的信息。
- 提出“谁、什么、何时、何地、为什么以及如何”（5W1H）的开放式问题。
- 提问跟进问题，例如：“这方面有什么例子？”“能多讲一点吗？” 有时，沉默也能引导出更多信息。
- 要求最近的个人示例——让客户提供具体的例子，而不是泛泛的身份描述。
- 注意时间管理。
- 不要推销或解释，而是专注于他们的想法：
    - “你认为这意味着什么？”
    - “你有哪些问题或顾虑？”
    - “你希望这如何运作？”
- 观察面部表情、肢体语言和语气，确保他们的参与感。

# 第8章：计划一个观看派对

- 观看派对可以节省时间、优化沟通并帮助团队对齐和激励。
- 团队更倾向于安排一个专门的整天时间——这样他们可以专注于访谈，而不会被其他事情分心。
- 这让每个人更容易发现模式。
- 你无需花时间进行总结、文档记录或撰写报告。
- 基于观点的优劣建立一致意见。
- 加速团队对客户及其目标的理解和共情。
- **观看派对的格式**：
    - 安排整天时间。
    - 一次观看一个访谈，并在每次后进行简短总结。
        - **访谈总结**：
            - 捕捉访谈中的关键信息和观察。
            - 赞扬访谈者并提供反馈。
            - 由决策者主导讨论——在完全总结每次访谈之前，克制住讨论大结论的冲动。
    - 让每个人都参与记录笔记：
        - 确保每个人知道研究目标、访谈对象、时间安排和各自的角色。
        - 分配不同类型的笔记任务并定期轮换：
            - **主要记录员**：记录详细的笔记和引述。
            - **次要记录员**：补充笔记、突出重要观察、捕捉值得注意的引述，并添加时间戳以便后续查找。
            - **协调员**：负责幕后协调。
            - **总结者（通常是产品经理）**：在每次访谈后主导关键观察的讨论。
    - 让每个人预测他们将从观看派对中学到什么。
    - 在一天结束时，让每个人独立记录主要收获：
        - 姓名。
        - **三大主要收获**。
        - 你将如何改进或调整靶心客户的定义？
        - 如果有的话，哪些开放性问题或顾虑仍然存在？
        - 下一步应该是什么？
- **第二天早晨的最终总结**：
    - 决策者描述他们在每个人的回答中观察到的模式：
        - 你回答了主要问题吗？
        - 是否有任何意外发现？
        - 团队的预测是否成真？
    - **可以帮助的问题**：
        - 你对每个主要收获的信心如何？评为低、中或高。
        - 这些主要收获是否契合并解释了你看到的其他数据和分析？
        - 哪些额外信息或分析可以增强你对主要收获的信心？
        - 你应该如何更新你的靶心客户定义？
        - 哪些主要问题仍未回答？
        - 你对客户或产品还有哪些新问题？
        - 这些访谈激发了哪些新想法？
        - 是否有任何需要立即修复或改进的现有产品或网站问题？
        - 你何时计划安排下一个观看派对和靶心客户冲刺？

# 第9章：常见问题与陷阱

- **为什么不能直接发布产品来学习？**
    - 未经过测试就发布产品是有风险的，可能导致昂贵的错误。通过与靶心客户进行快速研究，可以在正式发布前发现关键问题，从而确保更成功和有信心的产品推出。
- **我们应该什么时候进行研究？**
    - 研究在开发新产品、进入新市场或理解不同客户群时至关重要。对于早期初创企业或扩展至新领域的企业来说尤为重要。研究能帮助你优化理解和策略，确保产品与市场匹配。
- **研究多少才算过量？**
    - 过度研究会削弱其效果，特别是当研究未与高优先级目标对齐时。早期初创企业应专注于有针对性的高影响力研究，而不是持续进行低影响力的研究，这可能会浪费资源并削弱研究洞察的意义。
- **我们能否只用亲友进行测试？**
    - 用亲友测试可以作为练习，但不应依赖于他们的关键反馈。更好的方法是从没有个人偏见的人那里获取意见，以确保更诚实和可操作的洞察。
- **我们是否应该把目标锁定在早期采用者上？**
    - 早期采用者并不总是最佳目标人群，特别是跨类别时。定义与靶心客户一致的具体行为和标准非常重要，从而确保你锁定了正确的受众。
- **什么时候应该使用无人主持的测试工具？**
    - 无人主持的工具非常适合对定义明确的任务进行快速反馈，但在处理更复杂的问题或需要深入洞察时，应辅以深度访谈。
- **什么时候应该使用调查而不是访谈？**
    - 在定性研究已识别关键问题后，调查可能会更有效。早期初创企业应优先考虑一对一访谈，以首先获得深度洞察，然后再用调查验证结果。
- **焦点小组怎么样？它们会更高效吗？**
    - 焦点小组在获取详细的个人洞察方面不如一对一访谈高效。它们可能由于群体动力学和社会影响而导致较不准确的结论。
- **我们可以用客户顾问团代替靶心客户吗？**
    - 客户顾问团可能因对你的产品过于熟悉而导致反馈陈旧。靶心客户能提供更有价值且无偏见的洞察，确保研究相关性。
- **与客户合作作为设计伙伴怎么样？**
    - 虽然设计伙伴关系能提供深度洞察，但可能导致开发出过于迎合单一客户需求的产品，而不适合更广泛的市场。
- **我们是否应该衡量NPS（净推荐值）或满意度？**
    - NPS并不适合用于产品设计反馈，因为它在反映真实的客户情感上有限。推荐直接衡量客户满意度的方法，以获得更可操作的洞察。
- **我们如何从前客户那里获取更多反馈？**
    - 吸引前客户参与富有成效的访谈是具有挑战性的。相反，专注于理解并扩大你最幸福和最活跃的客户群体。
- **我们可以提供小礼品作为激励吗？**
    - 提供适当的激励可以增加参与率并增强研究的参与度。然而，激励的价值和类型需要经过深思熟虑，以确保它对目标受众有吸引力。
