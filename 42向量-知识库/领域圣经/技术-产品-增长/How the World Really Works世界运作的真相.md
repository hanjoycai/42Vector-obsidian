# 引言

- 科学技术的进步推动了过去几百年间人类生活水平的巨大提升。这一切得益于维持文明的复杂机器、设备、程序、协议和干预措施的协同作用。
- 日益复杂的系统让我们更难理解全局图景并做出正确决策。许多人不了解现代社会赖以存在的基本流程和复杂系统。我们的知识是浅显的，我们依赖许多对我们来说是“黑箱”的事物。只有少数人了解我们的食物、能源和技术是如何生产的。
- 我们正面临气候危机，而我们对化石燃料的依赖程度比大多数人想象得要高。**到2050年，我们不可能在不付出难以想象的经济撤退或几近奇迹般的技术进步的情况下实现经济脱碳。**
- 我们的高能耗社会正在逐步增加对化石燃料和电力的依赖。能源脱碳将对我们最基本的粮食生产需求带来挑战。
- 现代文明的四大支柱：**氨、钢、混凝土和塑料**。
- 生存的三大必要条件：**氧气、水和食物**。
- **我们忽视了化石燃料使用的警告，并对其依赖加深到如此程度，以至于我们难以与其割舍。**

# 能源系统的复杂性

- 尽管我们经历了多次向新能源的转换，但现代文明的进步可以主要归因于化石燃料的使用。我们现在拥有前所未有的能源可供支配。
    - **现代人类拥有的有效能源比19世纪多700倍。**
    - **人均每年使用800公斤原油。**
- 我们对化石燃料的依赖程度如此之深，以至于下一次能源转型将比大多数人想象的更耗时。
    - 一种能源替代另一种能源的程度，取决于它们在系统中的部署方式。摆脱对化石燃料的依赖，比从蜡烛转向电灯要困难得多。

## **经济系统本质上是一个提取、处理并将能源转化为产品和服务的系统**

——Robert Ayres

- **能源是唯一真正的全球货币，任何事情都离不开它的转化。**
- 能源是完成工作的能力。能源有多种形式：引力、动能、热能、弹性能、电能、化学能、辐射能、核能和质量能。
    - 能量不能被创造或销毁 → 但在转化过程中，一些有用的能量往往会丢失。

# 不要混淆“能量”和“功率”

- 标量量只有大小 → **能量**、体积、质量、密度等。
- 矢量量既有大小又有方向 → **功率**、速度、重量等。
- 能量以焦耳为单位测量。
    - 或在营养学中以卡路里为单位：1卡路里 = 4.186焦耳。
- 功率 = 能量 / 时间
    - 例如：瓦特 = 焦耳 / 秒
- 能量 = 功率 × 时间

## **关于发电站的误导性说法**

- 他们说某电厂产生1000兆瓦的电力，但实际上指的是**1000兆瓦时**。
- **一个静息中的成年人需要80瓦的功率 → 每天消耗1650卡路里。**
- **在考虑替代能源时，你需要关注：生产、储存和分配。**
    - **能源密度对于储存至关重要。**
        - 木柴的密度比煤低2.5倍。
        - 天然气的密度比航空煤油低3倍。
        - 像原油这样的液体燃料更容易生产、储存和分配。

---

## **从煤到原油的转变需要几代人时间**

- 原油成为全球燃料 → 它是世界上最重要的初级能源。
    - **最初原油非常便宜——因此没有动力高效使用它。**
        - 在1933年至1973年间，美国的汽车实际上变得更低效。
    - 20世纪70年代，阿尔及利亚、利比亚、科威特、卡塔尔和沙特阿拉伯将石油生产国有化。
    - 价格的不稳定性使其吸引力下降。

# 更新能源的挑战

- **石油不会很快被取代，尤其是在通过天然气、风能和太阳能发电时。**
- **可再生能源可以发电，但也有重大缺陷：**
    - **分布困难**：你不能仅仅在需要的地方发电。你需要花钱将能源从风力资源丰富的地区传输到高需求地区。
    - **不可预测**：你需要保留旧的不可再生能源电厂，以应对太阳能和风能短缺的日子（如德国保留了90%的化石燃料发电能力）。
        - 添加可再生能源可以在峰值生产时提供帮助，但仍需保证最低供应。
- **电力只是全球能源使用的18%**。
    - **2020年，电力主要由煤和天然气生产（10%核能，16%水电，7%风能和太阳能）。**
    - 需求迅速增长。

# 理解粮食生产

- 矛、斧头、弓箭、编织网、篮子和钓竿使人类能够捕猎和捕捉各种物种。
- 从采集生活过渡到定居生活使人口密度提高，因为粮食供应变得更有规律。
    - 这并不意味着营养更好。农业依赖少数主食作物（小麦、大麦、水稻、玉米、豆类、土豆）。
- 放眼全球，每年我们都能生产出足够的粮食。全球营养不良率从1950年的2/3下降到2019年的1/11。
    - **1950年世界生产的粮食足够养活8.9亿人 → 增长了8倍 → 2019年足够养活70亿人。**
- **我们高度可靠的粮食供应依赖于化石燃料（和电力）：**
    - **直接**：为所有田间机械、运输、加工场所和灌溉泵提供动力。
    - **间接**：制造农业机械、生产化肥、除草剂、杀虫剂、杀菌剂以及温室材料等。
- 作物（供人类和牲畜使用）需要蓝光、红光以及少量的元素，特别是氮和磷。
- 非太阳能能源对作物生产和捕捞野生海洋物种变得越来越重要。
- 我们在粮食生产上的效率越来越高。

---

## **粮食生产效率的演变**

| 年份 | 每生产1千克小麦所需劳动时间 | 技术 |
| --- | --- | --- |
| 1801年 | 10分钟 | 牛和木犁 |
| 1901年 | 90秒 | 马、钢犁、机械播种机、机械收割机 |
| 2021年 | 2秒 | 强大的拖拉机、宽幅犁、播种机、施肥机。氨用于氮肥和防治昆虫、杂草等 |

---

- **在1800年，美国83%的人口需要务农。**
- **化肥提供三种植物必需的大量营养素：氮、磷和钾。**
    - 它们需要大量使用以确保高产量。
    - 钾是最容易生产的。
    - 氨是所有合成氮肥的起始化合物：
        - 作物需要很多氮（每公顷100千克）。
        - **氮肥的合成是现代农业中最重要的间接能源投入。**
        - 氮存在于每个活细胞中（叶绿素、核酸（DNA和RNA）以及氨基酸（蛋白质））。
        - **氮是作物生产力的关键限制因素。**
        - 尽管氮很丰富（占大气的80%），但作为非反应性分子，只有少数方法可以将其转化为植物可用的化合物：
            1. 闪电。
            2. 豆科植物根部的固氮酶：
                - 大豆、豆类、豌豆、小扁豆和花生能够提供自身的氮。
                - 没有谷物或油料作物可以这样做。可以与豆科植物轮作，但这样会降低产能。

---

## **氮肥的历史与重要性**

1. 在温暖的气候中，你可以一年收获两次。
2. 人类和动物的废物也含氮，但你需要大量，且传播耗时。
3. **氮肥**：
    - 1909年，由弗里茨·哈柏发明的氨合成使之成为可能。
    - **新型高产小麦和水稻品种需要合成氮肥。**
    - 自20世纪70年代以来，氮肥已成为农业的重要能源补贴。
- **目前，我们无法在不依赖化石燃料的情况下养活世界。**

- **我们通过外部能源补贴为粮食系统提供支持，最大限度地减少或消除自然限制：**
    - 通过施肥、灌溉、防治昆虫、真菌和竞争性植物，或及时收获成熟作物。

## **减少依赖的可能性**

- **过去200年，我们将生产粮食所需的劳动减少了98%。**
    - **未来50年，减少对农业机械化和合成农用化学品的依赖将更加困难。**
- 减少化石燃料将需要劳动力回到农村。
- **氮通过以下方式到达世界的耕地：**
    - 大气沉降、灌溉水、翻耕作物残余物、施用动物粪肥、土壤中的氮、豆科作物和合成氮肥。
    - **氮肥贡献超过一半——没有它，我们无法养活80亿人。**
- **减少肉类消费、减少食物浪费和用有机来源替代化肥**常被提议作为解决方案。

- **田间机械和灌溉泵的脱碳应该是可行的。**

# 第三章：理解我们的物质世界

- 文明是复杂的——你不能简单地按重要性对材料进行排序。
- **硅晶圆**是电子时代的材料。
    - 这是一个多步骤且高耗能的过程，比以下材料耗能更多：
        - 比铝土矿 → 铝高20倍。
        - 比铁 → 钢高30倍。
- **硅（Si）是地壳中第二丰富的元素（28%）。**
    - 氧气是最丰富的，占49%。
    - 我们每年只需要1万吨硅晶圆。
- **现代文明的四大支柱 → 钢、混凝土、塑料和氨。**
    - 它们具有多样的属性和功能。
    - 我们需要大量它们：
        - 45亿吨水泥。
        - 18亿吨钢铁。
        - 3.7亿吨塑料。
        - 1.5亿吨氨。
    - **这些材料很难被其他材料替代。**
- **它们的生产严重依赖化石燃料：**
    - 钢 → 依靠煤和天然气进行冶炼。
    - 水泥 → 使用煤尘、石油焦和重燃油。
    - 塑料 → 来自原油和天然气。
    - 氨 → 合成需要天然气。
- **全球生产这些材料的影响：**
    - 占全球初级能源供应的17%。
    - 占化石燃料燃烧产生的二氧化碳的25%。

---

# 氨 → 喂养世界的气体

- **氨可能是最重要的材料。**
    - 它在氮肥中的应用使80亿人的喂养成为可能。
        - **没有氨，大约40亿人将无法存活。**
- **氨分子（NH3）→ 1个氮原子和3个氢原子。**
    - 氮占其质量的82% → 因为氮比氢重14倍。
- **合成氨的学习是一项困难且刻意的追求：**
    - 随着人口向城市迁移，农作物产量没有改善。
    - 粮田的快速扩张帮助喂养了所有人，但这并不可持续。
    - 世界需要一种方法来提高农作物产量：
        - **关键是氮和磷 → 两种关键宏量营养素。**
    - 我们需要足够的氮来维持不断增长的人口。

---

## **1898年，威廉·克鲁克斯提出小麦问题**

- **我们需要找到一种方法，从空气中提取氮，将其转化为植物可以吸收的化合物。**
- **1908年**，弗里茨·哈伯（在巴斯夫支持下）成为第一个成功的研究者 → 使用铁催化剂并实现前所未有的反应条件。
    - 随后卡尔·博施用了4年时间将这一工艺扩展到工厂。
    - **1913年，第一家利用哈伯-博施工艺的氨合成工厂投产。**
    - 到1970年代，全球每年生产数百万吨氨。

---

- 1972年，中国订购工厂以避免大规模饥荒 → 12年后取消粮食配给：
    - **中国农作物使用的60%的氮来自合成氨。**
- **全球农作物所需的50%的氮来自哈伯-博施法合成的氨** → 这可能是历史上最重要的技术进步。
    - **合成氨养活了人类一半人口。**
- **氨的80%生产用于农作物的氮肥：**
    - 20%用于硝酸、炸药、火箭推进剂、染料、纤维、窗户清洁剂等。
    - 55%的农用氮肥以固体形式（尿素）存在 → 其氮含量高达46%。
- **减少田间氮损失的两种方法：**
    1. 使用昂贵的缓释肥料。
    2. 分析土壤 → 仅在需要的地方施用氮肥。
- 每年合成1.5亿吨氨，其中80%用于肥料。

# 塑料 → 多样、有用、棘手

- 塑料可以被塑形。
    - 从薄膜到重型管道，塑料可塑性极强。
- **两种主要单体 → 乙烯和丙烯：**
    - 通过将碳氢化合物加热到750-900摄氏度产生。
- **热塑性塑料是主要产物 → 加热时软化，冷却时重新固化。**
    - 重量轻、强度高且易于塑形。
- **1910年，首次实现工业生产和用途。**
    - 塑料的种类：PVC、尼龙、特氟龙、聚碳酸酯、氨纶、凯夫拉等。
- **全球生产：**
    - 1925年：2万吨。
    - 1950年：2000万吨。
    - 2013年：3.7亿吨。
- 我们接触的大量物品都是塑料 → 它的用途无处不在。
    - 塑料在医院中被广泛使用。
- **不负责任地丢弃塑料并不是反对正确使用塑料的理由。**
    - 海洋中的微纤维90%是天然的。

# 钢 → 无处不在且可回收

- **3500种钢材**——大多数合金以铁为主：
    - 生铁含97%的铁、2.5%的碳和0.5%的硅。
    - 现代钢材使用较少的碳。
- **钢优于石材……**
    - **抗压强度**（柱子所能承受的力量）相当于花岗岩。
    - **抗拉强度**（梁所能承受的力量）：
        - 是花岗岩的10倍。
        - 是铝的7倍（硬度为4倍），熔点660摄氏度。
        - 是铜的4倍（硬度为8倍），熔点1085摄氏度。
- **钢的熔点为1425摄氏度。**
- **4种主要钢材：**
    - **碳钢**（占市场的90%，含0.3%-0.95%的碳）。
    - **合金钢**添加其他元素以赋予不同属性，例如硬度、强度和延展性。
        - 添加的元素包括锰、镍、硅、铬、铝、钛等。
    - **不锈钢**（含10%-20%的铬），诞生于1912年。
    - **工具钢**用于切割钢材，其抗拉强度是建筑钢材的2-4倍，用于切割、冲压等。
- **所有钢材（除了不锈钢）都是磁性的。**
- **钢是使用最广泛的金属**（汽车、建筑物、餐具、家电、自行车等）。
- **建筑领域至关重要**：高楼大厦、桥梁、路灯、通信塔、电力基础设施。
- **交通工具中按重量钢使用最广泛：**
    - 飞机是例外，钢仅占10%。
    - 汽车含约900千克钢（每年生产1亿辆）。
    - 船舶和集装箱主要由钢制成。
- **大多数钢制品通过大型钢铁机械制造**（车削、铣削、钻孔、焊接、切割等）。
    - **工具钢切割碳钢如刀切黄油般轻松。**
- **钢用于能源生产和基础设施。**
- **广泛应用于医院和武器制造。**

---

- **我们有足够的铁：**
    - 按质量计算，铁是地球的主导元素（比水重8倍）。
    - 地壳中仅三种元素更多见：氧、硅和铝。
- **铁矿石年产量约为25亿吨。**
    - 足以支撑当前使用量300年——而且钢可以轻松回收再利用（尽管耗能高）。
        - 汽车用钢和结构钢大多被回收利用。
    - **全球钢铁总产量的30%被回收。**

---

## **钢铁制造的现代化**

- 1950年代钢铁制造高度商业化：
    - 高炉 → 生铁。
    - 基本氧气炉 → 降低碳含量（生产钢材）。
    - 铸造机 → 板坯、钢锭和钢带。
- **钢铁制造耗能巨大，占全球初级能源供应的6%。**

---

- **钢铁依赖焦煤和天然气** → 是温室气体排放的重要来源：
    - 生产1000千克钢需要500千克碳。
    - 每年排放9亿吨碳（占化石燃料排放的7%-9%）。
- **水泥的能耗较低，但产量是钢的3倍**，因此其二氧化碳排放量约占8%。

---

# 混凝土 → 水泥造就的世界

- **水泥是混凝土的关键成分。**
    - 通过加热研磨的石灰石和粘土至1450摄氏度 → 磨成水泥。
- **混凝土：**
    - 75%骨料。
    - 15%水。
    - 10%水泥。
- 精细砂更强，但需要更多水。
- **混凝土坚硬且沉重，抗压能力强，但抗拉强度弱。**
    - 钢的抗拉强度是混凝土的100倍。
    - **用钢筋强化混凝土可以弥补这一缺点。**
- **混凝土使城市成为可能：**
    - 地基、桩、墙壁、天花板。
    - 隧道、道路、桥梁、机场跑道、码头。
- **罗马人用水泥建造了万神庙（2000年历史）。**
- *钢筋混凝土（1870年代）和现代旋转水泥窑（1890年代）**使水泥在大型建筑项目中变得经济实惠且可用。
- **胡佛大坝** → 使用2万吨钢、3.4百万立方米混凝土，另有8千吨结构钢。
- **全球每年生产40亿吨混凝土**（超过1900-1950年使用量）。
- **混凝土受到多种因素侵蚀**：湿气、冻结、细菌、藻类、酸、振动、地压、反应性化合物。
    - 高碱性阻止钢筋腐蚀。
- **1990年至2022年 → 使用7000亿吨混凝土**：
    - **建筑物需要在某些时候被替换 → 需要大量替换（30-100年寿命）。**
- **钢筋混凝土建筑可以回收利用。**

# 所有材料

- **钢、水泥、塑料和氨的需求可以满足。**
    - 但很难减少对化石燃料的依赖。
- 如果世界其他地区想像中国一样发展城市和基础设施：
    - **需要15倍的钢、10倍的水泥、30倍的塑料生产量，以及2倍的氨。**
- **对化石碳的需求是我们从钢、水泥、氨和塑料中获得好处所付出的代价。**
- **风力涡轮机需要大量钢、水泥和塑料：**
    - 地基是混凝土。
    - 叶片是塑料树脂（15吨）。
- **电动汽车是新材料依赖的例子：**
    - **典型汽车电池（450千克）：**
        - 11千克锂。
        - 14千克钴。
        - 27千克镍。
        - 40千克铜。
        - 50千克石墨。
        - 181千克钢、铝、塑料。
- **每辆车需要40吨矿石**（许多矿石浓度较低），因此每辆车需处理225吨材料。
- **为满足电动车需求增长，我们需要：**
    - 18倍的锂。
    - 18倍的钴。
    - 30倍的镍。

# 第四章：理解全球化

- **全球化** = 专业化、集装箱、散货船、产品组装、移民、休闲旅行、资金流动、数据流。
- **全球化** = 世界经济、文化和人口间因商品和服务的跨境贸易、技术、投资、人员和信息流动而日益相互依存。
- **全球化并不是一种自然力量的经济等价物。**
- **中国之所以优于非洲**，因为：
    - 一党政府、稳定的投资条件、同质且有文化的民众，以及庞大的国内市场。
    - **中国成为受益者。**
- **技术因素使全球化成为可能：**
    - 原动机 → 发动机、涡轮机、电动机。
    - 通信和信息 → 存储、传输和检索。
- **技术进步需要与政治和社会条件相吻合** → 因此无法保证全球化会持续。

---

# 全球化的历史起源

- **技术能力限制了交流的频率和强度：**
    - 能量和速度、长距离通信。

---

## **风动力（帆船）**

- 人力最多能携带50公斤。
- 马匹最多携带100公斤 / 日行25公里。
- 船只速度慢、体积小，难以导航，常无法完成航程。
    - 从荷兰到亚洲需要8个月的海上航行（时速4.7公里）。
    - 1780年，荷兰的航运业仅占GDP的1%-2%。

---

## **蒸汽机和电报**

- **三大因素推动了下一波全球化：**
    1. **更可靠的导航：**
        - 1765年，约翰·哈里森发明海洋时钟/计时器。
        - 能够精确测定经度。
    2. **蒸汽动力（意味着更大的船只、更高的速度）：**
        - 1838年，首次西向跨大西洋航行。
        - 蒸汽动力与帆船共存了数十年。
        - 低效的引擎需要大量煤炭。
        - 蒸汽动力从划桨轮过渡到螺旋桨（1840年代）。
        - 1877年，钢质船体问世。
        - 速度显著提高：
            - 1850年代最快的帆船时速20公里。
            - 钢质船体和螺旋桨时速30-49公里。
    3. **电报 → 更好的通信：**
        - 1858年，第一条跨大西洋电缆。
        - 交易时可获知世界另一端的价格。
        - 电话较慢：
            - 美国电话用了20年才普及 → 通话价格非常昂贵。
            - **1876年**，首次公开展示。
            - **1880年**，50,000台。
            - **1896年**，首次实现从芝加哥拨打纽约。
            - **1900年**，135万台。
            - **1927年**，首次实现跨国电话。

---

- **国内铁路**（美国、英国、欧洲和印度）也促进了贸易。
- **1870年至1913年，全球贸易增长了4倍。**
- **流线型船舶**以史无前例的规模运送旅客（每次2000人）。

---

## **柴油引擎、航空和无线电**

- **柴油引擎更高效且更可靠。**
- 1903年，莱特兄弟飞行成功。
- 1901年，首次跨大西洋无线电消息。
- 1920年，商用无线电问世。
- **按质量计算，柴油的效率是蒸汽的2倍**，引擎效率也更高。
- **1936年**，DC-3成为首架盈利的长途飞机。
- **1939年**，波音314客机（远程飞行艇）：
    - 从伦敦到新加坡。
- **无线电优于电报**：
    - 在10年内，60%的美国人拥有无线电。
    - 对结束战争作出了重大贡献：
        - **二战结束时，飞机产量**：
            - 美国30万架，德国11.2万架，日本6.8万架。
        - **1949年**，所有国家的生产水平超过战前。

---

## **大型柴油机、涡轮机、集装箱和微芯片**

- **二战后全球化（1950年后）：**
    - 随着1973年OPEC石油价格上涨而结束 → 全球化停滞15年。
    - 大量采用更强大、更高效的柴油引擎。
        - 燃气涡轮机 → 喷气客机。
        - 更好的船舶设计（液体和固体散货船）。
        - 计算与信息处理。
- **1950-1970年：**
    - 钢产量增长4倍（190 → 700百万吨）。
    - 水泥产量增长6倍（133 → 770百万吨）。
    - 氨合成/氮产量增长8倍（5 → 37百万吨）。
    - 塑料产量增长26倍（2 → 45百万吨）。
    - 初级能源产量增长3倍。
    - 原油消费增长6倍。
- **油轮越来越大 → 容量迅速增加。**
- **1957年发明集装箱**，1966年开启定期航线（纽瓦克到鹿特丹）。
- 1950年至1973年，柴油引擎变得更大（10 → 40兆瓦），效率达50%。
- **1960年代**，喷气式客机兴起。
    - **1970年**，首架商用波音747：
        - 前50年购买了1500架 → 运送了59亿人。
        - 涡扇发动机使之成为可能。
- **全球化与宽体喷气客机的增长息息相关。**
- **微型化的计算、通信和处理器**推动了全球化：
    - 无线电、电视、计算机。
- **计算机：**
    - ENIAC（电子通用计算机），使用18,000个真空管（重30吨）。
    - 1960年，英特尔微处理器 → 单个硅晶圆内含2000个晶体管：
        - 4044 → 运行电子计算器。
        - 最终发展为个人计算机。
- **西方是全球化的主要受益者**（进口和旅行）。

# 必然性、挫折与过度扩张

- **国际经济一体化的趋势通过能量、材料、人员、思想和信息流动的加剧表现出来** → 技术能力的提高推动了这一趋势。

    - 英国和日本进口的粮食多于其生产量。

    - 历史告诉我们，这种状态不太可能持续数代人。
    - **1980年，深圳只是一个小渔村。**
    - 欧洲、北美和日本去工业化 → 制造业转移到中国。
    - 技术进步并非必然延续。

- **我们可能正处于全球化的巅峰。**

# 第五章：理解风险

- **我们在减少饥荒、事故和医疗死亡风险方面取得了巨大进展。**
- **自然灾害** → 飓风、龙卷风、洪水、干旱、蝗灾和病毒。
- **人为灾害** → 石棉、全球变暖、恐怖主义。

---

## **基础知识：我们应该吃什么以延长寿命？**

- **日本的预期寿命最高 → 85岁。**
    - 寿命由遗传、生活方式和营养因素决定。
    - 白米 + 海鲜。
    - 美国人每年多摄入8千克脂肪和16千克糖。
- **西班牙女性是亚军 → 地中海饮食。**
    - 摄入大量水果、蔬菜、全谷物、豆类、坚果、种子和橄榄油。
    - 更高的脂肪、肉类和糖饮食 → 仅略逊于日本。
        - **像瓦伦西亚人那样饮食会更好。**

---

## **风险认知与容忍度**

- 当人们认为自己可以掌控时，他们不介意参与冒险行为（驾驶、吸烟）。
- **差异：**
    - **A）容忍自愿风险。**
    - **B）避免非自愿暴露的风险。**
        - 人们不喜欢被要求给孩子接种疫苗——因为存在自闭症风险的认知。
- **对核能的恐惧** → 它实际上挽救了空气污染导致的死亡人数。
    - 德国正在试图摆脱核能 → 而法国则采纳了它。
- **没有“客观风险” → 因为我们的认知是主观的，依赖于我们对具体危险的理解和文化环境。**
    - **非自愿风险**被视为不可控和未知的危险（如核能）。
    - **自愿风险**被视为可控和已知的危险（如X光）。
- **“恐惧”在风险认知中占据了重要地位。**
    - 恐怖分子行动时间、地点和规模不可预测 → 高度令人恐惧。
    - **与驾驶相比** → 自愿、频繁、熟悉，通常是单独死亡 → 不令人恐惧。
        - 每年导致120万人死亡。

---

## **量化日常生活中的风险**

- **每10万人死亡原因的年发生率：**
    - 他杀：6人。
    - 白血病：7.2人。
    - 意外跌倒：11.2人。
    - 胰腺癌：13.5人。
    - 机动车事故：52.5人。
    - 糖尿病：25.7人。
    - 意外中毒：19.9人。
    - 乳腺癌：13.1人。
- **你驾驶的时间并不长，因此驾驶的风险远大于谋杀的风险（谋杀风险分布在全年365天中）。**
- **可预防的医疗错误是一个重大杀手：**
    1. 心脏病：611,000人。
    2. 癌症：585,000人。
    3. 可预防的医疗错误：400,000人。
    - **医院死亡中很大一部分是由于医疗错误。**

---

## **自愿和非自愿风险**

- **驾驶比飞行危险10倍。**
- **在驾驶时死亡的几率比坐在椅子上增加50%。**
- 高空跳伞的死亡率为1/2317 → 比坐在椅子上高出50,000倍。
- 跳伞比坐在椅子上高出50倍。
- 恐怖主义在纽约的风险仅比坐在椅子上的风险高出1/10%。

---

## **自然灾害的风险低于电视上的表现**

- **地震和龙卷风并没有杀死那么多人。**
    - 比坐在椅子上的风险高0.0001。
- **在美国，因家用枪支死亡的人数是恐怖主义的1000倍。**
- **非洲裔美国男性死于车祸的可能性是其他人的5倍，但死于枪支的可能性高出30倍。**

# 第六章 - 理解环境

## **安全的地球边界**

- 气候变化
- 海洋酸化
- 平流层臭氧耗损（我们的紫外线屏障）
- 大气气溶胶（降低能见度并导致肺部损伤）
- 氮和磷循环的干扰（污染水供应）
- 土地利用变化（森林砍伐、农业、城市化和工业扩张）
- 生物多样性丧失
- 化学污染

---

**从呼吸、饮水和饮食的视角来看我们需要什么：**

- 氧气流通的大气层
- 水及其全球循环
- 土壤 + 光合作用、生物多样性和植物营养物质的流动。

---

## **我们总有足够的氧气**

- **我们需要持续供氧才能生存** → 每分钟呼吸12-20次：
    - 每人每天需要1千克氧气。
    - 每年共消耗27亿吨氧气（相对于大气中的氧气，这只是很小的一部分）。
- **我们不需要更多的氧气** → 我们不需要依赖树木来生产氧气：
    - 树木确实会产生氧气，但它们消耗的氧气几乎与产生的一样多。
    - 每年约3000亿吨氧气通过光合作用被吸收和释放。
    - 即使我们明天烧掉全球所有的植物，氧气也不会短缺。

---

## **水更加复杂**

- **我们拥有丰富的水资源，但分布不均**，因为我们管理不善：
    - 每人每天需饮用1.5-3升水 / 每年约750千克。
    - 用于清洁等用途的水每年约7000千克。
- **无水三天通常会致命。**
- **如果考虑整个经济，每人每年需用水2300吨。**
- **粮食生产是最大的用水领域。**
- **在一个80亿人口的世界中，我们无法回到前工业化的农业方式。**
- **磷和钾是两种关键的矿物宏量营养素**：
    - 剩余磷的使用年限约90年，但其他来源可能延长至1000年。
- **更大的担忧是它们如何污染水资源：**
    - **导致藻类生长 → 从水中移除氧气 → 鱼类和甲壳类动物无法生存。**
    - 很难通过过滤完全去除。

---

## **为什么地球不会永久冻结**

- **温室效应是部分自然的** → 它防止了地球进入冰河时代：
    - 没有温室效应，地球温度将为-18摄氏度。
    - 全球平均温度为15摄氏度（高出33摄氏度）。
- **水蒸气是温室效应的主要贡献者**：
    - 温度决定了大气中的水含量。
- **化石燃料的燃烧和水泥的生产**是二氧化碳增加的主要原因：
    - **1800年大气中的二氧化碳为270ppm。**
    - **2022年上升到420ppm（增加50%）。**
    - **二氧化碳占温室效应的75%，甲烷占15%。**

## **我们何时首次了解气候变化？**

- **1856年**，尤尼斯·富特 → 将二氧化碳与全球变暖联系起来。
- **1861年**，约翰·廷德尔 → 发现水蒸气是吸收辐射的最重要成分。
- **1908年**，斯万特·阿伦尼乌斯 → 首次计算二氧化碳增加对全球表面温度的影响。
    - 二氧化碳浓度翻倍将使温度升高4摄氏度。
- **直到1980年代，这才成为流行文化中的话题。**

## **在更温暖的世界中氧气、食物和水的变化**

- **1850年至2020年，气候变化的影响为每平方米2瓦：**
    - 海洋升温极其缓慢。
- **我们无需担心氧气：**
    - **化石燃料的燃烧会消耗氧气，但氧气储量非常大**：
        - 年变化仅为0.002%或每百万分之4（ppm）。
    - 要使氧气减少到纽约与盐湖城（海拔1200米）之间的差异水平，需耗时1500年。
- **水资源更令人担忧：**
    - 气温升高2摄氏度可能导致5亿至30亿人面临气候变化引发的水资源短缺。
    - 一些主要的河流流域可能变得缺水。
- **粮食供应将会安然无恙：**
    - 如果将牛肉换成鸡肉和猪肉，甚至可能不用减少肉类摄入。
    - 更高效的耕地分配可以支持更大的人口。

# 第七章 理解未来

## **在末日与奇点之间**

- **未来会是什么样子？**
    - **末日？** → 厄运的宣扬者。
    - **奇点？** → 技术乐观主义者 → 相信奇迹与永恒的救赎。
        - **机器智能超越人类智能。**
- **末日与奇点提供了两个绝对答案** → 我们的未来将介于两者之间。
- **三类定量预测：**
    1. **过程已知且动态受限于相对固定结果范围的事件。**
    2. **大方向正确，但结果存在重大不确定性的事件。**
    3. **定量寓言**：可以使用数字，但这些数字基于假设，结果可能截然不同。

---

## **失败的预测**

- **全球人口增长加速从未发生：**
    - **全球人口增长率**实际上在1960年代达到顶峰，每年增长2.1%；到1990年代仅为1.08%。
    - 很快，全球将近50%的国家将低于人口更替水平。
- **资源枯竭：**
    - 人们认为90年代石油开采已达到峰值 → 但1995年至2019年间产量增加了66%。
- **粮食短缺：**
    - 相反，我们让许多人摆脱了粮食贫困和营养不良。

---

## **停止预测，开始提供实际建议**

- **大型复杂系统的惯性**源于其基本的能量和物资需求，以及其运行规模：
    - **两个基本投入需要大量能源：**
        - **钢铁** → 每吨需要18吉焦耳。
        - **氨** → 每吨需要21吉焦耳。
- **欧盟每公顷使用160千克化肥，埃塞俄比亚仅使用20千克。**
- **21世纪前20年，可再生能源产量增加了50倍：**
    - 对化石燃料的依赖从87%下降到85%。
- **我们使用的能源越多** → 从一种形式转向另一种形式就越困难：
    - 从木材到煤炭比从天然气到可再生能源容易得多（相隔100年）。
- **我们可以将可再生能源的采用率提高三倍**，**但到2050年仍将以碳为主。**
- **用移动电话替代10亿部固定电话只需一代时间。**
- **但从燃气轮机转向太阳能却不可能在一代时间内完成。**
