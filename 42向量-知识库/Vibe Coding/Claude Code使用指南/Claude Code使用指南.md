Claude Code 五大利器总结

1. [CLAUDE.md](http://claude.md/)（规则文件）= 冰箱家规
先把"进门换鞋、10点关灯、刀具归位"写清楚，Claude 做任何事前都会查看并严格遵守。
2. Task（多任务并行）= 多台家电同时工作
扫地机器人+洗碗机+空调一起运行，Claude 可同时执行多个任务，效率显著提升。
3. /自定义指令（常用操作快捷）= 场景模式
设置"回家模式"：一进门自动开灯→启动空调→播放音乐。
4. Hook（事件触发器）= 智能提醒/自动联动
洗衣机完成→手机提醒晾衣服；门磁感应到你进门→灯自动亮起。
5. Sub Agent（子智能体）= 家庭专业团队
管家、厨师、保洁、物业、维修师傅……各有专长，随时待命。

打造"满血版Claude Code"的流程如下

先定家规（[CLAUDE.md](http://claude.md/)）→ 组建专业团队（Sub Agent）→ 配置自动触发器（Hook）→ 添加MCP → 创建一键场景指令（/自定义指令）→ 启动全自动多任务Task并行执行
