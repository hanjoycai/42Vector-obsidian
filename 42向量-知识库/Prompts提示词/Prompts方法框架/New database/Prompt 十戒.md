Prompt 十戒

1. 好的 Prompt 是精准的
每个词都有其目的，没有歧义，没有冗余。精准是对话的基础。
2. 好的 Prompt 赋予任务以意义
不只是指令，而是清晰传达目的与价值，让 AI 理解为什么，而不仅是做什么。
3. 好的 Prompt 是优雅的
结构清晰，逻辑流畅，读来自然。美的形式促进美的结果。
4. 好的 Prompt 是自明的
无需额外解释，上下文完整，让理解成为必然而非偶然。
5. 好的 Prompt 是谦逊的
不炫技，不卖弄，以达成目标为唯一追求。
6. 好的 Prompt 是真诚的
坦诚表达意图，不试图"欺骗"或操纵，建立在信任之上。
7. 好的 Prompt 是持久的
经得起重复使用和变化调整，核心价值不因时间而褪色。
8. 好的 Prompt 关注至微
从整体架构到标点符号，每个细节都经过推敲。
9. 好的 Prompt 是负责的
考虑输出的影响，避免有害结果，促进积极的创造。
10. 好的 Prompt 是克制的
Less is more. 不多一字，不少一词，恰到好处即是完美。
