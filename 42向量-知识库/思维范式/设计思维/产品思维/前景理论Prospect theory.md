**前景理论与损失规避：用户如何做出决策**

前景理论由心理学家丹尼尔-卡尼曼（Daniel Kahneman）和阿莫斯-特沃斯基（Amos Tversky）于 1979 年提出，卡尼曼因此于 2002 年获得诺贝尔经济学奖。

人们在做决策时依赖的偏差之一就是损失规避：就像上面的保险例子一样，人们倾向于过高地考虑小概率事件，以避免损失。即使发生代价高昂的事件的可能性微乎其微，我们也宁愿接受较小的、确定的损失--以保险金的形式--也不愿冒大笔支出的风险。我们认为出现重大健康问题的可能性要大于这种事件实际发生的可能性。

我们都愿意相信自己是合乎逻辑的决策者。在用户体验领域，我们经常谈论用户如何权衡不同选择的预期效用，以决定采取什么行动或下一步去哪里。然而，在做出是否购买物品、捐款或选择服务等级等决定时，人们极易受到认知偏差的影响，往往不会做出合乎逻辑的选择。

例如，你会如何选择：是拿 900 美元，还是赌 90%的机会赢 1000 美元（10%的机会赢 0 美元）？大多数人都会规避风险，选择 900 美元，尽管两种情况的预期结果是一样的。然而，如果我让你在损失 900 美元和有 90%的机会损失 1000 美元之间做出选择，你中的大多数人可能会更倾向于第二种选择（有 90%的机会损失 1000 美元），从而做出寻求风险的行为，希望避免损失

*在处理收益问题时，人们都是风险厌恶者，他们会选择有把握的收益（红线表示），而不是风险较大的前景，即使冒着风险也有可能获得更大的回报。还要注意的是，每种选择的总体预期值（或结果）是相等的。*

![[内容生产系统/03-内容素材库/爆款文稿库/assets/段永平的管理原则｜平庸CEO解决问题，优秀CEO改进系统/Untitled 138.png]]

*对待损失的态度与对待收益的态度截然相反。当人们想要避免损失时，就会变得追求风险，在肯定会损失的情况下赌一把，希望不付出任何代价。同样，两种选择的预期值相同。*

预期效用法无法轻易解释这类行为。在这两种情况下，两种选择的预期效用是一样的（+/-900 美元）：概率乘以预期中奖率。然而，人们在很大程度上更倾向于一种选择，而不是另一种。

前景理论解释了人们在做出此类决定时的偏差：

- **Certainty**** ****确定性**
- **Isolation effect**** ****隔离效果**
- **Loss aversion**** ****损失规避**

**Certainty 确定性：**

人们倾向于过分看重确定的选择，而对收益的风险厌恶。我们宁可获得有把握的、较小的胜利，也不愿冒险赢得更多的胜利（但也有可能一无所获）。在面对某些损失时，情况则恰恰相反：人们会采取寻求风险的行为，以避免更大的损失。

要说服用户采取某种行动，可以考虑利用确定性偏差：人们宁愿接受微小但确定的奖励，也不愿接受仅有机会获得更大收益的奖励。例如，如果你为撰写产品评论的用户提供奖励，可以考虑为所有评论者提供一张优惠券，在下次购买时可获得 10%的折扣。这种优惠券（只有当他们再次购买更多商品时，你才需要花钱）比 1000 美元的抽奖更有吸引力，也更有效--虽然奖励金额很大，但可能性很小。

这种偏见也可以解释为什么人们常常忠于特定的产品、服务、网站或其他工具。我们要么冒险使用其他可能比现有方法更好的东西，要么继续使用我们久经考验的工具。

**Isolation Effect 隔离效果：**

孤立效应指的是人们倾向于忽略两个选项中的共同点，从而简化并关注不同点。记住每个备选方案的所有细节会造成过多的认知负担，因此只有关注差异化才有意义。摒弃共同点可以减轻比较备选方案的负担，但也可能导致选择不一致，这取决于备选方案的展示方式。

丹尼尔-卡尼曼（Daniel Kahneman）和阿莫斯-特沃斯基（Amos Tversky）向参与者展示了两种情景。在这两个场景中，人们都得到了一笔初始金额，然后必须在两个备选方案中做出选择。

情景 1：参与者最初拥有 1000 美元。然后，他们可以选择

1. 以 50%的概率赢取 1000 美元（以 50%的概率赢取 0 美元），或
2. 肯定还要 500 美元。

情景 2：参与者最初拥有 2000 美元。然后，他们可以选择

3. 以 50%的概率输掉 1000 美元（以 50%的概率输掉 0 美元），或
4. 损失 500 美元是肯定的。

由于两种方案中的初始金额不同，因此这两种方案实际上是等价的：如果他们在第一种方案中选择方案 B，或者在第二种方案中选择方案 D，那么他们最终拥有的金额是一样的（方案 A 和 C 也是等价的）。(选项 A 和 C 同样是等价的。）然而，人们在两种方案中做出了相反的选择：大多数人在方案 1 中选择了规避风险的选项 B，而在方案 2 中选择了规避损失的选项 C。

改变问题的框架（相应地调整最初的礼物和选项）会让人们做出不同的决定。

> *在面对每个决定时，人们会根据选项是收益还是损失做出相反的选择。在情景 1 中，大多数人选择 B 而不是 A，但在情景 2 中，大多数人选择 C 而不是 D，以尽量避免损失。在这些情景中，人们只关注两个选项之间的选择，而忽略了初始赠与金额，因为它是两个选项的共同因素。然而，如果考虑到初始赠与的差异，可以看出选项 A 等同于选项 C，选项 B 等同于选项 D--只是框架发生了变化！*

在制作说服人们做出某种选择的内容时，要考虑如何构思。人们对负面信息的反应与对正面信息的反应截然不同。你是愿意使用满意率高达 95% 的服务，还是愿意使用投诉率只有 5% 的服务？负面的表述会让人们想到可能的 "损失 "或负面结果，并采取相应的行动。

还应考虑如何显示信息，以帮助用户识别可以安全忽略的常见元素，从而专注于关键的差异化因素。例如，展示产品配置器与让用户整体选择不同产品相比。看到产品或服务的每一种可能的最终排列组合，可能会让潜在客户做出不同的决定（或者只是让他们不知所措，导致他们放弃这项任务），而如果只向他们展示一种或两种产品，然后让他们选择通过添加功能来定制这些产品，他们可能会做出不同的决定。

在产品比较中支持简化过程的另一种方法是并排显示重要信息，而不是仅通过每个单独的产品页面。只要所有项目的详细程度保持一致，突出差异的比较表格就能很好地发挥作用。网络上最常见的活动之一就是用户在多个产品或服务之间进行比较和选择，因此为这项工作提供充分的支持至关重要。

## **Loss Aversion**** ****损失厌恶症**

大多数人都会尽量减少损失，因为损失比收益更大，尽管损失的概率很小。输钱的痛苦也解释了为什么在赌博时，赢了 100 美元，然后输了 80 美元，即使你实际上赢了 20 美元，也感觉是净损失。人们对损失的反应比对收益的反应更为极端。

网站上的信息可能会利用人们的偏见来说服他们做出购买或其他决定。例如，保险网站经常会列出一长串如果我们不买保险可能会遇到的不可能但代价高昂的结果。这份清单使我们倾向于避免这些巨大损失，并使我们忘记了为确保保险范围而支付的小额但定期的费用。

对于本质上无法避免巨大损失的产品或服务，我们可以通过了解用户的顾虑来说服他们采取某些行动。如果我们能通过用户研究发现人们的顾虑，就能提供信息帮助他们克服这些恐惧或反对意见。例如，潜在用户可能不愿意开始在线申请流程，因为他们担心会花费太多时间，或者需要不容易获得的信息。如果网站意识到这种看法，就可以尝试加以改变，例如说明申请平均需要多长时间，以及完成申请需要哪些信息。

## **Guard Users Against Negative Experiences****防范用户的负面体验**

前景理论还可以延伸应用于人们的整体用户体验。在与网站或应用程序交互的过程中，我们可能会遇到挫折或困惑，在这种情况下，我们会对失落时刻产生更强烈的反应。当一切都按预期运行时，人们会认为这是正常现象。但是，一旦出了一点差错，人们就会产生抵触情绪，并在更长的时间内记住这些糟糕的经历。这就是为什么测试一切并努力解决这些小绊脚石是如此重要的原因。我们正在为难以取悦的用户进行设计。
