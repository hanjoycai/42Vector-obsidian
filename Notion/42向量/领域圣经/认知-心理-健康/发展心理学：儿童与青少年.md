## **理解本书的哲学框架**

在深入探讨具体章节之前，必须首先把握作者在序言 (Preface) 中阐明的指导哲学，这是理解全书内容和结构的“镜头”。

1. **理论多元主义 (Theoretical Eclecticism)**：作者明确指出，没有任何单一理论是“最佳的”。本书尊重所有主要理论流派的贡献，包括精神分析、行为主义、认知发展、信息加工、行为生态学、进化论、社会文化观、生态系统观和行为遗传学。
2. **系统研究的价值 (Value of Systematic Research)**：本书坚信，关于人类发展的最可靠信息来源于系统的、科学的研究。因此，第1章（研究方法）和第2章（发展理论）构成了评估后续所有实证发现的“工具箱”。
3. **过程导向 (Process Orientation)**：本书的目标不仅是 *描述* 发展的现象（“是什么”），更是要 *解释* 发展 *为什么* 会发生（“如何发生”）。
4. **背景导向 (Contextual Orientation)**：强调发展并非在真空中发生，个体始终处于特定的历史和文化背景（如家庭、社会、文化）之中，这些背景深刻地影响着发展轨迹。
5. **发展的整体性 (Holistic Process)**：发展不是零碎的，而是整体的。生理、认知、社会和情感等领域是相互依赖、相互作用的 。本书的组织方式（按主题划分）旨在追溯每个领域的发展脉络，同时在各章中不断强调这些领域间的相互联系。

## **第1章 导论:发展心理学及其研究策略**

几个概念

- **成熟(maturation)**:由成长过程而非学习、受伤、疾病或者别的生活经历导致的身体或行为上的发展变化。
- **学习(learning)**:由经验或练习导致的个体行为(或行为潜能)发生的相对持久的变化。
- **常态发展(normative development)**:刻画了一个种系的大多数或所有成员发展变化的特点，是发展的典型方式。
- **特殊发展(ideographic development)**:个体在发展的速度、程度或方向上的差异。

发展学家设定的三个主要目标是：描述、解释、优化发展

没有一种单一的发展模式能精确地适用于所有文化、社会阶层或所有人种、种族。每种文化、亚文化和每个社会阶层都会向自己的下一代传递特定的信仰、价值观、风俗和技能，并且这种文化的社会化内容对个体所展现的特性和能力有很大的影响。发展也受到社会变化的影响:如历史事件(比如战争)、科技创新(如互联网的发展)、社会原因(如同性恋的权利运动)等。每一代人都会以自己的方式发展，每一代人又为下一代改变着世界。

**科学方法**指的是：为了检验一个理论或假设，采用客观的、可重复的方法收集数据。

- 科学方法的客观性意味着，所有分析资料的人会根据资料得到相同的一个结论，而不是一个主观的观点。
- 可重复性则是指，我们每次使用某种方法进行研究，应该收集到相同的数据，得到相同的结果。

**七种常用的研究方法及其优缺点**

| 研究方法 | 优点 | 缺点 |
| --- | --- | --- |
| **自我报告法** |   |   |
| 访谈法和问卷 | 收集大量信息的速度相对较快;标准化模式使研究者能直接比较来自不同被试的数据。 | 所收集的数据可能不够精确或不够真实;或者数据反映的只是被试回答问题的口头表达技巧或理解问题的能力。 |
| 临床法 | 可以灵活地把被试当作独特的个体来考察;自由的追问可以保证被试真正理解所问问题的意义。 | 因为没有同等对待被试，所得结论可能不可靠;灵活的追问在一定程度上依赖于研究者对被试反应的主观解释;只适用于有一定口头表达能力的被试。 |
| **观察法** |   |   |
| 自然观察法 | 能研究在自然情境中实际发生的行为。 | 观察者的存在可能影响观察对象的行为;在观察期间，那些不经常发生的行为或不被社会赞许的行为不一定出现。 |
| 结构化观察法 | 提供一个标准化的环境，使每个孩子都有机会表现出目标行为;是观察不经常发生的行为和不被社会赞许行为的良好方法。 | 设计出来的观察往往不能捕捉到孩子在自然情境中的行为。 |
| **个案研究法** | 在对被试个体进行推论和得出结论时，会考虑到数据的多种来源，是一种很宽泛的研究方法。 | 来自不同个案的数据类型不同，数据本身也可能不准确或者不真实;从个案得出的结论带有主观性，且不适用于其他人。 |
| **人种志研究法** | 比起观察法和访谈法，人种志法能对某种文化中的信仰、价值观和传统进行更为丰富的描述。 | 所得结论会受研究者的价值观和理论偏好的影响; 结论不能推广到所研究文化之外的群体中去， |
| **心理生理学研究方法** | 可以用来评价人的发展的生理基础，可以考察无法用口头报告法研究的婴幼儿的知觉、思维和情感。 | 不能确定被试所感觉的到底是什么;除了所研究的因素之外，还有很多因素会引发相似的生理反应。 |

**常用的几种研究设计及其优缺点**

| 研究设计 | 程序 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 相关设计 | 研究者在不干预的情况下，收集有关两个或多个变量的信息。 | 能评估自然环境中变量之间关系的强度和方向。 | 不能确定变量之间是否有因果关系。 |
| 实验室实验 | 可以对被试的环境进行操纵(自变量)，并考察自变量对被试行为(因变量)的影响。 | 能确定变量之间是否存在因果关系。 | 数据是从人为的实验环境中获得的，不能推广到真实环境中去。 |
| 现场实验 | 可以操纵自变量，测量在自然环境中自变量对因变量的影响。 | 能确定变量之间是否存在因果关系，能把实验结果推广到真实世界中去。 | 在自然环境中的实验处理可能不够有力，也难以控制。 |
| 自然实验(准实验) | 收集经历了自然事件操纵的人的行为方面的信息。 | 可以研究那些在实验室中难以引发或不可能引发的自然事件的影响;能给因果关系提供强有力的线索。 | 不可能对自然事件进行严格控制，没法建立明确的因果关系。 |

**四种发展设计的优缺点**

| 设计 | 程序 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 横断设计 | 在同一时间点上观察不同年龄的人(或同辈群体)。 | 能展示年龄差异;为发展的趋势提供线索;花费较少;耗时较少。 | 年龄趋势反映的可能是同辈群体间的差异而非真实的发展上的变化;只在某一个时间点上观察被试，所以不能提供个体发展的数据。 |
| 纵向设计 | 对某群体被试进行反复观察。 | 能提供个体发展方面的数据;能揭示早期的经历与后来发展结果之间的关系;能揭示个体之间在发展变化上的相似性及差异。 | 较耗时和昂贵;选择性损耗会导致样本无代表性，从而限制了结论的推广;跨代变化使得研究结果仅适用于所研究的被试群体。 |
| 序列设计 | 对不同年龄段(不同同辈群体)的人进行重复测量，从而把横断研究和纵向研究结合起来。 | 从同辈效应中区分出真正的发展趋势;可揭示出一个群体经历的发展变化是否与另一个群体相似;比纵向研究的花费要小，耗时要短。 | 比横断研究花费多、耗时长;尽管是最佳设计，在把所得发展变化推广到研究之外的群体时，仍然有一定的问题。 |
| 微观发生设计 | 发展变化发生时，对儿童进行短时间的密集观察。 | 对发展变化发生的时段进行密集观察，可以揭示变化的过程和原因。 | 为了刺激变化的发生，被试的密集经验可能是不具代表性的，带来的变化可能是短时的。 |

**人类发展研究中的主题**

- 天性与教养：人的发展主要是先天遗传的（生物的力量)，还是后天教养的结果（环境的力量)？
- 主动与被动：儿童是作为好奇的、积极的生命个体，在很大程度上由其自身决定社会对待他们的方式呢？还是作为被动接受者，任由社会来塑造呢？
- 连续性与非连续性(阶段性)：成长过程中我们所经历的这些变化是逐渐发生的，还是突然发生的?
- 发展的整体性：引起发展学家关注的最后一个话题是发展在多大程度上是一个整体的过程，或者是一些片段的、分裂的过程？

### **2.1 科学理论的性质**

一个好的科学理论应具备三个标准：**简约性 (Parsimony)**（简洁）、**可证伪性 (Falsifiability)**（可被检验）和**启发性 (Heuristic)**（激发新研究）。

### **2.2 精神分析观点**

- **弗洛伊德 (Freud) 的心理性欲理论 (Psychosexual Theory)**：
    - *核心*：发展由无意识的生物本能（主要是性本能）驱动，通过解决不同阶段的冲突来展开。
    - *人格结构*：**本我 (Id)**（快乐原则）、**自我 (Ego)**（现实原则）和**超我 (Superego)**（道德良知）。
    - *发展阶段*：口腔期、肛门期、性器期（恋父/恋母情结）、潜伏期、生殖期。在任何阶段的过度满足或挫折都可能导致**固着 (Fixation)**。
- **埃里克森 (Erikson) 的心理社会理论 (Psychosocial Theory)**：
    - *核心*：作为弗洛伊德的修正者，埃里克森强调社会文化（而非性本能）对发展的影响，以及“自我”在适应环境中的积极作用。
    - *发展阶段*：发展贯穿一生（共八个阶段），每个阶段都有一个核心的**心理社会冲突 (psychosocial conflict)**。前五个阶段对儿童和青少年至关重要：
        1. 信任 vs. 不信任 (0-1岁)
        2. 自主 vs. 羞耻/怀疑 (1-3岁)
        3. 主动 vs. 内疚 (3-6岁)
        4. 勤奋 vs. 自卑 (6-12岁)
        5. 认同 vs. 角色混乱 (12-20岁) 

### **2.3 学习观点**

- **华生 (Watson) 的行为主义 (Behaviorism)**：
    - *核心*：只研究可观察的行为。认为婴儿是“白板 (tabula rasa)”，发展完全由环境（通过经典条件反射）塑造。
- **斯金纳 (Skinner) 的操作性学习理论 (Operant Learning Theory)**：
    - *核心*：行为是由其结果决定的。**强化 (Reinforcer)**（增加行为）和**惩罚 (Punisher)**（减少行为）是发展的唯一机制。
- **班杜拉 (Bandura) 的社会认知理论 (Social Cognitive Theory)**：
    - *核心*：班杜拉在学习理论中加入了“认知”的元素，反对斯金纳的机械决定论。
    - *机制*：**观察学习 (Observational Learning)**（或模仿）。儿童通过观察“榜样 (model)”的行为及其后果来学习，无需亲身经历强化。著名的“波波玩偶 (Bobo doll)”实验证明了这一点 。
    - *关键概念*：**交互决定论 (Reciprocal Determinism)**。发展是个体 (P, Person，包括其认知)、其行为 (B, Behavior) 和环境 (E, Environment) 之间持续的双向互动 。

### **2.4 认知发展观点**

- **皮亚杰 (Piaget) 的认知发展理论 (Cognitive-Developmental Theory)**：
    - *核心*：儿童是**主动的建构者 (active constructors)**。
    - *机制*：通过**同化 (Assimilation)**（将新信息纳入现有图式）和**顺应 (Accommodation)**（调整图式以适应新信息）来达到认知**平衡 (Equilibration)** 。
    - *阶段*：发展是**非连续的 (discontinuous)**，经历四个不变的、质变的阶段（感知运动期、前运算期、具体运算期、形式运算期）。

### **2.5 社会文化与信息加工观点**

- **维果茨基 (Vygotsky) 的社会文化理论 (Sociocultural Theory)**：
    - *核心*：认知发展本质上是社会和文化的产物。儿童通过与更有知识的社会成员的**合作性对话 (collaborative dialogues)** 来内化其文化的思维方式。
- **信息加工观点 (Information-Processing Viewpoint)**：
    - *核心*：将人脑比作计算机。认知发展被视为心理“硬件”（如大脑容量、加工速度）和“软件”（如策略、元认知）的年龄相关变化。
    - *发展观*：发展是**连续的 (continuous)**，是量变的积累。

### **2.6 行为生态学与进化观点**

- **行为生态学 (Ethology)**：
    - *核心*：研究行为的生物进化基础及其适应性价值（对个体生存的贡献）。强调在自然情境中观察物种特有的行为（如洛伦茨的“印刻” (Imprinting)）。
- **现代进化理论 (Modern Evolutionary Theory)**：
    - *核心*：关注那些确保 *基因* 得以延续和复制的适应性行为。例如，人类漫长的不成熟期是为了适应学习复杂的社会和工具技能 。

### **2.7 生态系统观点**

- **布朗芬布伦纳 (Bronfenbrenner) 的生态系统理论 (Ecological Systems Theory)**：
    - *核心*：发展是在一个嵌套的环境系统中发生的，个体与环境是双向互动的。
    - *系统层次*：
        - **微观系统 (Microsystem)**：个体的直接环境（家庭、学校、同伴）。
        - **中间系统 (Mesosystem)**：微观系统之间的联系（如家庭与学校的关系）。
        - **外层系统 (Exosystem)**：个体未直接参与、但影响其发展的社会情境（如父母的工作环境）。
        - **宏观系统 (Macrosystem)**：广阔的文化、价值观、法律和意识形态 。
        - **时序系统 (Chronosystem)**：时间维度，包括个体生命历程中的变化和历史时期的变化 。

### **2.8 核心发展主题**

本章最后总结了贯穿全书的四个核心辩论，并展示了不同理论在这些问题上的立场 。这提供了一个元分析框架，是深刻理解本书观点的关键。

- **天性 vs. 教养 (Nature vs. Nurture)**：发展是由生物遗传还是环境经验决定的？
- **主动 vs. 被动 (Active vs. Passive)**：儿童是主动塑造自己发展的个体（如皮亚杰），还是被动接受环境塑造的个体（如斯金纳）？
- **连续 vs. 非连续 (Continuity vs. Discontinuity)**：发展是平稳的量变（连续，如信息加工），还是阶段性的质变（非连续，如皮亚JET）？
- **发展的整体性 (Holistic Nature of Development)**：发展是各领域相互交织的，还是可以模块化分开研究的？

## **第3章 产前期发展和出生**

> 孕妇所经历的早中晚三个孕期。在子宫内部，也有三个阶段，但这三个阶段过得很快，从受精卵开始，然后变成胚胎，最后成为胎儿。从胚胎到胎儿（最后一个阶段）的转变发生在第8周，此时离孕中期还有整整一个月，孕妇常常还未意识到自己怀孕，但这时，胚胎的主要器官都已形成。此后，胎儿产前期发育只是已有器官和组织的生长，以及功能的发展和改善。这意味着女人可能在根本不知道自己怀孕的情况下度过了孕期最关键的阶段。尽管女人可能知道戒酒、注意饮食营养这样的行为是有益的，但在意识到应该做出改变之前，她可能已经失去了使危险最小化的机会。

产前发育一般分为三个阶段:

- 第一个阶段是**受精卵期**，从受孕到着床，在这个阶段，发育中的受精卵将牢牢地固着在子宫壁上。受精卵期一般历时10 ~ 14 天。
- 第二个阶段是**胚胎期**，从第3周开始，到第8周结束。在这个阶段，几乎所有的重要器官已初具雏形，心脏也开始跳动。
- 第三个阶段是**胎儿期**，从怀孕的第 9周一直到胎儿出生。在这个阶段，主要器官都开始发挥功能，有机体迅速发育。

> 实际上，在怀孕后第22-28周(一般是在第7个月)，胎儿达到“存活期”，它们在子宫外有可能生存下去。

> 如果母亲怀孕时每天只喝少量的酒，那么婴儿通常不会表现出明显的生理畸形；然而，与那些母亲在怀孕时不饮酒的婴儿相比，这些婴儿发展到童年期以后，其信息加工速度通常较慢，而且智商可能较低。这些后果可能反映了酒精对胎儿大脑发育的轻微影响，但导致其大脑发育出现问题的也可能是其他因素。例如，在出生后，看护者可能给予那些反应较慢、行动迟缓的婴儿较少的刺激。一段时间以后，这种刺激的缺失（而不是酒精）可能阻碍了婴儿的智力发展。

**药物对胎儿的影响**

- 有数以千计的妇女在怀孕头两个月服用了反应停，她们意外地生出了有可怕的生理缺陷的婴儿。“反应停婴儿”通常会出现眼、耳、鼻、心脏严重畸形，许多还表现为短肢畸形——一种结构性畸形，四肢较短或没有四肢，脚或手可能直接与躯干连接在一起。
- 大剂量的阿斯匹林与胎儿生长迟滞、动作失调，甚至是婴儿死亡有关
- 孕妇在孕晚期服用布洛芬可能会推迟分娩并增加新生儿肺动脉高压的风险
- 一些研究表明，大量食用咖啡因（即每天喝超过4 罐饮料或若干杯咖啡）与早产和低体重儿等并发症有关
- 一些抗抑郁药中含有锂，如果孕妇在孕早期服用这种药物，可能造成的婴儿心脏缺陷

> 当然，绝大多数服用阿斯匹林、咖啡因、口服避孕药和DES的孕妇生出的婴儿都是非常正常的。在恰当的医疗指导下，用药物来治疗母亲的疾病对母亲和胎儿来说通常是安全的。

> 一项纵向研究从新生儿期开始追踪了一批婴儿直到6岁，发现那些出生前接触过酒精的婴儿比未接触者表现出了更高水平的负面效应。更麻烦的是，在子宫时就已接触过酒精，并表现出更高水平负面效应的婴儿，在6岁时更可能有抑郁的症状。这种情况在女孩中尤其显著。

**吸烟对胎儿的影响**

- 文献综述指出，吸烟显著增加了流产或新生儿死亡的危险，并且是导致胎儿发育缓慢和低体重儿的主要原因
- 孕期吸烟还与较高的宫外孕（受精卵着床于输卵管而非子宫）发生率及婴儿猝死综合征有关
- 不论是静态睡眠期还是动态睡眠期，在子宫中接触过尼古丁的新生儿，其心脏跳动得比没有接触者更快，接触过尼古丁的新生儿，其心率比未接触者更不稳定，震颤及行为状态改变都更频繁
- 孕妇每天吸烟越多，自发性流产和生出低体重儿的危险就越大，如果父亲吸烟，新生儿的体重也可能低于正常水平
- 如果母亲在怀孕期间抽烟或父母在孩子出生后一直抽烟，那么孩子的体形往往小于平均水平，他们更易患呼吸道疾病，在童年早期，其认知水平要低于那些父母不吸烟的同龄人

## **第4章：产前发展与出生**

本章描述了从受孕到出生的奇妙旅程，重点关注了三个发展阶段以及环境（尤其是致畸剂）对这一脆弱过程的影响。

### **4.1 产前发展阶段**

产前发展分为三个阶段：

12. **合子期 (Period of the Zygote) (0-2周)**：从受精卵（Zygote）开始，细胞迅速分裂形成囊胚 (blastocyst)，最终**植入 (implantation)** 子宫壁。
13. **胚胎期 (Period of the Embryo) (3-8周)**：这是发展的**关键期 (critical period)**。囊胚分化为三胚层，所有主要器官开始形成（**器官发生, Organogenesis**）。此时的胚胎对环境影响（致畸剂）极其敏感 。
14. **胎儿期 (Period of the Fetus) (9周-出生)**：主要的任务是生长和完善。器官系统开始运作。约22-28周达到**生存期 (Age of Viability)**，即在辅助医疗下有可能在子宫外存活 。

### **4.2 潜在问题：致畸剂**

**致畸剂 (Teratogen)** 是指任何可能导致出生缺陷的外部因子 。

- **致畸原则**：
    - *时间（关键期）*：致畸剂的影响取决于暴露的 *时间*。在胚胎期，器官正在形成，此时的危害最大 。
    - *剂量与时长*：暴露越多、越久，危害越大。
    - *遗传易感性*：母亲和胎儿的基因构成会影响其易感性。
- **主要致畸剂举例**：
    - *疾病*：如风疹 (Rubella)、艾滋病 (AIDS)。
    - *药物*：如沙利度胺 (Thalidomide)（导致肢体畸形）、酒精（导致**胎儿酒精谱系障碍, FASD**）、可卡因、烟草。
    - *环境危害*：如辐射、汞和铅。
- **母体特征**：母亲的营养状况、情绪压力（高皮质醇水平）以及年龄（过高或过低）也会影响产前发展 。

### **4.3 出生与围产期环境**

- **出生过程**：经历三个阶段：宫缩、分娩和胎盘娩出 。
- **新生儿评估**：**Apgar评分 (Apgar test)** 在出生后1分钟和5分钟进行，评估新生儿的心率、呼吸、肤色、肌张力和反射，是衡量其生命体征的重要指标 。
- **出生并发症**：
    - **缺氧 (Anoxia)**：出生时缺氧，可能导致脑损伤 。
    - **低出生体重 (Low Birth Weight)** 和**早产 (Prematurity)**：是新生儿死亡和后期发展问题的主要风险因素 。


## **第5章：婴儿期**

本章探讨了新生儿如何准备好适应子宫外的生活，他们如何感知世界，以及他们最初的学习能力。

### **5.1 新生儿的准备**

- **新生儿反射 (Newborn Reflexes)**：新生儿配备了一系列非习得的反射，用于评估神经系统的健康状况 。
    - *生存反射 (Survival Reflexes)*：具有明显适应性价值（如呼吸、吮吸、吞咽）。
    - *原始反射 (Primitive Reflexes)*：没有明显生存价值，但可能在进化上有意义（如巴宾斯基反射、莫罗反射）。
- **婴儿状态 (Infant States)**：婴儿在一天中会经历六种不同的意识状态，包括安静睡眠、**快速眼动 (REM) 睡眠**（REM睡眠占婴儿睡眠时间的50%，远高于成人，这可能为发育中的大脑提供了必要的刺激）和哭泣 。

### **5.2 婴儿感知研究方法**

由于婴儿无法用语言报告所见所闻，研究者发明了精妙的方法来探索他们的内心世界：

- **偏好法 (Preference Method)**：同时呈现两种刺激，婴儿看哪一种更久，说明他们偏好哪一种，并且能够 *区分* 这两种刺激。
- **习惯化/去习惯化 (Habituation Method)**：这是研究婴儿感知和记忆的最常用方法。向婴儿重复呈现同一刺激，直到他们失去兴趣（习惯化）；然后呈现一个新刺激，如果婴儿的注意力恢复（去习惯化），则表明他们能够区分新旧刺激 。
- **高振幅吮吸法 (High-Amplitude Sucking)**：婴儿通过控制吮吸速度和力度来“选择”他们想听的刺激（如母亲的声音）。

### **5.3 婴儿的感觉能力**

- **听觉**：产前即已发展良好。新生儿能区分不同的语音（如“ba”和“pa”），并明显偏好母亲的声音 。
- **味觉和嗅觉**：发展良好。新生儿偏好甜味，并能通过乳房的气味识别自己的母亲 。
- **触觉、温度和痛觉**：均已具备 。
- **视觉**：是新生儿 *最不* 发达的感觉 。
    - *视敏度 (Visual Acuity)*：很差（约20/600），非常近视。
    - *模式与形态感知*：婴儿天生偏好有图案的、高对比度的、复杂的刺激，其中最偏好的是**人脸** 。
    - *空间感知*：**视觉悬崖 (Visual Cliff)** 实验（Gibson & Walk, 1960）表明，当婴儿开始爬行（约6-7个月）时，他们已经能很好地感知深度，并会回避“悬崖” 。

### **5.4 跨通道感知**

**跨通道感知 (Intermodal Perception)** 是指整合来自多种感觉（如视觉和听觉）信息的能力。婴儿很早就表现出这种能力，例如，他们会期望看到的嘴唇动作与听到的声音相匹配 。

### **5.5 婴儿期的学习**

婴儿是天生的学习者：

- **习惯化 (Habituation)**：如前所述，是最早的学习形式。
- **经典条件反射 (Classical Conditioning)**：婴儿可以被动地学习将信号与事件联系起来（如灯光预示喂奶）。
- **操作性条件反射 (Operant Conditioning)**：婴儿能主动学习他们的行为所带来的后果（如婴儿学会踢腿来使床铃转动）。
- **观察学习/模仿 (Observational Learning/Imitation)**：Meltzoff 的研究表明，新生儿（甚至出生仅几小时）就能模仿成人的面部表情（如吐舌头），尽管这对模仿的机制提出了挑战 。

## **第6章：身体发展：大脑、身体、动作技能与性发展**

本章探讨了从婴儿期到青春期的身体变化，重点关注大脑、动作技能和青春期转变。

### **6.1 生长概述**

- **生长趋势**：身体生长遵循两个原则：
    - **头尾原则 (Cephalocaudal)**：从头到脚的顺序发展（头部在产前和婴儿期发展最快）。
    - **近远原则 (Proximodistal)**：从身体中心向边缘的顺序发展（躯干和手臂的发育先于手和手指）。

### **6.2 大脑发展**

- **神经发育**：出生时大脑已有绝大多数神经元。大脑的生长主要体现在：
    - **髓鞘化 (Myelinization)**：神经纤维被髓鞘（一种脂肪物质）包裹的过程，极大地提高了信息传递的速度和效率。
    - **突触形成 (Synaptogenesis)** 和 **突触修剪 (Synaptic Pruning)**：婴儿期大脑会产生过量的神经连接（突触），随后，未被使用的连接会“修剪”掉，使大脑更高效。
- **大脑可塑性 (Plasticity)**：大脑被经验塑造的能力。幼年期是大脑可塑性最强的时期，但也使其更容易受到伤害（如虐待或忽视）的影响 。

### **6.3 动作发展**

- **粗大动作技能 (Gross Motor Skills)**（如爬行、行走）和 **精细动作技能 (Fine Motor Skills)**（如抓握）的发展顺序在不同文化中具有普遍性，表明成熟（天性）的主导作用 。
- 然而，经验（教养）可以显著影响动作发展的 *时间*。
- 动作发展具有**整体性 (Holistic)** 影响：学会爬行或行走（身体发展）会极大地改变婴儿对空间的理解（认知发展）以及他们与照料者的关系（社会发展）。

### **6.4 青春期：身体的转变**

**青春期 (Puberty)** 是指个体达到性成熟并能够生育的生物过程 。

- **青春期生长突增 (Adolescent Growth Spurt)**：身高和体重的迅速增加 。
- **性成熟**：
    - *第一性征 (Primary Characteristics)*：与生殖直接相关的器官（如卵巢、睾丸）。
    - *第二性征 (Secondary Characteristics)*：生殖的外部标志（如女孩的乳房发育、男孩的声音变粗）。
    - *标志事件*：女孩的**初潮 (Menarche)** 和男孩的**初次射精 (Spermarche)**。

### **6.5 青春期的心理影响**

身体变化会带来深刻的心理和社会影响：

- **身体意象 (Body Image)**：青少年对自己身体的感受。女孩（尤其是早熟女孩）通常对体重增加感到不满意，这与社会对苗条的推崇有关 。
- **青春期时间 (Timing of Puberty)**：
    - *早熟男孩*：在社交上通常更具优势，更自信、更受欢迎，但也更容易出现问题行为。
    - *早熟女孩*：面临的风险最高，她们更容易焦虑、抑郁、成绩不佳、过早发生性行为，以及与问题同伴交往 。
    - *晚熟男孩*：在青春期可能面临社交焦虑，但在成年后可能发展出更强的应对能力和灵活性。
- **家庭关系**：青春期常伴随着与父母冲突的增加。这通常被视为个体寻求**自主 (autonomy)** 的正常过程，需要家庭关系进行“重新协商 (renegotiation)” 。

# **第三部分：认知发展**

## **第7章：认知发展：皮亚杰的理论与维果茨基的社会文化观**

本章深入探讨了两位认知发展巨匠——皮亚杰和维果茨基的理论。他们对于“儿童如何思考”以及“发展如何发生”提出了截然不同但均极具影响力的观点。

### **7.1 皮亚杰的认知发展阶段（详解）**

皮亚杰认为儿童是积极的建构者，他们的认知发展经历四个不变的、质变的阶段：

- **感知运动阶段 (Sensorimotor Stage) (0-2岁)**：
    - *核心*：婴儿通过感觉（看、听）和动作（抓、吸）来“思考”和理解世界。
    - *关键成就*：**客体永久性 (Object Permanence)**，即理解物体在看不见时依然存在。
    - *局限*：**A-not-B错误** 。婴儿会重复在A处（而非B处）寻找被藏匿的物体，即使他们看到了物体被移到了B处，这表明他们的客体概念尚不成熟。
- **前运算阶段 (Preoperational Stage) (2-7岁)**：
    - *核心*：**象征性思维 (Symbolic Thought)** 出现，最明显的表现是语言和**假装游戏 (Pretend Play)** 。
    - *核心局限*：
        - **自我中心主义 (Egocentrism)**：无法从他人的视角看问题（如“三山实验”所证实的）。
        - **缺乏守恒 (Lack of Conservation)**：无法理解物体的核心属性（如数量、液体体积、质量）在外观（如容器形状）改变时保持不变 。
        - *守恒失败的原因*：**集中化 (Centration)**（只关注一个维度，如高度）和**不可逆性 (Irreversibility)**（无法在心理上逆转操作）。
- **具体运算阶段 (Concrete-Operational Stage) (7-11岁)**：
    - *核心*：儿童获得了**认知运算 (Cognitive Operations)**，能够进行逻辑推理，但仅限于“具体的”事物和情境 。
    - *关键成就*：
        - **守恒 (Conservation)**：通过掌握**去集中 (Decentration)** 和**可逆性 (Reversibility)** 来解决守恒问题 。
        - **关系逻辑 (Relational Logic)**：包括**心理序列 (Mental Seriation)**（按高低排序）和**传递性 (Transitivity)**（如果A>B, B>C, 那么A>C）。
- **形式运算阶段 (Formal-Operational Stage) (11岁+)**：
    - *核心*：能够进行抽象的、假设的和演绎的思维 。
    - *关键成就*：**假设演绎推理 (Hypothetico-Deductive Reasoning)**，即能像科学家一样，从一般理论出发，系统性地检验所有可能的假设 。

### **7.2 维果茨基的社会文化观**

维果茨基提供了与皮亚杰（强调个体建构）截然不同的视角，强调社会和文化（社会建构）的决定性作用 。

- **核心概念**：
    - **最近发展区 (Zone of Proximal Development, ZPD)**：这是维果茨基理论的基石。它指的是介于“儿童能独立完成的任务”和“必须在更有经验者指导下才能完成的任务”之间的区域 。
    - **支架 (Scaffolding)**：专家（如父母或老师）在 ZPD 内部提供恰当的指导，并随着学习者能力的提高而逐渐撤去支持 。
    - **引导参与 (Guided Participation)**：儿童通过参与日常的、有意义的文化活动（如与父母一起做饭）来学习和掌握技能。
- **语言与思维的关系**：
    - 皮亚杰认为“自我中心语”是认知不成熟的标志，会自行消失。
    - 维果茨基认为**私语 (Private Speech)**（即皮亚杰的自我中心语）是儿童用来指导自己思维和行为的关键工具（“认知自我指导系统”）。这种出声的自我对话最终会内化为无声的**内部言语 (Inner Speech)**，即思想。

### **7.3 理论对比：发展与学习**

皮亚杰和维果茨基在“学习与发展的关系”上存在根本分歧 。

- 对于**皮亚杰**，发展 *先于* 学习。儿童必须首先达到某个认知阶段（如具体运算），才能学习该阶段的逻辑（如守恒）。
- 对于**维果茨基**，学习（在ZPD内的社会互动）*驱动* 发展 。

这种“个体建构”与“社会建构”的对立 ，直接导致了截然不同的教育应用：皮亚杰式的课堂强调**发现式学习 (discovery-based learning)** ，让儿童自己探索；而维果茨基式的课堂则强调**引导式学习 (guided learning)** 和**合作学习 (cooperative learning)** ，教师和同伴通过“支架”来推动学生前进。

## **第8章：认知发展：信息加工的观点**

本章将认知发展比作计算机系统的升级，关注的是认知过程（“软件”）和神经结构（“硬件”）的连续性改进。

### **8.1 多重存储模型**

该模型将人类认知系统分为三个部分：

15. **感觉存储 (Sensory Store)**：短暂（<1秒）保留原始感觉信息。
16. **短时/工作记忆 (Short-Term / Working Memory)**：是信息的“加工车间”，容量有限（约7±2个组块）。
17. **长时记忆 (Long-Term Store)**：容量无限的永久知识库。

### **8.2 “硬件”与“软件”的发展**

认知发展被视为“硬件”（生物成熟）和“软件”（策略习得）的共同进步：

- **硬件 (Hardware) 的发展**：
    - *加工速度 (Processing Speed)*：随年龄增长（可能与大脑髓鞘化有关）而加快。
    - *工作记忆容量 (Working Memory Capacity)*：随年龄增长而增加。
- **软件 (Software) 的发展**：
    - *策略 (Strategies)*：儿童学会使用更有效的策略来编码和检索信息。
    - **元认知 (Metacognition)**：“对思考的思考”，即个体对自己认知过程的认识和监控能力，这是策略有效运用的前提 。

### **8.3 注意力的发展**

儿童的注意力随年龄增长变得更具计划性、适应性和**选择性 (Selective Attention)** 。一个关键的进步是**认知抑制 (Cognitive Inhibition)** 能力的增强，即忽略无关刺激、抑制不当反应的能力 。

### **8.4 记忆的发展**

- **事件与自传体记忆 (Event and Autobiographical Memory)**：
    - 儿童通过形成**脚本 (Scripts)**（对日常事件的抽象化表征）来组织事件记忆。
    - **婴儿期遗忘 (Infantile Amnesia)**  指我们无法回忆起生命最初几年的事情，这可能因为早期的记忆是非语言编码的，或缺乏成熟的自我概念。
- **儿童作为目击证人**：研究表明，学龄前儿童的记忆尤其容易受到暗示性问题和误导信息的影响 。
- **策略性记忆 (Strategic Memory)**：
    - 儿童逐渐掌握**复述 (Rehearsal)**、**组织 (Organization)**（归类）和**精细加工 (Elaboration)**（在条目间建立联系）等记忆策略。
    - *策略发展缺陷*：
        - *产生缺陷 (Production Deficiency)*：儿童不会自发产生策略，但如果被教导使用，他们是能够使用的。
        - *利用缺陷 (Utilization Deficiency)*：儿童自发产生了策略，但使用效果不佳（可能是因为使用策略耗费了过多的认知资源）。

### **8.5 算术技能**

Siegler 提出了**适应性策略选择模型 (Adaptive Strategy Choice Model)** ，指出儿童在解决算术问题时，会根据问题的难度灵活地从多种策略（如数手指、心算、从已知事实推断）中选择最有效的一种。

## **第9章：智力：测量心理表现**




**9.1 什么是智力？**

• **心理测量观 (Psychometric Views)**：1
    ◦ *Spearman*：提出智力包含一个**g 因素 (general intelligence)**（一般智力）和多个 s 因素（特殊能力）20。
    ◦ *Cattell & Horn*：将 $g$ 因素细分为：21
        ▪ **流体智力 (Fluid Intelligence, Gf)**：先天的、解决新问题的能力，依赖于信息加工速度；成年后随年龄增长而下降 20。
        ▪ **晶体智力 (Crystallized Intelligence, Gc)**：后天习得的知识、技能和经验（如词汇量）；随年龄增长而持续积累 23。
• **现代观点**：
    ◦ **斯腾伯格 (Sternberg) 的三元理论 (Triarchic Theory)**：认为智力是多方面的，包括：1
        1. *分析性智力 (Analytical)*：“书本智慧”，用于解决学术问题 26。
        2. *创造性智力 (Creative)*：应对新颖任务、产生新想法的能力 27。
        3. *实践性智力 (Practical)*：“街头智慧”，适应现实环境、解决日常问题的能力 27。
    ◦ **加德纳 (Gardner) 的多元智能理论 (Multiple Intelligences)**：认为智力不是单一的，而是由至少8种（或9种）独立的智能构成，如语言、逻辑-数学、空间、音乐、身体-动觉、人际、内省和自然主义者 1。
**
9.2 智力如何测量？**

• 现代IQ测验（如韦氏量表）采用**离差IQ (Deviation IQ)**，将个人得分与其同龄常模群体的平均分（定为100）和标准差（定为15）进行比较 1。
• 婴儿智力（如Bayley量表）测量的是感知和动作技能，与儿童期的IQ相关性很低 1。
**
9.3 影响IQ分数的因素**

• **遗传 (Heredity)**：双生子和收养研究表明，遗传为智力设定了一个**反应范围 (range of reaction)** 1。
• **环境 (Environment)**：
    ◦ **HOME量表 (Home Observation for Measurement of the Environment)** 是一种测量家庭环境（如父母的情感回应、提供的玩教具、学业刺激）的工具 31。
    ◦ 研究一致发现，高质量的HOME环境与儿童的高IQ显著相关 33。
• **群体差异与偏见**：1
    ◦ 尽管存在社会阶层和种族的平均IQ分数差异，但这些差异很大程度上可以用环境假说（如贫困、营养、教育机会不均等）来解释。
    ◦ **文化/测验偏见假说 (Cultural/Test-Bias Hypothesis)** 认为IQ测验的内容偏向主流文化 1。
    ◦ **刻板印象威胁 (Stereotype Threat)** 1 指出，当少数群体成员意识到自己正处于可能证实（关于自己群体）负面刻板印象的情境中时，所感受到的额外压力会损害其测验表现。
**
9.4 提高认知表现**

**补偿性教育 (Compensatory Education)**（如“启智计划 Head Start”）旨在为处境不利的儿童提供早期干预。长期追踪研究表明，这些计划在提高毕业率、减少留级和犯罪率方面具有显著的长期效益。成功的关键在于**早期干预**和**父母参与** 1。

## **第10章：语言和沟通技能的发展**



**
10.1 语言的五个成分**

语言是一个复杂的系统，包含五个子系统：1
1. **音系 (Phonology)**：语言的语音系统（如何组合音素 $phonemes$）36。
2. **形态系 (Morphology)**：词的构成规则（如何使用语素 $morphemes$，即最小意义单位，如 $walk$ + $-ed$）36。
3. **语义系 (Semantics)**：词语和句子的含义 38。
4. **句法 (Syntax)**：将词语组合成合乎语法的句子的规则 35。
5. **语用 (Pragmatics)**：在社会情境中有效使用语言的规则（如轮流对话、讲礼貌）35。
**
10.2 语言发展理论**

关于儿童如何快速掌握这一复杂系统，存在三种主要理论：1
• **学习（经验主义）论 (Learning Perspective)**：
    ◦ *代表*：**斯金纳 (Skinner)** 40。
    ◦ *观点*：语言是通过模仿和操作性条件反射（父母对“正确”发音的强化）习得的 41。
    ◦ *批评*：无法解释儿童如何能 *创造* 出他们从未听过的句子（语法的生成性）。
• **先天（天赋）论 (Nativist Perspective)**：
    ◦ *代表*：**乔姆斯基 (Chomsky)** 40。
    ◦ *观点*：人类天生具备学习语言的生物准备。
    ◦ *机制*：拥有一个假想的**语言习得装置 (Language Acquisition Device, LAD)**，其中包含“普遍语法 (Universal Grammar)” 40。
    ◦ *支持*：语言发展的普遍阶段性；**关键期 (Critical Period)** 假说（如Grasping语言的案例）1。
• **互动论 (Interactionist Perspective)**：
    ◦ *观点*：承认生物准备（天性），但强调语言发展是认知发展和社会互动（教养）共同作用的结果 43。
    ◦ *机制*：发展有赖于丰富的语言环境，特别是成人使用的**儿童导向言语 (Child-Directed Speech)**（也称“妈妈语”，motherese），其特点是语调高、句子简单、夸张 1。
**
10.3 语言发展的里程碑**

儿童的语言发展遵循一个可预测的顺序：1
• **语言前阶段 (The Prelinguistic Period)**：
    ◦ *咕咕声 (Cooing)*（约2个月）：发出元音（如 "oooooh"）。
    ◦ *牙牙学语 (Babbling)*（约6个月）：发出辅音+元音的组合（如 "bababa"）46。
• **单词句阶段 (The Holophrase Period) (约1-1.5岁)**：
    ◦ *特点*：用单个词 (Holophrase) 表达完整句子的意思（如说 "Ball" 可能意为 "I want the ball"）。
    ◦ **词汇爆发 (Vocabulary Spurt)**：约18个月时词汇量迅速增长 45。
• **电报句阶段 (The Telegraphic Period) (约1.5-2.5岁)**：
    ◦ *特点*：说出由2-3个高信息量词组成的短句，省略功能词（如 "Want milk", "Daddy eat"），如同发电报 45。
• **学龄前及中期 (Preschool Period and Middle Childhood)**：
    ◦ 儿童开始掌握语法语素（如复数 $s$, 过去式 $ed$），常伴随**过度规则化 (Overregularization)**（如 "goed", "foots"），这反而证明了他们是在学习 *规则*，而不只是模仿。
    ◦ **元语言意识 (Metalinguistic Awareness)**（即对语言本身的反思能力）增强 1。

## **第四部分：社会性与人格发展 (PART IV: SOCIAL AND PERSONALITY DEVELOPMENT)**

## **第11章：情绪发展、气质与依恋**

本章探讨了儿童社会性和人格的三个基石：情绪的表达与理解、天生的气质差异，以及与照料者的早期情感联结。

### **11.1 情绪发展**

- **情绪表达**：
    - **基本情绪 (Basic Emotions)**：在婴儿早期出现，被认为是天生的（如兴趣、喜悦、悲伤、愤怒、恐惧）。
    - **复杂（自我意识）情绪 (Complex/Self-Conscious Emotions)**：在1.5-2岁出现，需要自我意识（见第12章）和对规则的理解（如尴尬、骄傲、内疚、羞耻）。
- **情绪调节 (Emotional Regulation)**：指管理和控制情绪表达的能力。婴儿期严重依赖外部调节（如父母的安抚）；儿童期发展出更多的内部策略 。

### **11.2 气质与发展**

- **气质 (Temperament)**：个体在反应性（情绪、活动水平）和自我调节方面，具有生物基础的、相对稳定的早期倾向 。
- **气质类型 (Thomas & Chess)**：
    - **容易型 (Easy Child)** (40%)：节律性好，适应性强，情绪积极。
    - **困难型 (Difficult Child)** (10%)：节律性差，适应慢，情绪消极且强烈。
    - **慢热型 (Slow-to-warm-up Child)** (15%)：活动水平低，适应慢，情绪轻微消极。
- **拟合优度 (Goodness of Fit)**： 这一概念至关重要。它强调，发展结果*不*是由气质单独决定的，而是由孩子的气质与父母的养育方式（环境要求）相匹配的程度决定的。例如，困难气质的孩子如果遇到耐心、包容的父母，发展结果会比遇到急躁、严厉的父母要好得多。

### **11.3 依恋与发展**

**依恋 (Attachment)** 是指婴儿与主要照料者之间形成的强烈、持久的情感联结 。

- **依恋理论**：
    - **Bowlby 的行为生态学理论**： 依恋是一种生物预设的适应性行为，确保婴儿得到保护和照料。
    - **Ainsworth 的研究**：
        - *安全基地 (Secure Base)*：照料者是婴儿探索环境的“安全基地”。
        - **陌生情境 (Strange Situation) 程序**：一套标准化的实验室程序，通过观察婴儿在分离和重聚时的行为来评估依恋质量 。
- **依恋类型 (Attachment Quality)**：
    1. **安全型 (Secure Attachment)** (60-65%)：母亲在场时积极探索，分离时苦恼，重聚时主动寻求安慰且易被安抚。
    2. **回避型 (Avoidant Attachment)** (20%)：对母亲分离无动于衷，重聚时回避或忽视母亲。
    3. **反抗/矛盾型 (Resistant/Ambivalent Attachment)** (10-15%)：分离时极度苦恼，重聚时寻求接触但又表现出反抗（如推开、踢打）。
    4. **混乱型 (Disorganized/Disoriented Attachment)** (5-15%)：表现出混乱、矛盾的行为（如呆滞、恐惧），这是后期发展问题（如攻击性）的最强预测指标 。
- **影响依恋的因素**：
    - **照料假说 (Caregiving Hypothesis)**：Ainsworth 认为，依恋质量主要取决于照料者的**敏感性 (Sensitivity)**（即能否及时、恰当地回应婴儿的需求）。
    - *气质的影响*：困难气质本身不 *决定* 依恋不安全，但它使父母提供敏感照料变得更加困难 。
- **依恋与后期发展**：
    - **内部工作模型 (Internal Working Models)**：早期依恋形成了关于自我（“我是否值得被爱？”）和他人（“他人是否可信？”）的心理表征，这将影响未来的社交关系和自尊 。

## **第12章：自我与社会认知的发展**

本章探讨了儿童如何发展出对“自我”的认识，以及如何理解他人的思想和感受（社会认知）。

### **12.1 自我概念的发展**

**自我概念 (Self-Concept)** 是个体对自己独特属性的感知 。

- **婴儿期**：
    - *自我分化 (Self-Differentiation)*：婴儿早期开始区分自我与他人。
    - **自我识别 (Self-Recognition)**：约18-24个月出现，标志是婴儿能在镜子或照片中认出自己（如“点红测试”）。
- **发展趋势**：
    - *学龄前儿童 (3-5岁)*：自我概念是**具体的、物理的**（"我跑得快"、"我有棕色头发"）。
    - *儿童中期 (8-11岁)*：自我概念转向**心理特质**（"我很诚实"）和**社会比较 (Social Comparison)**（"我比别人更擅长数学"）。
    - *青春期*：自我概念变得**抽象、分化**（认识到自己在不同情境下可能不同）和**整合**。

### **12.2 自尊：自我的评价成分**

**自尊 (Self-Esteem)** 是对自我价值的评价 。

- **社会贡献者**：
    - *父母*：**权威型 (Authoritative)** 养育方式（高温暖、高控制，见第15章）与儿童的高自尊显著相关 。
    - *同伴*：同伴接纳和社会比较是自尊的重要来源。

### **12.3 成就动机与归因**

- **成就动机 (Achievement Motivation)**：努力掌握挑战、追求卓越的倾向 。
- **成就归因 (Achievement Attributions)**：个体对成功和失败原因的解释，这比动机本身更能预测未来的努力 。
- **两种归因取向 (Dweck)**：
    1. **能力实体观 (Entity View)**：认为能力是固定的（“我聪明/我笨”）。当面临失败时，倾向于将其归因于内部-稳定因素（我笨），导致**习得性无助 (Learned Helplessness)**（即放弃努力）。
    2. **能力增长观 (Incremental View)**：认为能力是可以通过努力提高的。当面临失败时，倾向于将其归因于内部-不稳定因素（我努力不够），从而保持坚持性。

### **12.4 形成认同感**

根据埃里克森的理论，形成**认同感 (Identity)** 是青春期的核心危机。James Marcia 基于“探索 (Exploration)”和“承诺 (Commitment)”两个维度，提出了四种**认同状态 (Identity Statuses)**：

18. **认同达成 (Identity Achievement)**：（探索 + 承诺）经历过危机，已做出承诺。
19. **认同延缓 (Identity Moratorium)**：（探索 + 未承诺）正在危机中积极探索。
20. **认同早闭 (Identity Foreclosure)**：（未探索 + 承诺）未经探索就接受了他人（通常是父母）设定的承诺。
21. **认同弥散 (Identity Diffusion)**：（未探索 + 未承诺）既不探索也不承诺，感到迷茫。

### **12.5 认识他人：社会认知**

**社会认知 (Social Cognition)** 是指对他人思想、情感、动机和行为的理解。

- **心理理论 (Theory of Mind, ToM)**：
    - *定义*：理解他人拥有信念、愿望、意图等心理状态，且这些状态可能与自己不同，并驱动行为。
    - *测量*：经典方法是**错误信念任务 (False-Belief Task)**。在3-4岁时，儿童开始理解他人可能持有并根据“错误”的信念行事（如“Sally-Anne”任务，儿童理解 Sally 会去她 *认为* 弹珠在的地方，而不是弹珠 *实际* 在的地方）。

## **第13章：性别差异与性别角色发展**

本章探讨了生物、社会和认知因素如何共同作用，塑造了我们的性别认同和行为。

### **13.1 定义**

- **性 (Sex)**：生物学上的男性或女性 。
- **性别 (Gender)**：与男性气质 (masculinity) 和女性气质 (femininity) 相关的社会、文化和心理含义 。
- **性别角色标准 (Gender-Role Standards)**：社会认为适合不同性别的行为、价值观或动机 。
    - *工具性 (Instrumental) 角色*：（传统男性）如自信、独立、主导 。
    - *表达性 (Expressive) 角色*：（传统女性）如养育、合作、敏感 。
- **性别分型 (Gender Typing)**：儿童获得与其性别相适应的动机、价值观和行为的过程 。

### **13.2 性别差异的事实与虚构**

- **文化迷思 (Cultural Myths)**：大多数性别刻板印象（如女性话更多、男性更理性）在研究中并未得到证实，或者差异极小 。
- **实际的心理差异**：
    - *言语能力*：女性平均略占优势。
    - *空间能力*：男性平均略占优势（尤其是在心理旋转任务上）。
    - *攻击性*：男性在**外显攻击 (Overt Aggression)**（身体和言语）上更强；而研究发现，女性更倾向于使用**关系性攻击 (Relational Aggression)**（通过操纵社会关系、散布谣言来伤害他人）。

### **13.3 性别分型的发展**

- **性别隔离 (Gender Segregation)**： 约从3岁开始，儿童强烈偏好与同性玩伴玩耍。这是一种跨文化普遍存在的现象，并会强化性别刻板印象。
- **刻板印象的灵活性**：3-7岁的儿童对性别角色的看法非常**刻板 (rigid)**（如认为男孩不能玩娃娃）；到8-9岁后，随着认知发展，他们逐渐变得**灵活 (flexible)** 。

### **13.4 性别分型理论**

关于儿童如何习得性别角色，存在几种核心理论：

22. **生物社会理论 (Biosocial Theory) (Money & Ehrhardt)**：强调产前激素（如雄激素）对大脑的组织作用，以及出生后社会标签的共同作用 。
23. **社会学习理论 (Social Learning Theory)**：认为性别分型是通过**直接教导**（父母强化“性别适当”行为）和**观察学习**（模仿电视、父母等同性榜样）习得的 。
24. **认知发展理论 (Cognitive-Developmental Theory) (Kohlberg)**：
    - *核心*：*认知先于行为*。儿童必须首先在认知上理解**性别恒常性 (Gender Constancy)**（即性别是永久不变的，约5-7岁）， *然后* 才会主动模仿同性榜样以保持认知一致 。
25. **性别图式理论 (Gender Schema Theory) (Martin & Halverson)**：
    - *核心*：结合了认知和社会学习。一旦儿童获得“基本性别认同”（2-3岁，*早于* 性别恒常性），他们就会构建“性别图式 (gender schemas)”（即关于男性和女性的心理蓝图）。
    - *机制*：这些图式像过滤器一样，引导儿童主动关注、寻找和记忆与自己性别一致的信息，而忽略不一致的信息 。

### **13.5 心理双性化**

**心理双性化 (Psychological Androgyny)** 是指个体同时具备高水平的“工具性”（男性化）和“表达性”（女性化）特质。研究表明，双性化个体（尤其是女性）在心理上更健康、适应性更强，因为他们拥有更灵活的行为库 。

## **第14章：攻击、利他与道德发展**

本章探讨了社会与人格发展中具有强烈道德色彩的三个主题：攻击、利他以及道德推理。

### **14.1 攻击的发展**

**攻击 (Aggression)** 是指意图伤害他人的行为 。

- **攻击类型**：
    - **工具性攻击 (Instrumental Aggression)**：“冷”攻击。为了达到某个目标（如抢玩具）而伤害他人，在学龄前儿童中非常常见 。
    - **敌意性攻击 (Hostile Aggression)**：“热”攻击。以伤害他人为主要目的，通常由愤怒驱动 。
- **发展趋势**：幼儿期，身体攻击（工具性）减少，而言语攻击增多。敌意性攻击在儿童中期有所上升 。
- **攻击的来源**：
    - **强制性家庭环境 (Coercive Home Environments)**：Patterson 的研究发现，攻击性儿童的家庭常陷入一种消极强化的循环（如孩子哭闹→父母屈服→孩子哭闹行为被强化）。
    - **社会信息加工理论 (Dodge)**：攻击性强的儿童在解释模糊的社会线索时，存在**敌意归因偏见 (Hostile Attribution Bias)**，即倾向于将他人的中性行为（如意外碰撞）解释为故意的敌意 。

### **14.2 利他：亲社会自我的发展**

**利他 (Altruism)** 是指不期待外在回报的、对他人福利的关心和行动（如分享、帮助）。

- **发展**：利他行为随年龄增长而增加，这与**共情 (Empathy)**（理解和体验他人情绪的能力）的发展密切相关 。
- **培养**：父母的**情感解释 (Affective Explanations)**（即向孩子解释其行为对他人的情感后果，如“你抢了玩具，他很难过”）是培养利他行为的有效方式 。

### **14.3 道德发展**

道德发展是一个包含情感、认知和行为三个成分的复杂过程 。

- **认知成分 (Cognitive Component)**：关注道德 *推理* 的发展。
    - **皮亚杰的理论 (Piaget's Theory)**：
        - **他律道德 (Heteronomous Morality)** (约5-10岁)：规则是绝对的、不可改变的（来自权威）。判断是非基于“结果”而非“意图”（如认为“意外打碎15个杯子”比“故意打碎1个杯子”更坏）。
        - **自律道德 (Autonomous Morality)** (约10岁+)：规则是社会协商的产物，可以改变。判断是非时会考虑“意图” 。
    - **科尔伯格的理论 (Kohlberg's Theory)**：
        - *核心*：通过“海因茨偷药”等道德两难故事评估个体的道德 *推理* 水平。
        - *三水平六阶段*：
            - **水平一：前习俗 (Preconventional)**： 规则是外在的，服从是为了避免惩罚（阶段1）或获得回报（阶段2）。
            - **水平二：习俗 (Conventional)**： 服从社会规则和规范，以寻求他人认可（阶段3：“好孩子”）或维持社会秩序（阶段4：法律与秩序）。
            - **水平三：后习俗 (Postconventional)**： 道德基于抽象的原则和个人伦理。包括社会契约（阶段5）和普遍伦理原则（阶段6）。
        - *批评*：Carol Gilligan 批评 Kohlberg 的理论存在性别偏见，忽视了基于“关怀 (Care)”的道德（多见于女性），而过分强调基于“正义 (Justice)”的道德（多见于男性）。
- **行为成分 (Behavioral Component)**：
    - 关注实际的道德行为（如抑制违规行为）。社会学习理论认为，有效的惩罚（及时、一致、伴随解释）有助于儿童内化道德规范 。

## **第五部分：发展的背景 (PART V: THE CONTEXT OF DEVELOPMENT)**

## **第15章：发展的背景**

本章是全书（特别是第2章）生态系统理论的实证总结。它展示了发展 *不是* 在真空中发生的，而是由多个微观系统（家庭、同伴、学校、媒体）共同塑造的 。

### **15.1 父母的社会化：养育方式**

Diana Baumrind 根据两个维度（接纳/反应性 和 要求/控制）划分了四种养育方式 。

26. **权威型 (Authoritative)**：**（高接纳 + 高控制）**。高温暖、高控制，但坚定地执行规则，解释规则，尊重孩子的独立性。
    - *结果*：**最佳发展结果**。儿童具有高自尊、高成就动机（见第12章）、高社交能力、自控力强 。
27. **专制型 (Authoritarian)**：**（低接纳 + 高控制）**。低温暖，高压，要求绝对服从（"因为我说了算"）。
    - *结果*：儿童焦虑、退缩、缺乏自信、社交能力差。
28. **放纵型 (Permissive / Indulgent)**：**（高接纳 + 低控制）**。高温暖，但几乎没有规则或控制，过于放任。
    - *结果*：儿童不成熟、冲动、难以控制行为、学业成就低。
29. **忽视型 (Uninvolved / Neglectful)**：**（低接纳 + 低控制）**。父母冷漠、不投入，最糟糕的养育方式。
    - *结果*：**最差发展结果**。儿童在各方面都存在问题，包括依恋问题、反社会行为。

### **15.2 同伴作为社会化动因**

- **游戏的发展**：儿童的游戏随年龄增长，社交复杂性增加，从**平行游戏 (Parallel Play)**（彼此相邻但独立玩耍）发展到**联想游戏 (Associative Play)** 和**合作游戏 (Cooperative Play)** 。
- **同伴接纳与地位**：
    - *受欢迎 (Popular)*：社交能力强，亲社会。
    - *被拒绝 (Rejected)*：分为**被拒绝-攻击型 (Rejected-Aggressive)**（具有高攻击性、破坏性）和**被拒绝-退缩型 (Rejected-Withdrawn)**（社交焦虑、害羞）。
    - *被忽视 (Neglected)*：低调，不被注意，但适应良好。
    - *霸凌 (Bullying)*：通常涉及被拒绝-攻击型儿童（霸凌者）和被拒绝-退缩型儿童（受害者）。

### **15.3 学校作为社会化动因**

- **有效学校 (Effective Schooling)**：决定因素包括积极的课堂管理、学业重点、教师的温暖与支持，以及学生之间的合作氛围 。
- **学校转型**：从小学升入初中（尤其是在青春期早期）对许多学生是困难的，可能导致自尊和学业成绩的暂时下降 。

### **15.4 媒体对发展的影响**

- **电视 (Television)**：
    - *暴力与攻击性*：大量相关和实验研究证实，观看暴力电视 *确实* 会增加儿童的攻击性，其机制包括观察学习、去抑制和去敏感化 。
    - *积极影响*：教育性电视（如《芝麻街》）能促进学龄前儿童的认知技能（如字母和数字）和亲社会行为 。
- **计算机 (Computers)**：
    - *益处*：计算机辅助教学、互联网获取信息 。
    - *担忧*：接触暴力视频游戏（其对攻击性的影响可能比电视更强）、色情内容和网络霸凌 。

### **15.5 发展的背景总结**

本章清晰地表明，发展背景不是孤立的。一个来自“权威型”家庭（微观系统1） 的孩子，在“有效”的学校（微观系统2） 中，并且与亲社会的同伴（微观系统3） 交往，其发展结果是乘数效应。相反，一个来自“忽视型”家庭（微观系统4） 的孩子，在混乱的学校中，与“被拒绝-攻击型”同伴为伍（霸凌），并且大量消费暴力媒体（微观系统5），其反社会行为的风险也会呈指数级增长。发展的背景是动态且相互作用的 。
