我以产品管理为职业，一直以来都是行为经济学的忠实粉丝，《原子习惯》也是我最喜欢的书之一，所以我注定会喜欢这本书。它在现有理论的基础上，作者的贡献在于提出了几个易于遵循的框架，将行为改变原则应用于产品管理。考虑到大多数产品成果都依赖于改变人们的行为，这对于任何从事产品构建的人来说都是一本值得一读的书。

# 第一部分：大脑的运作机制

## 一、第一章：决策与行动

### 1.1 人类为何难以付诸行动？

- 人们在将意图转化为行动的过程中常常困难重重。人们有时难以做出正确决定。**问题不在于动机，而在于执行。**
- **想要改变行为，首先必须改变行为本身。**
- 行为科学结合心理学与经济学，**旨在理解人们如何做出决策，并将这些决策转化为实际行动。**
- “选择架构”或“行为设计”是一种通过**设计环境来影响我们选择与行为**的方式。
- 推荐书籍：
    - 《助推》（Nudge）：理查德·塞勒（Richard Thaler）和卡斯·桑斯坦（Cass Sunstein）
    - 《思考，快与慢》（Thinking, Fast and Slow）：丹尼尔·卡尼曼（Daniel Kahneman）
    - 《怪诞行为学》（Predictably Irrational）：丹·艾瑞里（Dan Ariely）

### 1.2 我们的大脑是如何运作的？

### 1.2.1 注意力、时间与意志力有限

- 我们的注意力资源是有限的：
    - 我们一次只能专注于一件事情
    - 选项过多会让我们陷入瘫痪（“选择悖论”）
    - 我们的记忆会出现偏差

### 1.2.2 大脑依赖“捷径”来简化复杂

- 因为大脑的运作效率需求，我们发展出两套系统来应对不同类型的决策：
    - **系统1：快速、直觉式、情绪驱动的系统**
        - 形成情绪与“直觉反应”
        - 在熟悉场景中非常有效
        - **主导我们大部分日常行为**
    - **系统2：慢速、专注、自觉的理性系统**
        - 在陌生情境中进行分析
        - 用于处理复杂问题
        - **信息处理能力有限**
        - 常常以为自己在“掌控一切”
- **两个系统可以并行运行，彼此独立，甚至发生冲突。**

### 1.2.3 情境对行为的决定性影响

- 我们的决策和行为深受当下情境影响：
    - 情境可能加剧或缓解我们的偏见
    - 情境也决定我们是否能将“意图”落实为“行动”
- **通过优化情境，我们可以更好地做决策，并缩小“意图-行动”之间的鸿沟。**

### 1.3 常见偏误与启发法（Heuristics）

| 偏差类型 | 描述 |
| --- | --- |
| **现状偏误**（Status quo bias） | 一般人倾向于维持现状，不愿做出改变 |
| **描述性规范**（Descriptive norms） | 我们倾向于**模仿他人**的行为 |
| **确认偏误**（Confirmation bias） | **我们会寻求与既有观点一致的信息**，忽视相反证据 |
| **即时偏误**（Present bias） | **我们过于看重眼前的利益，而忽视未来的回报** |
| **锚定效应**（Anchoring） | 我们做出判断时，**容易被最初的参考信息所影响** |
| **可得性启发**（Availability heuristic） | **我们倾向于认为近期发生或容易想起的事件更可能发生** |
| **宜家效应**（IKEA effect） | 当我们为某物投入时间精力后，**更倾向于高估它的价值** |
| **光环效应**（Halo effect） | **若某人在某一方面表现优秀，我们倾向于在其他方面也做出正面评价** |

## 二、习惯的力量

### 2.1 习惯的形成机制

- **习惯是一种对环境中“线索”做出反应的重复性行为。**
- 习惯是自动化行为，**脱离了有意识的控制。**
- **习惯通过将控制权“外包”给行为线索，从而释放大脑的认知资源。**
- 习惯通过重复建立：看到某个线索（X），我们就执行某个行为（Y）。
- 大脑会将“线索-行为”之间建立强关联 → 无需思考，直接执行。
- **若行为有奖励（包括随机奖励），潜意识会进一步强化这条路径。**

### 2.2 好习惯的关键

- 好习惯是可持续、稳定、低意志力消耗的行为系统。
- **持续的好习惯构成了长期成功的基石。**

## 三、环境决定我们行为的上下文

### 3.1 情境如何影响选择？

- 决策框架（Framing）会深刻影响选择：
    - 避免不确定性
    - 情绪预期失准（如我们通常高估未来痛苦）
    - 行为预期失准（我们对未来自己的行为预测不准）
- **例如，问人们他们将来会做什么，或认为他们将来会做什么，是极不可靠的。**
- 判断得失依赖“参考点”：是损失还是收益，影响我们选择。
- **环境会塑造行为。通过重新设计环境，我们可以改变人们的决策方式。**
    - **我们可以帮助人们做出更好的决定、明智地利用习惯，并真正落实行动意图。**

### 3.2 心智捷径：好用但不完美

- **心智捷径（Heuristics）是我们用来快速做出“合理”选择的工具。**
    - 如：社会证明、可得性启发、信号启发等
- 偏见并不一定是负面的，**它只是我们思考的固有方式之一。**
- **最终目标：帮助人们在有限信息下做出更好的决策。**

### 3.3 行动机制的缺陷

- 行动失败既可能源于“不作为”，也可能是“错误的执行”：
    - **“意图—行动”鸿沟是行动失败的核心原因之一。**
    - 光有意图与动机远远不够。
- **坏习惯和好习惯一样，都是通过重复习得的。**

## 四、大脑选择正确行动的“工具箱”

### 4.1 不同情境下的策略选择

| 工具类型 | 应用情境 |
| --- | --- |
| **习惯（Habits）** | 熟悉的线索会自动触发例行行为 |
| **直觉反应（Other intuitive responses）** | 半熟悉场景，基于过往经验快速反应 |
| **主动思维/自我概念（Active mindset / self-concept）** | 情境模糊、有多种解读空间时 |
| **启发法（Heuristics）** | 有意识思考有限，需简化决策时 |
| **专注理性计算（Focused, conscious calculation）** | 情境陌生或重大决策，需集中精力深度思考 |

### 4.2 注意事项

- **这些规则不是绝对的，而是大致适用于大多数情况。**
- 我们只会在有充分理由时才启动深度计算（如重大、不寻常事件）。

## 二、第二章：如何促进行动

### 2.1 人们为何迟迟不行动？

- 每年都有许多符合政府援助资格的学生**并未申请免费资金**
    - 他们声称是不知道自己符合资格（但**人们常常无法解释自己行为背后的真实原因**）
    - 完成申请流程需耗费大量精力，**多达20个步骤** → 造成“认知超载”，学生拖延，直到第二天、第三天……最后放弃
- **“非理性实验室”曾向学生发送短信，提醒申请是注册的一部分，并提示完成时间节点**
    - 结果是原来的3倍学生申请，**如果广泛推广，预计将有额外23万名学生申请**
- **当我们理解人们面临的障碍时，就能帮助他们迈出第一步。**

### 2.2 两种关键工具

### 2.2.1 缩小“意图—行动”鸿沟（我们想做但做不到的事）

- **“CREATE” 框架**：
    - **Cue（线索）**：启动自动化反应的提示，可引发系统1的直觉反应
    - **Reaction（反应）**：下意识的回应
    - **Evaluation（评估）**：系统2的意识判断，权衡利弊
    - **Ability（能力）**：是否有执行所需的技能与资源
    - **Timing（时机）**：是否选择了合适的时间
    - **Experience（经验）**：过往经验如何影响当前行为

### 2.2.2 识别思考不足或无意中的行为

- 很多行为是**无意识习惯或外部干扰下的结果**
- 可以用 CREATE 框架**替代不良习惯**或**阻止错误行为**
    - 例如：删除线索、反应或评估环节
    - 或者移除执行能力
- **产品可以通过多个维度促使我们采取行动**：
    - 让我们注意到“行动”的存在
    - 避免我们对行动产生负面情绪
    - 说服我们意识到“行动有价值”
    - 激励我们“现在就去做”
    - **并让我们相信“我们真的有能力去做这件事”**

### 2.3 线索（Cue）

- 我们不断在思考“下一步做什么”，**我们使用“心理过滤器”来避免被选择淹没**
- **但心理过滤器也让我们只看到一小部分可能性**
- 例如确认偏误决定我们注意哪些线索
- 线索来源：
    - 外部：环境中的提示（如视觉、声音）
    - 内部：与已有联想相关的想法
- 外部线索策略：
    - **将线索置于环境核心位置**
    - **每次略作变化避免“习得性忽略”**
    - **将线索与已有行为模式建立关联**

### 2.4 反应（Reaction）

- 来源于系统1的自动反应：快速、情绪驱动、直觉形成
- 驱动因素：
    - 社会一致性（符合群体认同）
    - 与熟悉事物相似（熟悉偏好效应）
    - 熟悉度越高越喜欢（曝光效应）
    - 经验训练：经典条件反射
- **当下意识产生反应时，会激发情绪和记忆，并与概念联想相关**
    - 若是“习惯反应”，可能自动触发
- 产品启示：
    - **设计时要规避负面反应**
    - 不要问用户为何不行动，**观察他们的行为更重要**
    - **首次使用体验极其关键** → 用户正在形成“使用习惯”

### 2.5 评估（Evaluation）

- 若未被系统1的直觉反应中断，**行为会进入系统2的意识评估阶段**
- 在新颖情境中，用户会启动系统2判断利弊：
    - 该行动是否值得执行？
    - 效益是否大于成本？
- 产品启示：
    - **强调收益**
    - **降低成本**
    - **弱化替代选项**
- **重点是：用户赋予行为和产品的“主观价值”才是关键，而非产品本身的“客观价值”**

### 2.6 能力（Ability）

- 就算经过评估决定要行动，也需思考：**现在是否真的能行动？**
    - 是否现在立刻就能做？
- 能力包括四个维度：
    1. **行动计划**：知道怎么做
    2. **资源**：是否具备必要资源
    3. **技能**：是否拥有执行能力
    4. **自我效能感**：**人们需要相信自己“能成功”，不会“失败出丑”**

### 2.7 时机（Timing）

- 你抓住了注意力，行为也可行且有吸引力，但**何时行动才是关键**
- **我们总可以“以后再做”，所以必须创造“紧迫感”**
    - 外部紧迫感：如报税截止日
    - 内部紧迫感：如无聊、生理节律
- **具体时间点越清晰 → 执行概率越高**
- 一致性原则：事先承诺、公开说出 → 强化执行
- **主动营造合适的行动时机**
- **对准人们自然倾向于行动的时段**
    - **古希腊称其为“Kairos”时机：产品必须在“最佳行动时刻”出现**

### 2.8 经验（Experience）

- **过往经验会在潜意识中建立联想**
    - 决定我们注意什么、如何判断、是否愿意行动
- 产品历史也会影响用户反应
    - **不同人即使面对相同场景，其行为也可能完全不同，因为过往经验不同**
    - 建议产品团队记录用户交互行为史

### 2.9 CREATE 六要素总结

| 阻断行为的机制 | 失败情境 |
| --- | --- |
| Cue | 没注意到 |
| Reaction | 产生负面反应 |
| Evaluation | 成本高于收益 |
| Ability | 无法执行 |
| Timing | 没有紧迫感 |
| Experience | 负面过往经验 |

- **意图—行动鸿沟极大**：即使有10%的人立志要多存钱，真正执行的比例也非常低

### 2.10 每一步都是条件相对的

- **用户是否执行行为，取决于每个阶段是否优于“替代选项”**
    - 每个阶段都存在竞争（线索、选择、注意力）
- 产品建议：
    - **清除分心因素**
    - **用户当前正在做的事，其实是你产品行为的“最大竞争者”**

### 2.11 BJ Fogg 行为模型（注：斯坦福大学行为设计专家）

- 单独提高“动机”或“能力”效果有限
- **促进行动需要三个要素同时满足**：
    1. **动机**：快乐/痛苦、希望/恐惧、接受/拒绝
    2. **能力**：行动的“难易程度”
    3. **触发器**：线索本身
- **动机高 + 能力强时，再引入触发器，行为就发生**
- **行为 = 动机 × 能力 × 触发器（必须同时存在）**

## 三、第三章：阻止负面行为

### 3.1 有意识地设计环境来抑制诱惑（情境性自我控制）

- 故意设计环境来**削弱诱惑来源**，实现行为自控

### 3.2 反向使用 CREATE 模型

- **识别CREATE是如何支持负面行为的**：
    - 线索是什么？为何反应和评估是正面的？
    - 使其具备执行能力的原因？为何“此时此刻”优先完成？
- **制定策略以制造“障碍”**：增加摩擦、移除线索等
- 如果行为已成习惯，需采取额外措施
    - **尤其需关注评估环节是否由意识控制**
- 设置反馈回路 → 检验干预是否有效

### 3.3 运用CREATE来设置“障碍”

- 移除线索：不让其进入视野
- **接近那些不具备该行为习惯（或公开反对）的同伴**
- **避免与实施负面行为的朋友聚在一起**
- **思考行为的后果**
- 改变当下的呈现方式（如手机解锁计时器）
- **提高行为的代价，让其更难完成**
- **加入小摩擦点，让人停顿**
- **强化对真正重要事情的紧迫感（设定截止期限）**
- **冥想有助于排除其他干扰源所带来的紧迫感**

### 3.4 改变已有习惯为何困难？

- **人们对习惯行为的决策并不“有意识”**
- **“想改变行为的意图”与“实际能否改变”之间几乎没有关系**
- 习惯不会真正消失，只是“潜伏”，一旦有触发，会重新启动

### 3.5 产品团队可以如何介入改变用户习惯？

### 3.5.1 注意力（Attention）：避免触发线索

- 线索往往发生在产品之外 → 难以识别
- 例行行为同样发生在产品之外 → 难以真正观察行为动因

### 3.5.2 反应（Reaction）：替换旧例程

- 找出触发点（并设置奖励）
- 当触发点出现时，**引导其进入新行为流程**
- **持续重复新流程，直到其形成习惯**（这被称为“对抗反应训练”）
- 用户也必须“相信改变是可能的”

### 3.5.3 评估（Evaluation）：使用意识干预

- **打断正在进行的旧习惯**，借助意识反思
- **实时反馈**可帮助跳出旧行为模式

### 3.5.4 能力（Ability）：以“替代性行为”覆盖旧行为

- **专注于多做你想要的行为，而不是少做你不想要的行为**

## 四、第四章：行为科学的伦理问题

### 4.1 界定“黑暗模式”（Dark Patterns）

- 黑暗模式指的是：“用户界面设计选择，促使用户在不知情下做出对其有害的决策。”
- 来自网站[deceptive.design](https://deceptive.design/)（注：反欺骗设计社区）归纳的黑暗模式种类：

| 黑暗模式 | 描述 |
| --- | --- |
| **比较阻碍（Comparison Prevention）** | 产品设计模糊不清，使用户难以比较价格或关键特性 |
| **确认偏误操控（Confirmshaming）** | **利用情感操控使用户“羞于”拒绝某行为** |
| **伪装内容（Disguised ads）** | 用户误以为点击的是内容，实则是广告 |
| **虚假稀缺（Fake scarcity）** | 利用“限时”、“限量”信息施压 |
| **伪社交证据（Fake social proof）** | 虚构热度或评论诱导用户信任产品 |
| **紧迫伪装（Fake urgency）** | 制造时间压力让用户赶紧下决定 |
| **强制操作（Forced action）** | **强制用户执行某行为才能继续流程** |
| **难以取消（Hard to cancel）** | **让取消流程复杂、模糊、时间成本高** |
| **隐藏费用（Hidden costs）** | 用户在结算时才发现额外费用 |
| **隐藏订阅（Hidden subscription）** | **悄悄将用户加入自动续订服务** |
| **反复干扰（Nagging）** | 在用户操作过程中反复打断 |
| **人为障碍（Obstruction）** | 故意设置障碍使任务变得复杂 |
| **默认选项（Preselection）** | **默认选中某项，影响用户决策** |
| **偷换概念（Sneaking）** | 掩盖或延迟披露重要交易信息 |
| **误导性措辞（Trick wording）** | 使用复杂或双关语言误导用户 |
| **视觉干扰（Visual interference）** | 隐藏关键信息，或使用不明显设计呈现信息 |

### 4.2 如何对待这些工具？

- **它们既可以用来“帮助”用户，也可以“操纵”用户**
- 行为产品设计是一条危险边界线：
    - **有益设计**：帮助用户做出更好的决策
    - **边缘设计**：追求利润而牺牲系统2理性
    - **成瘾设计**：制造上瘾机制，牺牲用户健康
    - **有害设计**：鼓励用户做出对其不利的行为

### 4.3 若有疑问，请确保“自愿”与“透明”

- **即便在无意中，许多公司也通过“竞争压力”采取了误导性策略**
    - **“在无意中”欺骗用户，依然具有破坏性**
- 不要低估行为设计的力量，甚至好人也会被系统引导
- **我们应当设计环境，使“积极行为”成为“默认选择”**

### 4.4 如何保持伦理？

- 使用“伦理检查清单”反复审视设计意图：
    - 不要让产品上瘾
    - 不要误导用户
    - **要透明！明确告诉用户你在做什么**
- **明确说明哪些选择是自愿的**
    - 产品真的对孩子好吗？你愿意推荐给孩子吗？
    - 陌生人是否会信任这个产品？
- 创建独立评审流程，确保设计公开透明
- **消除“模糊策略” → 使用平实语言明确规则**
- 提高标准：将伦理承诺制度化，对外公开

---

### 4.5 认知偏差回顾：基本归因偏误（Fundamental Attribution Bias）

- **始终假设：我们每个人都不完美，别人也想做好事，只是同样会犯错。**
    - **不要因为别人做错事就否定其人格，而对自己则宽容以待。**

---

### 4.6 为什么这个话题令人不安？

- **我们不愿相信“产品能操控我们”**
- **我们不愿接受“技巧能让我们行动”**
- **当技巧被隐藏时，事后发现自己被操控会更痛苦**

# 第二部分：行为改变的实施蓝图

## 五、第五章：流程总结

### 5.1 “四个D”步骤框架

- **定义问题与商业背景**
- **诊断现状与可变革机会**
- **设计与测试行为改变的解决方案**
- **决定是否扩大应用规模并全面实施**
- **干预措施往往难以立即奏效（这是本质难点），因此我们必须采取“迭代式”方法。**

### 5.2 在产品与传播中如何做出“正确干预”决策？

| 步骤 | 行动/输出成果 |
| --- | --- |
| **定义问题** | 项目说明书；行为改变假设（行为者、行为、结果） |
| **探索情境** | 详细的行为地图；识别问题的过程诊断 |
| **制定干预措施** | 干预本身（如新界面、流程、提示等） |
| **产品内实施** | 伦理审查；嵌入至产品流程 |
| **衡量效果** | 影响评估 |
| **评估后续行动** | 洞察与优先级梳理 |

### 5.3 核心提示

- **本流程本质上是“常识 + 科学方法”的结合**

### 5.4 每一步的具体说明

### 定义问题：

- 明确你要与谁合作（行为者）
- 明确他们试图达成什么目标（结果）
- 明确你将如何引导该行为（行动）

### 探索情境：

- 深入了解用户所处的环境与使用场景
- 将你的初步行动计划与用户实际情况对齐

### 制定干预措施：

- 设计新屏幕、功能、提示、内容等以帮助用户克服阻碍

### 产品内实施：

- 将干预措施嵌入产品中，并结合行为追踪与评估机制

### 衡量影响：

- 通过观察用户反应来判断干预是否生效

### 评估下一步：

- **识别进一步提升干预效果的方式，并评估其必要性与优先级**

## 六、第六章：定义问题

### 6.1 明确问题的三个核心维度

- **目标结果（Outcome）**：
    - 产品应实现什么？它成功时，现实世界应有哪些变化？
- **目标行为者（Actor）**：
    - 我们希望谁使用产品？他们将如何完成目标结果？
- **目标行为（Action）**：
    - 用户会实际做出怎样的行为来达成结果？

### 6.2 从产品愿景出发

- 提问以明确目标结果：
    - 产品成功后，世界会有什么不同？
    - 哪个具体且可观测的变化将出现？
    - 第三方能看到、听到或感受到什么变化？
    - **现实世界中，哪件重要的事情因你的产品而改变？**

### 6.3 使“结果”具体化

- 环境还是人？目标频率？影响规模？
- **写出一句简洁明了的愿景句子**：
    - “本产品将在未来五年内，使切萨皮克湾（注：美国东海岸）氮污染物浓度显著下降。”
- **基于上述愿景陈述，必须定义可衡量的指标来判断产品是否成功。**

### 6.4 关于指标的建议

- **不要陈述“产品如何实现目标”**
- **一定要定义“可衡量的结果陈述”**
    - 更便于各方协同、理解目标一致性
- **指标应直接由目标结果推导得出**

### 6.5 写出指标公式

- **定义一个“评估公式”，说明结果如何衡量**

### 6.6 好的指标应具备以下特征：

- **准确性**：衡量的正是你想要的结果
- **可靠性**：重复测量结果一致
- **快速性**：能迅速得到结果
- **响应性**：能反映用户行为的变化
- **敏感性**：细微变化也能捕捉
- **低成本**：反复测量不应昂贵

### 6.7 用户中心与公司中心的两种路径

### 用户中心路径：

- 产品愿景（为用户）→ 用户结果 → 行为者 → 行为

### 公司中心路径：

- 产品愿景（为公司）→ 公司目标 → 用户结果 → 行为者 → 行为

---

### 6.8 明确要改变的行为动作

- **当你定义了结果和衡量指标后，接下来要定义希望用户采取的具体行为：**

> “我们的产品将帮助用户【开始/停止】【具体行为描述】。”

- 确保行为具象明确，不模糊
- 将目标行为转化为“可测量行为指标”
    - 是否采取了行为？
    - 行为持续了多久？频率？强度？

> 行为指标包括：衡量什么、如何衡量、以及衡量周期

---

### 6.9 找出“最小可行行为”（Minimum Viable Action）

- **找到目标行为中最小且最基本的组成动作**，如：
    - 将重复行为压缩为首次行为
    - 拆分为更简单动作
    - **剥离掉中间步骤，只留下“核心行为”**

---

### 6.10 行为改变假设模型（Hypothesis for Behaviour Change）

- 写出一条行为假设句，表明产品应帮助用户实现何种结果：

> “通过帮助【行为者】在【开始/停止】【行为】上努力，我们将实现【目标结果】。”

- 再写出一个三者联动的逻辑句：

> **“结果—行为—行为者”模型：如果这三者得以实现，产品就成功；若未实现，产品将失败（或部分失败）。”

## 七、第七章：探索行为情境

### 7.1 找到用户真正需要的行动

- **目标是找到既能帮助用户实现目标，又能兼顾商业诉求的行动。**
- 面对用户时，必须摒弃假设，重新审视“结果、行为者与行动”的真实样貌。
- **问题定义要进一步细化，特别是为何目标行为至今未发生，以及其背后的障碍。**

### 7.2 五步流程

1. **了解你的用户，以及他们对目标结果与行为的情感反应**
2. **列出他们可能采取的所有行为路径**
3. **评估各项可能行为，选出最佳方案**
4. **将该大行为拆解为多个微动作**
5. **诊断该行为当前为何未被采取**

### 7.3 用户研究重点

- 研究用户的生活情境、动机与他们和目标行为之间的关系
- 收集定性与定量数据，了解他们行为背后的真实原因

### 7.4 研究行为问题的典型提问

6. 用户是否有类似经验？
7. 用户是否信任你们公司或组织？
8. 用户目前的动机是什么？
9. 是否存在身体、心理或经济障碍，使该行为变得困难？

### 7.5 构建“行为画像 Persona”

- 识别用户群体（基于以上问题）
- 保持画像“真实、具体、生动”

### 示例画像对比

| 分类维度 | 群体A | 群体B |
| --- | --- | --- |
| 行为经验 | 无类似经验 | 有软件使用经验 |
| 产品经验 | 基本无 | 曾尝试类似系统 |
| 与组织关系 | 弱信任 | 熟悉或信任 |
| 动机 | 不明确 | 明确目标驱动 |
| 行为障碍 | 明显 | 可克服 |

- 有过类似软件使用经验的员工

## 七续：行为地图 —— 微行为通往目标行动的路径

### 7.6 “行为地图”说明

- **将用户从“未采取行动”到“采取行动”的过程完整拆解为微步骤**
- 示例：一位特朗普支持者打电话到电台进行宣传
- 找个安静地方 + 电话 + 广播
- 确认节目 + 收听适时段 + 鼓起勇气 + 拨打 + 开口说话……
- **每一步都是一个潜在阻碍点**

![[image 535.png]]

### 7.7 拆解原则

- **每个微行为都是改变或中断行为的切入点**
- 可绘图或文字描述用户行为路径（包含产品内、外的行为）
- **别忘了“新用户”的路径也需特别处理**

### 7.8 微行为映射的价值

- **揭示行为挑战根源**
- 揭示行为实现过程中的复杂性

> “人们的行为远比我们想象得复杂。”

## 八、第八章：理解我们做出的努力

### 8.1 如何有效促进行为改变？

- 有四种方法：
a. **简化行动路径**
b. **直接为用户完成动作**
c. **优化环境设置以提高行为发生概率**
d. **塑造用户自身以做好准备**

> 设计的目的在于构建一个“能推动或阻碍”行为的情境结构。

### 8.2 “代替用户行动”的优势

- **帮用户完成动作 > 简化动作本身**
- **将执行压力从用户转移到产品上 → 前提是用户知情并授权**

### 8.3 “产品自动化”的几个方式

- 将行为设置为默认选项
- 将重复行为转化为一次性设置
- 在用户进行其他任务时“顺便”触发目标行为（如默认勾选）

---

### 8.4 如果无法帮用户直接完成，就使用CREATE

- 不能只依赖动机：
    - **人们知道该怎么做，但仍不去做**
    - **动机经常变化，“下一个动作”未必是“最有激励性”的那个**

> 信息的存在不等于行动会发生。

- 教育类干预失效场景：
    - 用户行为已自动化
    - 信息出现得太早/太晚
    - **信息过载压垮决策能力**

---

### 8.5 行为改变设计的四种策略

10. **帮用户完成 → 最大程度减负**
11. **结构化行为路径，使其变得更可行（或故意更难）**
12. **优化环境设置 → 支持或抑制特定行为**
13. **帮助用户做好准备 → 心理上更愿意采取行动**

## 九与十：CREATE 行动节点干预指南

### 10.1 如何在行为地图中的关键节点促进行动？

> 使用CREATE模型的6大组件，识别并干预用户在某一时刻所需的行动

| 模块 | 目标 | 具体操作建议 |
| --- | --- | --- |
| **Cue（线索）** | 创建线索 | - 明确告诉用户下一步行动 <br> - 将某元素重新命名为提示 <br> - 设置提醒 |
|   | 增强线索强度 | - 明确行动位置 <br> - 移除干扰因素 |
|   | 定位线索 | - 去注意力集中的地方 <br> - 配合用户的时间节奏 |
| **Reaction（反应）** | 激发正面情绪 | - 回顾过往成功 <br> - 联结正向记忆 |
|   | 增强社会动机 | - 引入社会认同感（如：他人都在做） <br> - 同侪比较 |
|   | 提升信任 | - 展示权威 <br> - 保持真诚 <br> - 呈现专业与美观 |
| **Evaluation（评估）** | 经济激励 | - 确保奖励机制正确 |
|   | 支持内在动机 | - 利用已有动机 <br> - 避免直接金钱激励 <br> - 测试多种动机组合 |
|   | 提升动机 | - 利用“损失厌恶” <br> - 将未来目标提前感知 <br> - 加入竞争机制 |
|   | 支持理性决策 | - 简化信息 <br> - 降低认知负担 <br> - 避免选项过多 |
| **Ability（能力）** | 移除摩擦 | - 减少决策点 <br> - 默认选项设置 <br> - 引导计划性执行 |
|   | 提高可行性感知 | - 使用正面同侪比较 <br> - 让用户相信自己能做到 |
|   | 移除物理障碍 | - 检查并移除空间、流程障碍 |
| **Timing（时机）** | 增强紧迫性 | - 避免时间拖延（时限呈现） <br> - 回顾先前承诺 <br> - 向朋友承诺行动 <br> - 奖励设置为“稀缺” |
| **Experience（经验）** | 打破旧经验束缚 | - 借助新起点（搬家/新学期） <br> - 使用“叙事重写” <br> - 使用减速技巧，促使反思 |
|   | 脱离过去路径 | - 设置“陌生情境”打破旧链路 |
|   | 与经验保持更新 | - 定期用户反馈回访 |

## 十一、第十一章：设计干预措施的高级策略

### 11.1 多步骤干预策略

- **尽可能合并行为步骤**
    - 每一步应是用户能够理解并执行的“最大动作块”
    - 自动化、默认化、拆分为渐进任务
- **将执行成本从用户转移至产品端**
- **每步应设计“即时、小而确切”的成就感**
- **引入反馈循环**
    - **反馈应具备：“及时 + 明确 + 可执行”** ← **核心原则**

---

### 11.2 常见错误

- **“如果你做起来很轻松，不代表用户也轻松。”**
- 难度本身就能筛选出承诺者，但不应故意制造门槛

---

### 11.3 创建新习惯

> 当大脑重复某行为，并获得奖励后，“自动化习惯”形成

- **基本步骤如下：**
    1. 找到应重复的目标行为（明确且有益）
    2. 设置清晰单一的线索（在日常或产品中触发）
    3. 告知用户线索→例程→奖励路径
    4. 确保用户“愿意并能做到”
    5. 激活线索
    6. 记录例程发生
    7. **行为完成后立刻给予奖励**
    8. 持续追踪完成率与时间，及时优化
- 奖励不必每次都给，但必须“与例程强相关”

---

### 11.4 终止旧习惯

- **Cue**：移除线索或避开线索来源
- **Reaction**：替换例程，重设反应
- **Ability**：用新行为“覆盖旧行为路径”
- **Evaluation**：用意识介入，干扰自动执行流程
    - （如冥想训练、正念反应训练）

---

## 行为阻断与促进操作对照表

| 模块 | 促进行为（To Start） | 阻断行为（To Stop） |
| --- | --- | --- |
| **Cue** | 重新标记元素为线索 <br> 设置提醒 <br> 移除干扰 <br> 与时间点对齐 | 取消线索与旧行为联动 <br> 移除提醒 <br> 制造分心/隐藏线索 <br> 插入有趣干扰 |
| **Reaction** | 回顾过往成功 <br> 联结正向情绪 <br> 使用社会认同 <br> 同侪比较 <br> 真诚展现 <br> 专业美观 | 强调对行动的负面印象 <br> 用负面同侪比较 <br> 对停止行为表达认同 <br> 使用丑化手法 |
| **Evaluation** | 正确激励机制 <br> 支持动机源 <br> 测试多种动机 <br> 利用损失厌恶 <br> 使用承诺机制 <br> 将未来动机提前感知 <br> 加入竞赛 | 增加行为成本 <br> 移除正向动机通道 <br> 忽视用户的多样动机 <br> 仍使用损失厌恶（如最大失败者） |
| **Ability** | 移除不必要决策点 <br> 默认设置 <br> 引导用户制定执行意图 <br> 同侪鼓励 <br> 强化用户信心 <br> 检查物理障碍 | 增加选择复杂度 <br> 取消默认选项 <br> 插入中断点 <br> 使用失败对照组 <br> 加入阻碍行为的空间设计 |
| **Experience** | 借助“人生新起点” <br> 编辑行为叙事 <br> 使用“减速法”延迟冲动 | 阻断“重启”路径 <br> 继续固化旧路径 <br> 混淆行为意义 <br> 使用相同旧情境触发旧行为 |

## 十二、第十二章：在产品中实施干预措施

### 12.1 开展伦理审查

- 在开始构建与部署干预措施前，应进行伦理审查。
- **只有当你决定了具体干预策略后，才真正开始显现其潜在影响。**
- 审查过程本身与规则同样重要。

### 12.2 伦理审查模板

### 一、**行为目标与目的描述**

- 项目希望改变什么行为？是**推动**还是**抑制**该行为？
- 使用了哪些干预方法来支持这种改变？
- 谁是目标人群（行为者）？
- **这种干预将如何（或是否）真正帮助该人群（用户结果）？**
- 是否会在短期或长期对个体产生负面影响？
- 该项目会如何使你的组织受益？
- 你是否在该项目中拥有财务或个人利益？

### 二、**透明度与选择自由**

- 目标人群是否真心想实现该结果？他们是否希望改变行为？
- 如果他们不知道自己被改变了，**在知情后会不会感到不悦？**
- 干预是默认设置？强制选项？还是可自由退出？
- **将采取哪些步骤，来最大程度减少“强制性”的可能？**

---

### 12.3 留出创造性空间

- **结构化障碍诊断**与**创造性设计思维**之间存在张力

> “我们希望用户怎么做”，和“他们真的会怎么做”，中间还有很多差距。

---

### 12.4 衡量行为的关键指标定义

- **从一开始就纳入行为度量**
- 明确、具体、可衡量的目标结果（outcome）和行动（action），**并为其定义衡量指标**
- 为每个指标定义“成功”与“失败”的阈值

---

## 十三、第十三章：用A/B测试与实验来衡量影响

### 13.1 实验的基本原则

- **假设你是错的，目标是“减少错误”**
- **随机对照试验**是衡量干预对行为影响最有效、最严谨的手段

### 13.2 实验步骤

14. 写明：
    - 目标结果（outcome）是什么？如何衡量？
    - 哪种干预可能引发该结果？
    - 哪些用户是目标群体？
15. 将用户随机分组（控制组 vs 实验组）
16. 部署干预
17. 测量结果
18. 计算影响：
> 干预效果 = 实验组平均结果 − 控制组平均结果
19. 若影响足够大，可认定具有统计学意义与实际意义

---

### 13.3 样本量计算：多少人“够多”？

- 使用“效能计算公式”（power calculation）判断所需最小样本量
- 所需信息包括：
    - 未干预群体的平均结果
    - 结果的波动性
    - 置信水平（一般取95%）

> 判断“需要多久”收集足够样本：一旦达到目标样本量，就停止。

---

### 13.4 实验设计提示

- **随机选择并不容易**
- 一次只改变一个变量
- 永远测试统计显著性
- 尽量进行双盲实验
- 保持一致的测量方式

---

### 13.5 为什么做实验？四大目的

20. **衡量影响（统计检验）**
21. **原型筛选**
22. **优化测试（如多臂赌博机试验）**
23. **验证长期效果（即产品是否持续有效）**

## 十四、第十四章：无法进行A/B测试时的影响评估

### 14.1 前后对比分析（Pre-post analysis）

- 比较某个关键变化前后的用户行为与结果
- **但要排除其他影响因素**，如：
    - 时间点：季节、星期、日期、时间段
    - 用户经验差异
    - 数据质量与可获取性
    - 用户群构成变化

---

### 14.2 横截面分析（Cross-sectional analysis）

- 比较同一时间点不同用户群体的行为差异
- 分析该差异是否由“产品使用”所致，而不是其他背景变量

### 18.1 干预流程回顾（六步骤）

27. **定义问题**
28. **探索行为情境**

### 18.2 关键原则总结

- **先理解用户，再谈改变行为**
- **不存在“万能的行为改变魔法”**
- **一个有效的行为产品，首先必须是一个“好产品”**
- **尽可能通过技术手段来替代用户的繁琐操作**
- **不论设计得多好，总有出错的时候**
> 面对人类行为的复杂性，保持谦逊，是一种智慧。

- **人们在一天中的不同行为场景中会做出完全不同的决定**
