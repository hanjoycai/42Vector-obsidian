- 将产品管理视为一种实践（类似于医学实践）。
    - 从工具箱中选择工具来解决问题
    - 需要大量实验和反复试验
    - 需要一套特殊的技能，以便在压力和紧张时期持续进行实验
    - 需要一种独特的领导力和文化，以支持团队完成这些任务

---

- 产品经理需要同时具备技术技能和人际技能。

| 技术技能 | 人际技能 |
| --- | --- |
| 路线图 | 影响力 |
| OKRs, KPIs | 思维协调 |
| 探索冲刺 | 创造力 |
| 原型设计 | 决策能力 |
| 用户访谈 | 领导力 |
| 敏捷开发, 精益开发 | 主动学习 |
| A/B测试 | 抗压能力 |
| MVPs | 适应能力 |
|   | 解决冲突 |
|   | 情商（自我认知、自我管理、社会认知、关系管理） |

- 实现技术技能和人际技能的平衡至关重要。
- *技术技能：**产品经理用来解决客户问题、交付产品并支持产品的技术和工具。这些技能代表了产品经理的具体工作（如创意、创建、交付和迭代）。
- 如果过于注重技术技能，实践中将缺乏人际技能。
- 职位描述能很好地反映公司对某一职位的真实看法。设计得当的职位描述有助于建立优秀团队。

---

自我反思活动：

- 你的实践中在人际技能和技术技能上的关注点如何？
- 是什么阻碍你将这两个维度平衡起来？
- 你可以做出哪些小的改变或尝试哪些实验来朝着正确方向前进？

---

**情商（Emotional Intelligence）：**

- *定义：**识别、理解和管理自己的情绪的能力，以及识别、理解和影响他人情绪的能力。

---

EQ的维度（根据Goleman定义）：

| 自我意识 | 了解我们的感受和感受的原因的能力。<br>有助于直觉和决策 |
| --- | --- |
| 自我管理 | 处理痛苦情绪的能力<br>与积极情绪相联系的能力 |
| 社会意识 | 有能力处理人际关系，了解他人的感受、需求和关切 |
| 关系管理 | 使关系对双方都积极有利 |

使用角色画布（Role Canvas）

- 考虑一个跨职能的角色创建研讨会。
- **角色画布：**

| **目标** | 该角色存在的目的是什么？ |
| --- | --- |
| **职责** | 该角色将致力于实现的目标或结果是什么？ |
|   | - 列出已知的目标或结果 |
| **人际技能** | 例如：领导力、冲突解决、影响力、适应能力 |
| **技术技能** | 例如：路线图、设计冲刺、产品愿景声明、 |
|   | JTBD, OKRs |

- 持续为画布贡献内容。
- 将其转化为职位描述。

---

针对人际技能的面试

- **基于行为的问题** → 了解行为背后的意图以及其对他人产生的影响。
- 提出与EQ相关的行为问题：
    - **告诉我一个你...的例子：**
        - 提出某个建议但被他人反对时，你是怎么做的？
        - 被认为不公平时，你是如何处理的？
        - 决定放弃目标时，你的理由是什么？
        - 在工作中分心或心不在焉时，你是如何应对的？
    - *告诉我你上次在工作中被批评的经历：**如何应对？
    - **你是否遇到过不讲理的同事？你是怎么做的？**

---

- 面试官需倾听候选人的回答，识别行为背后的意图，深入挖掘叙述，直到将看似无形的技能（如冲突解决）具体化。
    - 这个人如何应对冲突？
    - 他们是选择逃避还是参与其中？
    - 如果参与，他们是如何处理的？
    - 他们希望所有人都感到满意，还是在寻找明确的赢家或输家？
- 头脑风暴基于行为的问题，帮助理解候选人的意图和行为背后的思考。
- 团队合作迭代你的面试问题和结构。

**结束会议的核对环节：**

- 让每个人选择一个词来描述会议结束时的感受。

超越文化契合（Going beyond culture fit）

- 不要仅仅为了“契合”而招聘。过于相似的团队成员会有相同的经验，无法相互挑战或推动创新。
- **多样性更有利于创新：**
    - *固有多样性：**与生俱来的特征，例如性别、种族和性取向。
    - *后天多样性：**通过经验获得的特征，例如在其他国家工作、为与你不同的客户创造产品。
- 拥有更多固有和后天多样性的公司表现更好（能占据更多市场份额）。
- 不要建立一个“克隆”团队。你需要团队看起来像拼图，而不是一堆相同的堆叠物。你希望每个人看起来都不同，但能够融洽合作。
- 寻找文化贡献。
- 候选人需要契合公司的价值观，并带来文化贡献。

---

添加能够检查价值观契合的面试问题：

- 你的同事从与你合作中受益的地方是什么？
- 讲述一个通过理解他人视角帮助你完成任务或解决问题的例子？
- 你对我们公司文化和价值观的印象是什么？

---

如何在面试后反思候选人？

- 他们会挑战团队当前的思维和流程吗？
- 候选人是否为团队带来了新的能量？
- 你是否从候选人那里学到了新东西？
- 记住要解释你的思考来源。是他们说的某些话吗？还是他们的肢体语言？

---

采用持续学习（Adopting continuous learning）

- 不断思考如何在招聘流程的每个阶段进行迭代和改进：
    - 持续感知、响应并进化，以寻找适合某个职位的最佳人选。
    - 将其视为一个**持续学习的循环**。
- 定期举办回顾会议，与团队交流，审查定性和定量见解，并提出改进建议。
- 每次成功招聘后，都应进行反思回顾，检查你是否找到了一个优秀的候选人。
