## 第1部分：介绍（Part 1: Introduction）

### 问题：产品动量差距（The Problem: The Product Momentum Gap）

- 初创阶段的公司能够快速了解客户及其动机。探索和决策的速度非常快。来自市场的反馈循环是非正式但快速的。
- 创始人将专注于融资。如果成功获得资金以扩大团队，公司预计将以快速速度增长。
- 更多人员和计划意味着创始人离客户更远。由于分心，关键决策需要更长时间，因为创始人的时间被分散了。与客户的交流减少，学习速度减慢。
- 很快就会发现对路线图缺乏清晰的理解，节奏减缓。关于产品战略的混乱、不一致的意见隐藏在表面之下。销售和市场团队为了获得客户而撒下更广的网，推动客户购买并非为其设计的产品。
- **症状：**
    - 客户无法获得销售过程中承诺的功能。
    - 随着竞争对手缩小功能差距，销售周期变长。
    - 客户服务被重复性问题轰炸。
    - 领导层无法看到产品开发在何处创造价值。
- 创始人认为他们需要同时停止客户流失、增加销售和提升客户终身价值。如果一切都是优先事项，那么就没有优先事项。
- 领导层感到沮丧，因为额外的资源并未带来结果。
- *产品动量差距：**初创公司预期的高增长曲线与平均增长之间的差异。
- *产品管理：**基于证据发现客户的共鸣点。
- 仅靠创始人接触产品无法解决问题。他们对客户的知识已经过时了，客户群体扩大了，新用例也在不断演变。

---

### 如何知道你是否即将陷入差距？（How do you know if you’re about to fall into a gap?）

- *原因1：**目标客户的对齐和理解存在偏差。
    - 销售团队接触的潜在客户与目标客户不匹配。
    - 转化率下降，客户流失增加。
- *原因2：**产品团队失去对客户需求的跟踪。
    - 产品团队猜测并快速推出功能。

---

### 弥合产品动量差距（Bridging the Product Momentum Gap）

- 产品领导者需要创造透明性和一致性：
    - 建立一个清晰且可衡量的方向以创造价值。
    - 改善全公司的可见性和认同感。
    - 简化产品开发的优先级排序。
    - 建立一个能够更快交付的自信产品团队。
    - 创建一个清晰的路径以提供产品价值（推动关键业务指标）。

---

### 解决方案：产品价值创造计划（The Solution: The Product Value Creation Plan, VCP）

- 你是否了解你的产品提供了什么价值以及它是如何实现的？
- **产品VCP将产品战略、目标和路线图与关注客户价值的连接点联系起来。**
- 产品开发与最终用户之间往往存在不对齐。
- 产品战略通常定义了价值主张，但未定义实现价值的路径。
- **团队认为他们在客户价值上达成一致意见，但在产品实现该价值的方法上存在分歧。**
- **为了让每个人保持一致 → 消除关于产品如何生成客户价值的模糊性：**
    - 精确地看清我们如何通过每次更新改变用户行为。
- 产品战略的重点是如何更接近产品愿景。
- 产品VCP专注于哪些用户行为或动作将创造价值。

---

|   | · 用户画像 |
|   | · 竞争对手 |
|   | · 技术趋势 |
|   | · 分销渠道 |
|   | · 行动：如何实现结果 |
|   | · 商业模式 |
|   | · 定位策略 |
|   | · 定价策略 |

---

- *价值：**当客户找到一种可重复的行为并带来正面影响时的瞬间。
- 通过专注于价值，团队可以识别和优先解决最有影响力的问题。
- 价值驱动的文化培养了对客户需求和愿望的深刻理解 → 更容易取悦客户并创造忠诚度。
- 将客户价值引入产品战略有助于对齐组织并促进共同目标感：
    - 一致性使团队更容易协作。
- 专注于客户价值使得更容易实现业务目标：
    - 客户价值 → 创新解决方案 → 强大的用户采用 → 实现业务目标。
- **我们需要理解用户行为、客户价值和业务目标之间的交集。**
- 承担责任 → 我们构建的功能影响用户行为。
- **将领导力从关注功能转变为关注用户行为。**
- 用户行为常常在产品战略中被忽视。

## 第2部分：构建产品价值创造计划（VCP） （Part 2: Building a Product VCP）

### 产品愿景（Product Vision）

- 随着公司的扩展，决策速度变慢且更加分散。通过一致性和透明性应对这种情况。
- 你可能会迷失在问题和功能中。
- **围绕产品开发的价值对齐：你在构建什么以及为什么构建它。**
- **你需要一个清晰的产品愿景和一个可衡量的产品战略。**
- 产品愿景是决策的基础，包括：
    - 对目标市场的清晰认识。
    - 你将为市场解决的高层次问题。
    - 你在竞争中的定位。
- 当所有人都理解愿景后 → 制定一个展示如何交付价值的产品战略。
- 产品战略应通过展示战略计划如何影响客户和支持业务目标来建立一致性：
    - 同意需要影响的用户行为。
    - 将用户行为作为价值指标捕获（用于衡量价值创造/成功）。
    - 如果价值指标朝着正确的方向发展，我们就在创造价值。
- VCP应缩小你专注的问题和解决方案的类型 → 明确产品的目标受众。它帮助集中注意力：
    - 专注于一个特定的客户细分市场，并为他们提供价值。
    - 策略需要回答：你接下来为谁服务？为了维持客户吸引力，你需要在扩大市场的同时保持对原始细分市场的吸引力。

---

### 产品价值链（The Product Value Chain）

- 不要盲目尝试。你需要证据来理解一个解决方案是否值得花时间。
- 功能如何创造价值？用户采用功能 → 用户行为改变 → 价值实现。
- **产品价值链：用户行为 → 客户价值 → 业务目标**
    - **产品战略需要讨论用户行为！（大多数没有）**
- **我们需要透明地了解产品团队可以影响的用户行为以及目标影响的行为。**
- 通过以用户行为为基础阐明产品战略，团队可以采取行动 → 同时为创新设定边界。

| **业务目标** | **客户价值** | **用户行为** |
| --- | --- | --- |
| 增加收入 | 降低运营成本 | 更快的发票对账 |

- 利益相关者可以围绕价值假设进行辩论，并评估价值创造的风险。

---

### 映射价值（Mapping the Value）

- 从你的业务目标开始，将其映射到客户价值。
- 专注于业务目标，并明确客户将收到的价值。
- 清晰的业务战略和互补的产品战略让这一过程更容易。
- 捕捉你当前对客户价值的思考：
    - 你应该有支持证据（产品研究、客户访谈、市场研究、客户反馈）。
    - 如果没有证据，进行更多的探索。

### 探索价值（Exploring the Value）

- 价值探索器阐明每个客户价值，确保它们与业务目标保持一致。
- 从地图中提取每个客户价值点，并检查：
    - 客户如何识别这一价值？
    - 客户的KPI是什么？客户如何衡量它？
    - 哪些客户行为或动作影响价值？
    - 产品如何帮助改善这些行为？
        - **注意：不要急于选择第一个选项。**

**探索客户价值（Exploring Customer Value）**

|**客户价值**|**客户如何识别？**|**客户KPI变化？**|**哪些行为或动作影响价值？**|**产品如何改进？**|

- *协作讨论：**你将更好地理解你的假设。
- **目标可重复的行为，寻找可以持续提供客户价值的一致活动。**
- 你是否处于最佳位置来创造这一价值？

---

### 价值假设构建器（Value Assumption Builder）

- 使利益相关者一致同意产品应培养的精确用户行为，以生成价值。
- 从列出之前练习中的所有客户行为开始（暂时不考虑优先级）。
- 对于每种行为，定义如何修改以实现更多客户价值。
- 每个客户行为都有一个修正因素，必须到位才能提供我们所寻找的客户价值。
- 合并并整合类似项，优先考虑5项或更少（你需要专注）。
- 没有明确的优先级，执行是不可能的。并非所有内容都能立即解决。

**探索价值假设（Explore Value Assumptions）**

| **客户行为或动作** | **修正因素** | **更大的客户价值** |

### 跟踪价值创造（Tracking Value Creation）

- 如果根据价值假设来衡量进展，产品开发过程会更有影响力。
- **领导层往往倾向于回归顶级业务指标（例如ARR或流失率）……但你必须衡量当你的产品与用户接触时会发生什么。**
    - 你必须以领先指标的形式衡量价值假设。
        - 滞后指标在战略上很重要，但在日常产品开发中无用。
    - 你需要一个每日测量循环，以快速为决策提供信息。
    - 行动需要能够提供快速反馈的指标。
- 价值假设不容易与领先指标对齐：
    - 确定能快速显示测量方向的指标。
    - 即使准确性不那么重要，也要关注这点。
    - 这些是“价值指标”（如何随着时间推移衡量一个功能的价值）。
    - 如果指标连接较松散也没关系，但每个人都必须确信，当行为改变时，指标也会发生变化。

- 将测量结果反馈到产品战略决策中。

### 如何实现这一目标（How to Make This Happen）

- 产品VCP从用户行为的角度为产品团队设定方向，为产品及其周边功能提供更多清晰性。
- 将注意力重新聚焦到产品存在的目的上（利用产品愿景）。
- 通过使用产品VCP和价值指标，持续推动学习和问责制的文化。
- 不要规定具体的构建内容，但要优先确保对齐，以确保每个人都朝着正确的方向努力。
- 产品VCP将产品战略阐明为可实现的、可衡量的以用户为中心的目标。
- **Pendo研究：80%的发布功能很少或从未被使用。**

## 第3部分：创建一致性（Part 3: Creating Alignment）

### 转变为战略性成果（Transforming to Strategic Outcomes）

- 如果产品愿景不足以支持产品价值创造计划（VCP），你可能需要重写产品愿景：
    - 将产品愿景聚焦于产品体验。
- 你可以识别待完成任务（JTBD），但VCP将提供清晰性，并定义客户在使用产品时感知的价值将如何增长。
- 客户价值探索器（Customer Value Explorer）围绕哪些用户行为会成为游戏规则的改变者展开关键对话。
- 专注于行为而非功能，与业务计划建立更强的联系。
- 价值假设推动清晰性 → 并能进一步激发探索。
- 产品VCP是专注于成果的关键。
- 很快，产品团队将对VCP指标负责，而不是对产品功能负责。

---

### 阐明你的战略（Articulating Your Strategy）

- **产品战略定义了产品投资如何让你更接近产品愿景。**
- 产品愿景将实现业务目标（因此与业务战略相关）。
- 清晰地阐明产品战略可以在创建一致性方面产生重大影响。
- 专注于三个关键方面：
    - **为什么这对业务很重要？**
    - **客户将获得什么价值？**
    - **产品将如何交付这一价值？**
- 产品战略和路线图不应被视为固定不变的文件。
- 不要用产品路线图来解释“如何”。不要坚持没有灵活性的解决方案。为改变不起作用的事物留出空间。
- 将“如何”视为你希望以某种方式改变的高级别用户行为：
    - 这弥合了战略与执行之间的差距。
    - 衡量变化带来问责制。
    - 专注于行为变化为团队找到正确的解决方案创造了自由。

---

### 组织一致性（Organisational Alignment）

- 你的业务愿景和产品愿景应该是不同的。
- **创建一个独立的产品愿景，它可以：**
    - 支持你的业务战略。
    - 指导你的产品战略。
    - 围绕一组共享的价值观和目标团结你的团队。

| **业务愿景（Business Vision）** | **产品愿景（Product Vision）** |
| --- | --- |
| 你是谁 | 目标受众是谁 |
| 你做什么 | 产品的概念和体验是什么 |
| 为什么你这样做 | 关键益处是什么 |
| 业务目标是什么 | 主要竞争优势是什么 |

---

### 创建透明度和信任（Creating Transparency and Trust）

- 要有一个路线图，你必须首先有一个战略和方向。
- 设定方向，而不是规定解决方案。
- 如果领导层在战略中规定了解决方案，他们在做产品团队的工作，但没有产品团队所拥有的证据和客户接触。这可能浪费时间和资源。
- 一旦方向、战略和价值一致，它们就应该在产品路线图中明确表达：
    - 解决方案是承诺，难以更改。
    - 专注于将授权团队共同探索解决方案的成果。
    - 在完成产品VCP后，更容易创建基于成果的路线图。

---

- 领导层的责任是创建一致性和目标。
- 专注于问题空间，制定假设并设计实验以进行测试。
- 信任你的团队从过程中学习。
- 信任不是盲目信任。产品VCP是一个良好的平衡，它设定了一些边界并可以被监控。

## 第4部分：通过行动推动责任感（Part 4: Driving Accountability with Action）

### 优先事项的排序（Initiative Prioritisation）

- 产品战略的复杂性可能阻碍优先事项的排序。
- 产品VCP阐明了价值假设，并突出了需要影响的用户行为。
- 价值假设是关于产品如何为用户创造价值的假设。
- 价值假设在价值链中分为两个层次：
    - *产品影响：**如何改变产品 → 改变行为 → 创造更多客户价值。
    - *战略层面：**创造的客户价值 → 转化为业务目标。
- 理解你的假设，明确表达它们，并确保每个人都理解这些假设：
    - 然后将努力集中在用户行为上。
- *价值指标：**一组领先指标，标志着对战略利益相关的用户行为的状态。
- 根据用户行为，指标可能需要作为指导性指标（而非直接测量）。
- 价值指标的改进 → 意味着我们正在积极影响用户行为 → 如果假设正确，这将创造客户价值 → 进而影响业务目标。
    - **产品团队应该能够专注于价值指标。**
        - 将其与滞后指标和定性数据交叉引用。
- 战略价值矩阵可以帮助评估价值，并为其他优先级排序方法提供支持。

- 目标从业务层级向产品层级逐级分解。
- OKR帮助分阶段执行战略计划。
- 产品VCP可以帮助你定义正确的OKR。
- **你的产品目标和关键结果（KRs）应该专注于通过创建或修改用户行为为客户创造价值。**

### 用价值假设进行实验（Experimenting with Value Assumptions）

- 针对这种方法的一个反对意见是没有时间进行实验。**但进展不仅仅来自于发布，它还来自于理解某事可能如何以及为什么提供价值。**
- 实验提供了关于应该构建什么以及不应该构建什么的洞察。
- 测试产品创意可以帮助你评估用户的响应。如果错误则：
    - 避免构建错误的内容。
    - 学到解决问题是否可行。
    - 获得关于什么可能更有效的知识。
- 考虑使用双轨敏捷和低代码解决方案以更快学习。
- 将学习放在你所做的一切的核心，通过优先考虑创新：
    - 接受错误，以敏捷的方式工作，拥有支持心理安全的文化。
- 加快客户反馈循环使你能够快速学习和迭代，足以领先于市场，同时在过程中让客户感到被包含。
- 为了促进实验文化，你需要投入时间进行探索。

### 承担责任（Taking Accountability）

- **构建人们所要求的内容与构建人们所需要的内容之间存在差异。**
- 作为产品团队，你通过以下方式创造价值：
    - 对公司目标有清晰的了解：
        - 清晰的公司愿景为产品愿景铺平了道路。
        - 一个产品愿景帮助你创建一个产品战略。
        - 明确的公司目标有助于促进可衡量的产品目标、跟踪和进展。
    - 围绕你的客户和用户建立一致性：
        - 在特定目标市场中建立你的产品。
        - 然后战略性地扩展到相邻细分市场。
    - 解决[正确的]客户问题：
        - 哪些计划支持你的公司目标？
        - 哪些计划帮助实现客户结果？
        - 然后……你还能在哪里进一步实验？
- 产品VCP帮助突出显示计划将在何处以及如何对公司目标产生影响。

### 如何实现这一目标（How to Make This Happen）

- *直言不讳：**是时候停止通过将路线图作为执行产品战略的主要手段来浪费资源了。这行不通。
- 产品团队需要一个战略来指导他们解决哪些问题，而不是规定具体功能。
- 赋予你的产品团队掌控权。**为他们提供更多的清晰性至关重要。**
- **不要将业务战略与产品战略混为一谈 → 这种做法无法就客户认为有价值的内容以及我们试图改变的行为创建一致性。**

## 第5部分：销售价值（Part 5: Selling Value）

### 向产品团队之外传递价值（Communicating Value Beyond the Product Team）

- 保持透明，并向整个组织传达你的产品VCP。
- 花点时间添加更多上下文，并清楚地向组织传达你所做的事情以及原因：
    - 我们开发了功能X，
    - 它帮助客户实现了[一个具体的结果]。
    - 这服务于我们的产品愿景中的[客户细分]，
    - 提供了[这种特定的体验]，
    - 影响了这些[行为]，
    - 并与[公司目标X]保持一致，
    - 并影响了[关键结果]。
- 在决策演示中包含你的路线图、战略和生产愿景。
- 缺乏沟通比潜在的产品泄漏问题更为严重。
- 你可以通过产品价值金字塔进行交流：
    - 你正在改善谁的生活？
    - 你在解决什么问题？
    - 为什么这很重要？
    - 你想提供什么体验？
    - 你想影响哪些行为？

---

### 实现并保持客户吸引力（Achieving and Maintaining Customer Traction）

- *产品与市场的契合并非二元或静态。**市场在不断发展，客户需求也在变化。
- 功能对等不是一种战略。要超越竞争对手，你需要识别市场中的差距，并以你自己的方式解决这些差距：
    - 识别市场中的问题，并找到更好的客户体验来解决它。
- 对客户问题的更深理解将使你比其他人更有优势：
    - 更快的反馈循环和更高的学习速度 → 然后利用这些快速迭代。
- 当产品没有解决正确的问题，或试图解决太多问题时，产品会失败。
- 你需要对市场需求和目标客户有扎实的了解。
- 增加专注以实现稳步增长，不要分心。
- 验证你的战略，并对可能出错的地方保持开放心态。
- 不断问自己两个基本问题：
    - 我们在解决什么问题？
    - 这对客户有什么价值？

### 市场定位（Positioning）

- **当拥有优秀产品的公司难以增长时，可能是因为它们面向了错误的市场。**
- 与产品营销和营销团队一起审视产品价值金字塔，以便在目标客户方面达成一致。
- 使用你的产品VCP将营销和销售与产品对齐。
- 产品的定位也需要以价值假设为核心。
