## **核心收获**

- 良好的决策可以归结为知道什么是值得追求的，以及如何得到你想要的，为此最重要的是拥有智慧，把你未来的后知后觉变成你现在的预见。你需要看到生命的所有广度：工作、健康、家庭、朋友、信仰和社区的智慧，你需要避免被情绪、自我、社会和惯性四类偏见影响的智慧，你需要设定高标准，并且以[自我问责](https://zhida.zhihu.com/search?content_id=236175787&content_type=Article&match_order=1&q=%E8%87%AA%E6%88%91%E9%97%AE%E8%B4%A3&zhida_source=entity)、[自我认识](https://zhida.zhihu.com/search?content_id=236175787&content_type=Article&match_order=1&q=%E8%87%AA%E6%88%91%E8%AE%A4%E8%AF%86&zhida_source=entity)、[自我控制](https://zhida.zhihu.com/search?content_id=236175787&content_type=Article&match_order=1&q=%E8%87%AA%E6%88%91%E6%8E%A7%E5%88%B6&zhida_source=entity)和自信的态度去寻找客观规律的智慧。
- 这本书最重要的信息是，有一些看不见的本能在密谋反对好的判断。你的默认会鼓励你做出没有理由的反应——无意识地而不是刻意地去生活。
- 一个好的位置可以让你清晰地思考，而不是被环境所迫而做出决定。世界上最优秀的人之所以能做出一贯正确的决定，原因之一是他们很少发现自己是迫于环境而做出决定的。清晰的思维是正确定位的关键，这是让你掌握你的环境，而不是被环境所控制。
- 在刺激和反应之间的空间里，有两种情况会发生。你可以有意识地停下来，把原因应用到这个情况中。或者您可以放弃控制并执行默认行为。我们没有意识到我们的情绪正在使我们做出反应，从而在下游制造问题。因此，我们改善结果的第一步是训练自己识别需要首先做出判断的时刻，并停下来创造[清晰思考](https://zhida.zhihu.com/search?content_id=236175787&content_type=Article&match_order=1&q=%E6%B8%85%E6%99%B0%E6%80%9D%E8%80%83&zhida_source=entity)的空间。
- 惯性是双刃剑，如果我们拥有好的习惯，惯性能继续增强这些习惯。
- 有许多内在的生物学弱点会阻碍良好的判断力：睡眠不足，饥饿，疲劳，情绪，分心，紧张的感觉，在一个陌生的环境只是一些例子。我们不可避免地会时不时地发现自己处于这样的环境中。但我们可以实施保障措施，以保护我们不受违约的影响。具体包括预防、成功的自动规则、制造做不好的事前的摩擦、设置检查表、转变观点
- 做出决定的四个步骤：定义问题，探索可能的解决方案，评估选项，最后做出判断并执行最好的选项。最后，从决策中学习。
- 更有效地处理错误的四个步骤如下：（1）承担责任；（2）从错误中学习；（3）致力于做得更好；（4）尽你所能弥补损失。
- 塞涅卡说：“让我们做好思想准备，就好像我们已经走到了生命的尽头。”如果你想要更好的生活，开始思考死亡。提醒自己快死了，是我在人生中下重大决定时，所用过最重要的工具。因为几乎每件事--所有外界的期望、所有的骄傲、所有对困窘或失败的恐惧--在面对死亡时，都消失了，只有真正重要的东西才会留下。记住你即将死去是我所知道的最好的方法，以避免认为你有一些东西要失去的陷阱。
- 时间是生命的终极货币。管理我们在地球上的短暂时间就像管理任何稀缺资源一样：你必须明智地使用它，优先考虑最重要的事情。
- 我们年纪越大，就越像马可·奥勒留那样看待事物：“当你被一件外在的事情困扰时，困扰你的不是事情本身，而是你对它的判断。你可以在一瞬间将其清除。

## **清晰思考需要的四个关键优势**

>> 自我负责：让自己对发展自己的能力负责，管理自己的无能，用理性来管理自己的行为

>> 自知之明：知道自己的长处和短处——你能做什么，不能做什么

>> 自我控制：控制你的恐惧、欲望和情绪

>> 自信：相信自己的能力和对他人的价值

## **其他收获**

◆ Preface

>> 那天晚上，我开始问自己一些问题，这些问题我将在接下来的十年里继续探索。如何才能更好地推理？人为什么会做出错误的决定？为什么有些人总是得到更好的结果比其他人谁拥有相同的信息？我怎样才能在生命危在旦夕的情况下，更经常地做出正确的判断，并减少糟糕结果的可能性？

>> 为了得到我们渴望的结果，我们必须做两件事。我们必须首先在我们的思想、感情和行动中创造出推理的空间；其次，我们必须有意识地利用这个空间来清晰地思考。一旦你掌握了这个技能，你会发现你有一个不可阻挡的优势。

>> 我将转向也许是最重要的问题：你的首要目标是什么。如果不是为了正确的结果，世界上所有成功的执行都是毫无价值的，但你如何决定正确的结果是什么？

>> 如果我的人生有一个口号，那就是“掌握别人已经掌握的最好的东西”，这本书就是对这个信念的致敬。我已经尽我所能把这些想法归功于那些值得称赞的人。我可能错过了一些，为此我道歉。当你把事情付诸实践，它们就会成为你的一部分。二十年来，我与世界上最优秀的人进行了数千次对话，我读过的书多得数不清，要记住每样东西都是从哪里来的并不是一件容易的事。大部分都是我潜意识里根深蒂固的。可以有把握地认为，本书中任何有用的东西都是别人的想法，我的主要贡献是把我从前人那里学到的东西镶嵌在那里，为世界所用。

◆ Introduction: The Power of Clear Thinking in Ordinary Moments

>> 清晰思维的敌人——我们天性中更原始的部分——让我们很难看清正在发生的事情，相反，只会让我们的生活更具挑战性。当我们在会议上情绪化地对同事作出反应时，我们必须做出补偿。当我们做出决定来证明自己是正确的，而不是得到可能的最好结果时，我们最终只会留下一个烂摊子要收拾。如果我们在星期五开始和伴侣争吵，整个周末都可能失去。难怪我们的精力更少，压力更大，总是觉得很忙。

◆ Part 1: The Enemies of Clear Thinking

>> 永远不要忘记，你的潜意识比你聪明，比你快，比你强大。它甚至可能控制你

◆ Chapter 1.1: Thinking Badly—Or Not Thinking at All?

>> 有意识的处理需要时间和精力。进化青睐刺激-反应捷径，因为它们对群体有利：它们增强群体适应性、群体生存和繁殖。随着人类继续在群体中繁荣发展，等级制度不断发展，从混沌生序，给我们所有人一个地方。领土是我们试图避免与他人战斗的方式--你离开我的地盘，我也不干涉你的领土。自我保护意味着我们选择生存而不是规则、规范或习俗。

◆ Chapter 1.2: The Emotion Default

>> 《教父》是我最喜欢的电影之一，部分原因是它包含了许多商业经验。维托柯里昂，柯里昂犯罪家族的首领，是一个耐心和纪律的大师。由于他的缺点在控制之下，他从不不经推理就做出反应，而当他做出反应时，这种反应是无情地有效的。

>> 维托的大儿子，桑提诺，又名桑尼，是维托的继承人然而，与他的父亲不同的是，桑尼是复仇的，冲动的，狂热的。他很容易勃然大怒，先做出反应，然后再推理。他的非强制性错误确保了他一直在艰难地玩生活。

>> 对竞争对手的愤怒会阻止你做对自己最有利的事情。害怕失去机会会促使你停止思考，冲动行事。对批评的愤怒会让你在防御上猛烈抨击，疏远潜在的盟友。这样的例子不胜枚举。

>> 情绪甚至会让我们变成白痴，让我们远离清晰的思考。不过，他们通常会得到帮助。稍后，我们将看到许多内在的生物弱点，这些弱点使我们更容易受到情绪预设的影响：睡眠不足，饥饿，疲劳，情绪，注意力分散，紧张，匆忙，在一个陌生的环境。如果你发现自己处于这些情况中的任何一种，一定要提高警惕！情绪的默认值很可能是主导这场秀。我们还将探讨在这种情况下可以保护您的安全措施。

◆ Chapter 1.3: The Ego Default

>> 在卡洛的例子中，被提醒他在家庭中的低地位与他捍卫自我形象的愿望相结合（“我能做的不仅仅是工作我加入，但他们不给我更多”），并导致他做出最终的背叛。卡罗从来没有打算从内部拆散考利昂家族。他只是想要一个符合他对自己看法的角色。每天被人轻视的愤怒引起了连锁反应，这是他从来没有想到的。

>> 我们的自我引诱我们认为我们比我们更重要。如果不加以控制，它可能会把自信变成过度自信，甚至是傲慢。我们在互联网上获得了一点知识，突然之间我们充满了傲慢。一切似乎都很容易。因此，我们冒着我们可能不明白自己在冒的风险。然而，如果我们想要得到我们想要的结果，我们就必须抵制这种不劳而获的信心。

>> 自信并不会降低坏结果的可能性，也不会提高好结果的可能性，它只会让我们对风险视而不见。自我也使我们更关心维持或提高我们在社会等级中的感知地位，而不是扩展我们的知识或技能。

>> 人们很难在工作中授权给他人的一个原因是，让他们依赖我们做每一个决定会让我们觉得自己很重要，不可或缺。让他们依靠我们，让我们觉得自己不仅是必要的，而且是强大的。依赖我们的人越多，我们就越有力量。然而，这种立场往往弄巧成拙。慢慢地，然后突然之间，我们变成了自己所创造的环境的囚徒；要想保持在一个地方需要越来越多的努力，这时我们就接近了暴力的极限。【*】事情破裂只是时间问题。

>> 大多数人终其一生都以为自己是对的。不按自己的想法看问题的人是错的。[2]我们误解了我们希望的世界是什么样子，而它实际上是什么样子。

◆ Chapter 1.4: The Social Default

>> 社会默认让我们害怕被冷落，被嘲笑，被当成白痴。在大多数人的心目中，这种对失去社会资本的恐惧超过了偏离社会规范的任何潜在好处，并使他们倾向于接受它。

>> 如果你在做无差别的工作，唯一能超越别人的方法就是比别人更努力。想象一下，一队挖沟工人用他们的双手工作。几乎觉察不到每小时移动的土壤数量的微小变化。你的工作和你旁边的人的工作没有什么区别。搬运更多泥土的唯一方法是挖得更久。在这种模式下，挖沟者花一周时间去试验和发明铲子似乎很疯狂。他们不仅看起来像一个冒险的傻瓜，而且他们的累积产量落后于他们不挖的每一天。只有当铲子出现时，其他人才能看到它的优势。成功需要无耻。失败也是如此。

>> 我们很容易因为别人同意我们的观点而感到安慰。正如传奇投资家[沃伦·巴菲特](https://zhida.zhihu.com/search?content_id=236175787&content_type=Article&match_order=1&q=%E6%B2%83%E4%BC%A6%C2%B7%E5%B7%B4%E8%8F%B2%E7%89%B9&zhida_source=entity)所指出的那样，尽管“事实上，别人同意或不同意你，使你既不对也不错。如果你的事实和推理是正确的，你就是对的。”

>> 如果你发现自己在努力融入人群，如果你经常害怕让别人失望，如果你害怕成为一个局外人，或者如果嘲笑的威胁让你充满恐惧，那么要小心了！社会默认负责。

◆ Chapter 1.5: The Inertia Default

>> 惯性让我们做的事情不能让我们得到我们想要的。它在我们的潜意识中运作，在很大程度上没有被发现，直到它的影响太难对抗。稍后我将讨论更多关于惯性默认值在工作中的示例以及如何与之对抗。暂时请记住以下几点：如果你发现自己在团队中咬舌头，如果你发现自己或你的团队抵制改变，或者继续以一种方式做某事，仅仅因为这是你过去一直做的——请提高警惕！惯性违约很可能在起作用。

◆ Chapter 1.6: Default to Clarity

>> 你会不自觉地养成和你在一起的人的习惯，这些人会让你更容易或更难实现你的目标。你和别人相处的时间越长，你就越有可能开始像他们一样思考和行动。

◆ Part 2: Building Strength

>> 我们的默认行为消除了根深蒂固的生物学倾向——我们的自我保护倾向，承认和维持社会等级制度的倾向，以及保卫自己和领土的倾向。我们不能简单地知道这些倾向的存在，然后将它们消灭。相反，认为意志力是消除这些力量所需要的一切的感觉，是他们用来使我们处于他们的控制之下的伎俩之一。

>> 为了阻止我们的违约妨碍良好的判断力，我们需要利用同样强大的生物力量。我们需要采取同样的力量，违约会用来摧毁我们，并把它们变成我们的优势。其中最主要的是惯性力。

>> 惯性是把双刃剑。我们在前面看到，惰性是一种维持现状的趋势。如果现状是次优或功能失调，惯性就会对我们不利。但现状不一定是次优的。如果你训练自己不断地思考、感受和行动，以促进你最重要的目标，换句话说，如果你增强了力量，那么惯性就会成为一种几乎不可阻挡的力量，释放你的潜力。

>> 建立仪式感是创造积极惯性的关键。仪式会让人把注意力集中在当下之外的事情上。它们可以很简单，比如在回应某人在工作中的争论点之前，先快速停顿一下。我以前的一位导师曾经告诉我：“当有人在会议上轻视你时，在你发言之前先深呼吸一下，观察一下你改变即将要说的话的频率。”

◆ Chapter 2.1: Self-Accountability

>> 当人们的行为产生的结果与他们对自己的看法不一致时，他们倾向于通过责怪他人或不利的环境来隔离他们的自我。心理学家甚至对这种倾向有一个术语。他们称之为自我服务偏见，一种以保护或提升自我形象的方式评估事物的习惯。语句如“这是个好主意，只是执行得不好”、“我们已经尽力了”、“我们一开始就不应该出现这种情况””往往是这种偏见的表现。

>> 如果你不接受这个世界的真实运作方式，你的时间和精力就会被用来证明你是多么正确。当期望的结果没有实现时，人们很容易责怪环境或他人。我称之为正确的错误一面。你关注的是你的自负，而不是结果。

>> 自我负责是意识到即使你不能控制一切，你可以控制你对一切的反应的力量。这是一种心态，它赋予你行动的力量，而不仅仅是对生活抛给你的任何东西做出反应。它将障碍转化为学习和成长的机会。这意味着你要意识到你应对困难的方式比困难本身对你的幸福更重要。这意味着要明白，最好的办法往往就是接受现实，然后继续前进。

◆ Chapter 2.2: Self-Knowledge

>> 自知之明就是要知道自己的长处和短处。你必须知道什么是你能做的，什么是你不能做的；你的能力和局限，你的优势和弱点，什么是你能控制的，什么不是。你知道你知道什么，你不知道什么。而且，你知道，你有认知盲点——有些事情你不知道，你不知道你不知道他们-唐纳德拉姆斯菲尔德著名的所谓的“未知的未知”。

>> 一天晚餐时，[查理芒格](https://zhida.zhihu.com/search?content_id=236175787&content_type=Article&match_order=1&q=%E6%9F%A5%E7%90%86%E8%8A%92%E6%A0%BC&zhida_source=entity)（Charlie Munger）详细阐述了我那位房地产投资者朋友提出的同样观点。他说，“当你玩游戏时，其他人有天赋而你没有，你会输的。你必须找出自己的优势所在，并坚持下去。”

◆ Chapter 2.3: Self-Control

>> 情感是人类生活中不可回避的一部分。像我们这样的哺乳动物进化出了对即时环境威胁和机会的快速反应——恐惧是对威胁的反应，快乐是对社会关系体验的反应，悲伤是对损失的反应。我们无法消除这些生理反应或触发它们的条件。我们只能管理我们如何应对它们。

>> 获得成功的很大一部分是有自制力去做任何需要做的事情，不管你当时是否想做。从长远来看，情绪的强度远不如纪律的一致性重要。灵感和兴奋可能会让你前进，但坚持和常规是让你前进直到你达到目标的动力。任何人都能保持几分钟的兴奋，但一个项目持续的时间越长，能为之保持兴奋的人就越少。最成功的人有自制力，无论如何都要坚持下去。虽然不总是令人兴奋，但他们还是会出现。

◆ Chapter 2.4: Self-Confidence

>> 自信就是相信自己的能力，相信自己对他人的价值。

>> 你需要自信，才能独立思考，才能在社会压力、自我、惰性或情绪面前坚定立场。你需要它来理解不是所有的结果都是立竿见影的，并专注于做那些最终能赢得它们的事情。

>> 自信增强了在负反馈后的恢复力，以及在面对不断变化的环境时的适应性。你知道你的能力是什么，以及它们如何增加价值，不管别人是否欣赏它们。如果你已经建立了健康的自信心，它将帮助你度过任何出现在你面前的挑战和困难。

>> 没有谦逊的自信通常和过度自信是一样的--一种弱点，而不是一种力量。自信的人有能力承认自己的弱点和弱点，承认其他人可能在某些方面比他们做得更好，并在需要帮助时寻求帮助。

>> 互联网让我们很容易找到认同我们的人无论我们相信什么。想否认大屠杀吗？有这样一个小组认为疫苗会导致自闭症吗？许多人也这样做。见鬼，我们仍然有一个地球平坦的社会，其成员遍布全球。

◆ Chapter 2.6: Setting the Standards

>> 建立你的任何优势的第一步是提高你坚持自己的标准，这是一个实际的问题，看看你日常环境中充斥着的人和实践。

>> 最成功的人有最高的标准，不仅对别人，而且对自己。例如，有一次我被派到一个偏远的地方工作，我记得我在一次会议上站起来解释某项操作的一些要素是如何工作的。过了一会儿，另一个被公认为这方面专家的人打断了我，让我先停下来，直到我知道自己在说什么。然后他站起来，解释得比我想象的更详细。会后我去了他的办公室和他谈了谈。他解释说，虽然他不知道我来自哪里，但这里的标准是，除非你知道自己在说什么，否则不要说话。

>> 最好的老师对学生和自己的期望更高。而更多的时候，学生们会奋起来满足这些期望。最优秀的领导者对员工期望更高；他们用同样的标准来要求员工，就像要求自己一样——一个比大多数人想象的更高的标准。

>> 与大师直接合作是最好的教育；这是提高标准的最可靠的方法。他们的优秀要求你的优秀。但我们大多数人都没有足够的幸运，有这样的机会。不过，并非一切都失去了。如果你没有机会直接与大师一起工作，你仍然可以通过阅读他们和他们的工作来让自己周围的人有更高的标准。

◆ Chapter 2.7: Exemplars + Practice

>> 当你选择了正确的榜样——那些标准比你高的人——你就能超越你从父母、朋友和熟人那里继承来的标准。你的样本告诉你你的标准应该是什么。正如彼得·考夫曼曾经告诉我的那样，“没有什么技巧比学习和采用别人的好榜样更能使我在生活中取得成功。”

>> 我的榜样之一是查理芒格，他是沃伦巴菲特的亿万富翁商业伙伴。他提高了我坚持意见的标准。天晚上吃饭时，他评论说：“我从不允许自己对任何事情发表意见，除非我比他们更了解对方的论点。”

>> 如果你的英雄是世界历史上最成功的公司之一Shopify的创始人托比·L(Tobi Lütke)，你可以在互联网上找到无数对他的采访。你可以坐在大师的脚下，学习他如何思考，如何决策，如何经营他的公司。彼得·D·考夫曼、沃伦·巴菲特、杰夫·贝佐斯、汤姆·布雷迪、西蒙·拜尔斯、塞雷娜·威廉姆斯或凯蒂·雷德基也是如此。

>> 你可以在历史伟人中选择：理查德·费曼、乔治·华盛顿、查尔斯·戴高乐、温斯顿·丘吉尔、可可·香奈儿、查理·芒格、玛丽·居里、马可·奥勒留。他们都准备好接受您的邀请，成为您的个人董事会。所有你需要做的是收集最好的他们在一起，并在你的脑海中统一他们。如蒙田所说：“我采集了别人的鲜花编成的花环，除了那束花的绳子，没有一样东西是我的。

>> 如果你想象你的榜样看着你，你会倾向于做所有你知道他们想让你做的事情，而避免那些你知道会妨碍你的事情。

◆ Chapter 3.1: Knowing Your Weaknesses

>> 我们的一些弱点是对我们所能知道的东西的限制，我们的盲点。我们都对感知盲点很熟悉--我们无法在一定的距离之外，在没有足够光线的环境中精确地看东西。我们也有失聪的地方；我们听不到低于某一音量或高于某一音高的声音。

>> 我们看不到自己的弱点，主要有三个原因。

>> 首先，我们很难发现这些缺点，因为它们是我们习惯于思考、感觉和行为方式的一部分。有缺陷的行为通过一个长期的习惯形成过程而变得根深蒂固。这些缺点是我们的一部分，即使它不符合我们想成为的人。

>> 其次，看到我们的缺点会伤害我们的自尊心，特别是当这些缺点是根深蒂固的行为时。它们不同于缺点，比如说，缺乏一项技术技能，因为它们感觉像是对我们认为自己是什么样的人的一次公投。我们对自己的看法是有地域性的，并且倾向于忽略那些挑战我们自我形象的信息。

>> 第三，我们的视角有限。很难理解一个我们是其中一部分的系统。就像你回头看十六岁的自己，想知道自己当时在想什么一样，未来的自己回头看现在的自己，也会想同样的事情。你现在的自己对未来的自己视而不见。

◆ Chapter 3.2: Protecting Yourself with Safeguards

>> 举个简单的例子。假设你想开始吃更健康的饮食。如果你居住在一个不健康的环境中，比如说，你的食品储藏室和冰箱里装满了垃圾食品，你会让这个任务变得更加困难。清除你家里所有的垃圾食品是一种安全措施。当你感到饥饿或无聊时，它可以保护你不冲动地撕开一包薯片。当然，你仍然可以去商店买薯条，但这是一个很大的工作。你必须思考、计划和行动。在你做这一切的时候，你可能会更好地思考你的选择，选择吃一些更符合你健康目标的东西。

>> 清除你家里所有的垃圾食品是一个保护策略的例子：增加做一些与你的长期目标相反的事情所需的“摩擦”的数量。不过，有很多安全策略。我最喜欢的方法包括预防，为自己制定规则，列清单，改变你的参照框架，让看不见的东西变得可见。我们来谈谈每种策略。

>> 我们也天生想要融入其他人。想一想你有多少次在你真的只想喝水的时候，却在社交场合喝酒。你的朋友或同事先点了一杯酒，比如说，而你却因为自己没有点一杯酒而感到内疚。所以，你也点了酒，在你真正想要的东西上妥协了。

>> 同样，假设你的目标是少喝苏打水。【*】与其根据具体情况来决定你是否要喝碳酸饮料——这需要很多努力，而且很容易出错——不如制定一个规则。例如，“我只在星期五晚餐时喝汽水”，或者，“我根本不喝汽水”。有一个规则意味着不必在每顿饭都做决定。执行路径很短，并且不容易出错。

>> 心理学上的一个怪癖是，人们通常不会和你的个人规则争论。他们只是接受它们作为你是谁的特征。人们质疑决策，但他们尊重规则。

>> 当你回过头来想一想的时候，我给了我最重要的事情之一，我最想做的就是我自己。电子邮件，我最害怕的日子，得到了我最精力充沛和最具创造性的自我。我们中的许多人也这样做与我们的合作伙伴。当我们在漫长的一天中完成所有需要做的事情时，我们已经筋疲力尽了。而这是我们给我们的配偶，我们生命中最重要的人的时间！

>> 打破坏习惯的途径是让你想要的行为成为默认行为。为了顺利完成报告，我跟同事们说，在报告提交之前，如果他们发现我在上午11点前打开电子邮件，我就请他们吃午饭。我的好胜心和不想给他们买午餐制造了足够的摩擦，让我早上第一件事就是不去查看它。

◆ Part 4: Decisions: Clear Thinking in Action

>> 决定本身应该代表决策过程的结果。这个过程是关于权衡你的选择，目的是选择最好的一个，它由四个阶段组成：定义问题，探索可能的解决方案，评估选项，最后做出判断并执行最好的选项。

◆ Chapter 4.6: Learn from Your Decisions

>> 显然，我们都希望有好的结果，但正如我们所看到的，好的决定可能有坏的结果，坏的决定也可能有好的结果。根据结果评估我们或他人的决策（或我们对结果的感觉）未能区分运气与技巧和控制。正因为如此，致力于结果并不能帮助我们变得更好。结果反而是停滞。

>> 一个糟糕的过程永远不会产生一个好的决定。当然，这可能会导致一个好的结果，但这与做一个好的决定是不同的。结果在一定程度上受到运气的影响，有好的也有坏的。以错误的理由获得正确的结果并不取决于聪明或技能，而只是运气。

>> 透明度原则：让你的决策过程尽可能清晰可见，并接受审查。

>> 保障措施：记录下你做决定时的想法。不要依赖你事后的记忆。试图回忆你在做决定的时候所知道的和所想的是一个傻瓜的游戏。

>> 把你的想法写下来的第三个好处是，它可以让其他人看到你的想法，这主要是看不见的。如果他们能看到它，他们可以检查它的错误，并提供一个不同的观点，否则你可能是盲目的。如果你不能简单地向其他人（或你自己）解释你的想法，这表明你还没有完全理解事物，需要深入挖掘，收集更多的信息。

◆ Chapter 5.1: Dickens’s Hidden Lesson

>> 走开一会儿后，他得出结论，他一直在试图赢得错误的游戏。他的目标是获得财富、权力和名望——许多人告诉我们要追求的目标。他把这些目标放在首位，并坚持不懈地追求它们。最后，他得到了他认为他想要的。但这让他感到空虚。他得到了他想要的东西，但代价是失去了有意义的人际关系，他开始意识到，这才是真正重要的东西。不像史克鲁奇，他没有第二次机会。

>> 我认识很多成功人士，我不想拥有他们的生活。他们有智慧，他们有动力，他们有机会，他们有必要的手段来利用这一切。但他们还遗漏了其他东西。他们知道如何得到他们想要的东西，但他们想要的东西并不值得去想要。事实上，他们想要的东西最终毁了他们的生活。他们忽略了斯克鲁奇在他的故事的幸福转折点上所获得的东西——那是造成不幸福的大众和少数幸福的人之间差异的因素。

◆ Chapter 5.3: Memento Mori

>> 现在深入思考。你想象中的生活是怎么样的？里面的人是谁？你在哪些方面影响了他们？你为他们做了什么？你让他们感觉如何？你有什么成就？你有什么财产？在你生命的最后几天，什么最重要？什么看起来不重要？你珍惜哪些回忆？你后悔的事有哪些？你的朋友怎么说你？你的家人呢？

>> 将我们的视角转换到生命的尽头，可以帮助我们洞察到什么才是真正重要的。它可以帮助我们变得更聪明。当我们透过生命终结的镜头来回顾现在时，占据我们注意力的恐惧和欲望会被推到一边，为对我们的整体生活有更大意义的事情腾出空间。史蒂夫·乔布斯是这样说的：

>> 提醒自己快死了，是我在人生中下重大决定时，所用过最重要的工具。因为几乎每件事--所有外界的期望、所有的骄傲、所有对困窘或失败的恐惧--在面对死亡时，都消失了，只有真正重要的东西才会留下。记住你即将死去是我所知道的最好的方法，以避免认为你有一些东西要失去的陷阱。

>> 乔布斯每天都有一个仪式。每天早晨，他都会对着镜子问自己：“如果今天是我生命中的最后一天，我还会去做我今天要做的事情吗？”[3]他说，每当连续很多天答案都是“不”的时候，他就知道自己需要有所改变了。在我生命中的某个时刻，我开始执行同样的仪式。这也是我最终决定离开情报局的部分原因。我们都有糟糕的日子，但当约伯的问题的答案是没有日复一日，周复一周，是时候做出改变。

>> 当你做这个练习的时候，你可能想到了你的人际关系。也许是你和你的配偶一起在沙发上哭泣，度过一个浪漫的周末，或者手牵着手在沙滩上散步。也许是因为你的婚礼也可能是你和孩子们一起体验纯粹快乐的时光。也许是你陪在朋友身边的时候，或者是他们陪在你身边的时候。

>> 杰夫·贝佐斯用了一个类似的思想实验：

>> 我想让自己活到80岁，然后说，“好吧，现在我在回顾我的人生我想尽量减少我的遗憾。” . . . 我知道，当我80岁的时候，我不会后悔尝试过（亚马逊）。我不会后悔尝试参与这个叫做互联网的东西，我认为这将是一个真正的大交易。我知道如果我失败了，我不会后悔，但我知道我可能会后悔的一件事就是从来没有尝试过。我知道这件事每天都会困扰着我，所以，当我这样想的时候，这是一个非常容易的决定。[4]

>> 财产对它们本身的重要性不如对它们所能带来的重要性。我猜，在思维练习中，你并没有把你的房子当作一种投资。如果它出现在我的脑海中，可能是在关系和记忆的背景下家庭晚餐，欢笑，泪水，聚会，你和你的伴侣在床上呆了一整天的时间，棋盘游戏的战斗，门口记录你的孩子在每个年龄段的身高的标记。

>> 你可能还记得你没有达到你想成为的那个人的时候--我们每个人都有过这样或那样的经历。也许是你发了一封不恰当的电子邮件，或者是你情绪失控对你爱的人大喊大叫。也许是有一次你说了一些无心的话，只是想引起别人的反应，因为你不知道如何，在那一刻，告诉他们你爱他们，或者你有多害怕。又或许是某个人说他们需要你，而你却忙于自己的事情而无暇顾及。

>> 你可能会想到你对你的社区、你的城市、你的国家或世界所产生的影响或缺乏的影响。你可能会想到你的健康。你有没有尽你所能让你的身体活到八十岁、九十岁、一百岁？你有没有照顾好自己才能照顾好别人？

>> 我们所认为的决定性时刻，如升职或买新房子，对生活满意度的影响不如那些当时看起来不重要的微小时刻的积累。最后，每天的时刻比大奖更重要。在明亮的大灯光下，微小的快乐。

◆ Chapter 5.4: Life Lessons from Death

>> 例如，在做了这个思想实验后，我开始吃得更好，睡得更多，并定期锻炼。Why? 因为为了活到九十岁，做我想做的所有事情，我需要健康。同样，在做了这个思想实验之后，很明显，我想成为一个更临在的父亲。因此，我减少了在孩子们身边使用手机的时间，并创造了一些与他们建立联系的惯例：每天当他们回家时，我们坐在沙发上谈论学校的一天。毫无疑问，这些都是很小的改变，但对我和重要的人却有很大的影响。

>> 聪明的人知道什么是真正有价值的。他们比任何人都清楚，生命只有一次没有草稿，没有重来，没有从较早的保存点重新启动。他们不会把时间浪费在追逐无聊的野心上。他们知道真正的财富是由什么组成的，而且他们全身心投入到获取财富的过程中——不管别人怎么想怎么说。

>> 有时候，聪明的代价是别人把你当傻瓜。这也难怪：傻瓜看不见聪明人做的事。明智的人看到生命的所有广度：工作、健康、家庭、朋友、信仰和社区。他们不会只关注一个部分而排斥其他部分。相反，他们知道如何协调生活的各个部分，并按照整体的比例追求每个部分。他们知道，以这种方式实现和谐，才能让生活变得有意义、令人钦佩和美丽。

>> 如果你想培养良好的判断力，首先要问两个问题：“我想要的生活是什么？我想要的东西真的值得我去想要吗？”除非你回答了第二个问题，否则世界上所有的决策建议都不会对你有多大帮助。知道如何得到你想要的东西，如果这些东西不能让你快乐，那就没有什么好处了。无论你在获得权力、名望或金钱方面有多成功如果最后你想重来一次的话。

◆ Conclusion: The Value of Clear Thinking

>> 好的判断力是昂贵的，但糟糕的判断力会使你损失一大笔钱。

>> 这本书最重要的信息是，有一些看不见的本能在密谋反对好的判断。你的默认会鼓励你做出没有理由的反应——无意识地而不是刻意地去生活。

>> 当你恢复到默认值时，你参与了一场你赢不了的游戏。当你过着自动驾驶的生活时，你会得到不好的结果。你把事情弄得更糟。你说的话不能收回，做的事不能收回。你可能完成了眼前的目标，但你没有意识到你已经让实现最终目标变得更难了。所有这些都发生在没有意识到你一开始就在行使判断的情况下。

>> 大多数关于思考的书只关注更加理性。他们忽略了一个最基本的问题：大多数判断错误发生在我们不知道我们应该进行判断的时候。它们之所以会发生，是因为我们的潜意识在驱使我们的行为，并将我们排除在决定我们应该做什么的过程之外。你不是有意识地选择与伴侣争吵，但你发现自己说了一些伤人的话，这些话无法收回。你不会有意识地以家庭为代价去追求金钱和地位，但你发现自己与生命中最重要的人相处的时间越来越少。你不会有意识地为自己的想法辩护，但你发现自己对任何批评你的人都怀恨在心。

>> 从生活中得到你想要的东西的关键是认清这个世界是如何运作的，并使自己与它保持一致。人们常常认为世界应该以不同的方式运行，当他们没有得到他们想要的结果时，他们试图通过责怪他人或他们的环境来逃避责任。[1]逃避责任是造成痛苦的良方，与培养良好判断力所需要的正好相反。

>> 事实证明，提高你的判断力，与其说是积累工具来增强你的理性，不如说是实施保护措施，使所希望的道路成为阻力最小的道路。它是关于在你最好的时候设计系统，在你最坏的时候为你工作。这些系统不会消除默认值，但它们确实可以帮助您识别它们何时运行。

>> 管理你的默认设置需要的不仅仅是意志力。默认是在我们的潜意识层面运作的，所以克服它们需要利用同样强大的力量，将你的潜意识拉向正确的方向：习惯、规则和环境。覆盖默认值需要实现安全措施，使不可见的可见，并防止您过早地采取行动。它需要培养思维责任、知识、纪律和信心的习惯，这些都能让你走上正确的轨道并保持下去。

>> 你在判断上所做的微小改进，直到它们大到无法忽视时，才能被感觉到。渐地，随着改进的积累，你会注意到花在修复那些一开始就不应该存在的问题上的时间越来越少了。你会注意到你生活的各个部分和谐地融合在一起，你会注意到你的压力和焦虑减少了，快乐增加了。

>> 良好的判断力是教不来的，但可以学习。
