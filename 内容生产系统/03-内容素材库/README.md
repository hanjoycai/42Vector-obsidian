# 内容素材库

> [!quote] 核心理念
> 素材库是整个系统的核心。不是每次从零开始，而是站在自己的肩膀上创作。
> 每一次创作都在给素材库添砖加瓦，素材库反过来加速下一次创作——这就是内容的复利效应。

---

## 从「碰运气」到「系统化」

| 维度 | 传统方式 | 系统化方式 |
|------|---------|-----------|
| 开始创作 | 每次从零开始 | AI 先检索素材库，找到可复用内容 |
| 历史内容 | 不知道自己以前写过什么 | 推文库 + 爆款文稿库，随时追溯 |
| 好的表达 | 散落在各个文稿里 | 金句库统一管理，按主题索引 |
| 理论框架 | 每次重新组织 | 核心概念库，一个概念撑十篇内容 |
| 创作效率 | 靠灵感和记忆 | 结构化检索 + AI 建议复用 |

## AI 检索工作流

> [!tip] 当你对 AI 说「深化选题」或「找素材」时，AI 会自动执行以下检索流程

```
用户说：深化选题「如何用兴趣赚钱」
         │
         ▼
┌─────────────────────────────────────────────────┐
│  Step 1：检索核心概念库                            │
│  → 找到 核心概念库/生产型兴趣.md                    │
│  → 「你之前定义过'生产型兴趣'这个概念，建议复用」     │
├─────────────────────────────────────────────────┤
│  Step 2：检索爆款文稿库                            │
│  → 找到 爆款文稿库/02-如何用兴趣赚钱并实现规模增长.md │
│  → 「你写过类似内容，数据表现 Top 5%，建议参考结构」  │
├─────────────────────────────────────────────────┤
│  Step 3：检索推文库 & 100条思考                     │
│  → 找到 3 条相关推文                               │
│  → 「这些历史推文中有可复用的观点和表达」             │
├─────────────────────────────────────────────────┤
│  Step 4：检索金句库 & 案例库                        │
│  → 找到 2 条金句 + 1 个案例                        │
│  → 「建议在文稿中使用这些素材」                      │
├─────────────────────────────────────────────────┤
│  Step 5：汇总建议                                  │
│  → 列出所有可复用的素材                             │
│  → 给出复用建议：直接用 / 需改编 / 仅参考            │
│  → 生成初稿到 待深化的选题/                         │
└─────────────────────────────────────────────────┘
```

## 素材入库流程

> [!abstract] 每次创作和复盘后，都应该检查是否有素材值得入库

```
创作/复盘完成
    │
    ├── 有新概念？ → 入库 核心概念库/
    ├── 有好表达？ → 入库 金句库/
    ├── 有真实案例？ → 入库 案例库/
    ├── 内容数据 Top 10%？ → 入库 爆款文稿库/
    └── 有值得提炼的思考？ → 入库 100条思考系列/
```

## 检索优先级

AI 在检索素材时，按以下优先级排列结果：

1. **核心概念库** — 最优先，概念是内容的骨架
2. **爆款文稿库** — 已验证的结构和框架
3. **100条思考系列** — 精炼的观点和思考
4. **金句库** — 增强表达力的素材
5. **案例库** — 增强说服力的素材
6. **推文库** — 原始素材，需要二次加工

> [!important] 复用原则
> 复用不是照搬。每次复用都应该在原有基础上**升级**——更好的表达、更新的案例、更深的洞察。
> 素材库的价值不在于存了多少，而在于**用了多少**、**用得多好**。
