## 使用说明

1. **创作找灵感** → 按主题浏览，找到与当前选题相关的思考
2. **选题验证** → 一条思考如果能展开成 1000+ 字，说明是个好选题
3. **金句复用** → 精炼的表达可直接用于文稿开头、结尾或核心论点
4. **持续更新** → 随着推文库积累，定期从新推文中提炼新的思考
5. **标记热门** → 被复用 3 次以上的思考标记为「王牌思考」
