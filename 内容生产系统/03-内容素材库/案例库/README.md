# 案例库

> [!info] 说明
> 存放真实案例，包括成功经验和失败教训。
> 案例是内容创作中最有说服力的素材——数据让人信服，故事让人共鸣。

---

## 分类体系

- [[#个人经历]]：自己亲身经历的事件
- [[#用户故事]]：粉丝、客户、学员的真实故事
- [[#行业案例]]：行业内值得参考的成功/失败案例
- [[#数据案例]]：用数据说话的案例（AB 测试、增长数据等）

---

## 模板格式

每个案例按以下结构记录：

```markdown
---
title: 案例标题
category: 个人经历 / 用户故事 / 行业案例 / 数据案例
date: YYYY-MM-DD
result: 成功 / 失败 / 进行中
tags:
  - 案例
---
```

## 使用说明

1. 遇到好案例 → 立即记录核心信息，后续补充细节
2. 按四个维度（背景、过程、结果、启发）结构化整理
3. 创作时 → 按分类或关键词查找合适的案例
4. 使用后 → 记录引用效果，高频案例标记为「王牌案例」
