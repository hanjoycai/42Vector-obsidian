# 爆款文稿库

> [!info] 说明
> 存放经过数据验证的爆款内容结构。不是收藏爆款，而是拆解爆款背后的「结构密码」。
> 每一篇爆款都是一次验证，拆解得越细，复制成功的概率越高。

---

## 入库标准

- **数据 Top 10% 的内容**：自己或竞品的高数据内容
- **可归因的成功要素**：能拆解出具体原因，而不是「运气好」
- **可复制的结构**：拆解后能指导下一次创作

---

## 拆解维度

每篇爆款文稿从以下 5 个维度拆解：

1. **标题结构**：用了什么公式？为什么吸引点击？
2. **开头方式**：前 3-5 秒 / 前 2 行做了什么？
3. **论证框架**：整体结构是什么？（总分总 / 递进 / 并列 / 故事线）
4. **金句表达**：有哪些值得提炼的高质量表达？
5. **结尾方式**：如何收尾？是否有效引导互动？
