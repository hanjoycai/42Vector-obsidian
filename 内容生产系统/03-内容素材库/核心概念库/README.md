# 核心概念库

> [!info] 说明
> 存放经过深度消化、可在内容中反复复用的理论框架和思维模型。
> 好的概念是内容的「弹药」，一个好概念可以撑起十篇内容。

---

## 入库标准

- **自己深度消化的概念**：不是看到就收藏，而是能用自己的话讲清楚
- **被复用超过 2 次的框架**：实践验证过有效，值得沉淀
- **有明确应用场景**：知道在什么内容中可以用

---

## 模板格式

| 概念名 | 一句话定义 | 应用场景 | 使用次数 |
| ------ | ---------- | -------- | -------- |
| 概念A  | 简洁定义   | 场景描述 | 0        |

每个概念建议单独创建一个笔记，包含：
1. **一句话定义**：用最简洁的语言说清楚
2. **详细解释**：用自己的话展开
3. **应用场景**：在什么类型的内容中可以使用
4. **使用记录**：每次用到时记录，追踪复用率

## 概念索引

| 概念名 | 一句话定义 | 应用场景 | 使用次数 |
| ------ | ---------- | -------- | -------- |
| 生产型兴趣 | 能产出可交付成果的兴趣，区别于纯消费型兴趣 | 讲个人成长、兴趣变现、副业选择 | 3 |
| 内容复利 | 一次创作、多次分发、持续获得回报的内容策略 | 讲内容创作效率、系统化运营 | 2 |
| 最小可行内容（MVC） | 用最低成本验证内容方向是否可行的最小单元 | 讲起步策略、降低启动门槛 | 2 |

---

## 使用说明

1. 遇到好概念 → 先放入 [[01-内容生产]] 的灵感捕捉中
2. 消化理解后 → 整理成标准格式存入本库
3. 创作时 → 来这里找「弹药」
4. 每次使用后 → 更新使用次数，记录效果
