**方式 A：按时间分片**（推荐）

```

```

## AI 检索说明

> [!abstract] AI 如何使用推文库

当用户触发「深化选题」或「找素材」时，AI 会：

1. 根据选题关键词，在推文库全文检索
2. 找到相关推文后，摘取核心表达
3. 判断是否可直接复用，或需要改编升级
4. 在建议中标注来源：`来自推文库 #编号`

> [!warning] 注意事项
> - 推文是原始素材，直接复用前需要评估是否需要升级表达
> - 推文的互动数据可以作为「用户验证」的参考——高互动推文的观点更值得展开
> - 避免大段照搬推文，应将其作为创作的「种子」而非「成品」
