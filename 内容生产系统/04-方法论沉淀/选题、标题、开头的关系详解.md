# 选题、标题、开头的关系详解

> [!info] 核心认知
> 选题、标题、开头不是三个独立的环节，而是一条逻辑链。
> 选题决定了「你要说什么」，标题决定了「用户是否点开」，开头决定了「用户是否留下」。
> 三者必须协同设计，才能最大化内容的流量表现。

---

## 三者的逻辑关系

```
选题 ──────────► 标题 ──────────► 开头
 │                │                │
 │ 决定内容方向    │ 决定点击率     │ 决定留存率
 │ 决定受众群体    │ 决定流量入口    │ 决定完播/读完率
 │                │                │
 └──── 一致性 ────┴──── 一致性 ────┘
        ▲                          │
        │                          │
        └────── 数据反馈 ───────────┘
```

### 核心原则：三者必须一致

- **选题**承诺了价值方向
- **标题**是这个承诺的「广告语」
- **开头**是这个承诺的「首付款」

> [!warning] 常见错误
> 选题很好，但标题没有传达出选题的价值 → 点击率低
> 标题很吸引人，但开头没有兑现标题的承诺 → 跳出率高
> 开头很精彩，但选题本身没有需求 → 总流量上限低

## 三者的协同设计流程

### 正确的设计顺序

```
Step 1：确定选题
  │  问自己：这个选题的核心价值是什么？目标用户是谁？
  │
  ▼
Step 2：从选题推导标题
  │  问自己：如何用一句话让目标用户觉得「这和我有关」？
  │  参考 [[标题方法论]] + [[dontbesilent小红书标题方法论]]
  │
  ▼
Step 3：从标题推导开头
  │  问自己：标题承诺了什么？开头前 5 秒如何兑现这个承诺？
  │  参考 [[开头方法论]]
  │
  ▼
Step 4：一致性检查
     标题和开头是否在说同一件事？
     开头是否让用户觉得「点对了」？
```

### 错误的设计顺序

- ❌ 先写完内容 → 再想标题 → 开头随意（标题和内容脱节）
- ❌ 先想一个吸引人的标题 → 再找选题（标题党）
- ❌ 选题、标题、开头分别独立思考（三者不协同）

## 不同选题类型的标题 × 开头最佳搭配

| 选题类型 | 推荐标题公式 | 推荐开头方式 | 示例 |
|----------|-------------|-------------|------|
| 痛点型 | 痛点 + 解决方案 | 痛点共鸣型开头 | 选题「拖延症」→ 标题「总是拖延？不是懒，是方法错了」→ 开头「你有没有过这种感觉……」 |
| 方法论型 | 数字 + 关键词 | 利益前置型开头 | 选题「阅读方法」→ 标题「3 个让阅读效率翻倍的方法」→ 开头「看完这篇，你会掌握……」 |
| 反常识型 | 反常识/颠覆 | 反常识型开头 | 选题「努力陷阱」→ 标题「努力其实在害你」→ 开头「90% 的人都搞反了一件事……」 |
| 故事型 | 对比/转折 | 故事开场型开头 | 选题「转型经历」→ 标题「从月入 3000 到月入 3 万」→ 开头「去年这个时候，我还在……」 |
| 热点型 | 时效热点 + 专业解读 | 数据/事实震撼型开头 | 选题「AI 浪潮」→ 标题「XXX 之后，这个行业要变天了」→ 开头「一个数据可能会让你震惊……」 |

## 优化检查清单

> [!tip] 发布前的终极检查

### 一致性检查

- [ ] 标题是否准确传达了选题的核心价值？
- [ ] 开头是否在 5 秒内兑现了标题的承诺？
- [ ] 三者是否在说同一件事？（没有「文不对题」）

### 协同优化检查

- [ ] 选题类型和标题公式是否匹配？（参考上方搭配表）
- [ ] 标题公式和开头方式是否匹配？
- [ ] 平台规则是否满足？（字数、关键词、风格）
