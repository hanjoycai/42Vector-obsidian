# 标题方法论

> [!info] 核心理念
> 标题是内容的「门面」，决定了用户是否愿意点开。不同平台有不同的标题逻辑，但底层都是在 1 秒内回答用户一个问题：「这和我有什么关系？」
> 本文件用于持续沉淀从数据复盘中验证有效的标题公式。

---

## 通用标题公式

### 公式 1：数字 + 关键词

- 格式：`[数字] 个 [关键词] 的 [结果/方法]`
- 示例：「3 个让阅读效率翻倍的方法」
- 原理：数字降低认知成本，用户知道内容量级

### 公式 2：痛点 + 解决方案

- 格式：`[痛点描述]？[解决方案暗示]`
- 示例：「总是坚持不下去？试试这个方法」
- 原理：先共鸣后给希望，用户有动力点开

### 公式 3：反常识/颠覆

- 格式：`你以为的 [常识]，其实 [反转]`
- 示例：「你以为早起就是自律？其实你搞反了」
- 原理：认知冲突引发好奇心

### 公式 4：身份标签

- 格式：`[身份标签] 必看 / 必读 / 才懂`
- 示例：「内容创作者必看｜这个工具能帮你省 80% 时间」
- 原理：精准锁定目标人群，提升点击相关性

### 公式 5：对比/转折

- 格式：`[之前状态] → [之后状态]`
- 示例：「从月入 3000 到月入 3 万，我只做了一件事」
- 原理：反差制造吸引力，用户想知道怎么做到的

## 各平台标题差异

### 小红书标题

| 要素 | 规则 |
|------|------|
| 字数 | 18-25 字 |
| 关键词 | 搜索关键词前置，便于搜索收录 |
| Emoji | 适度使用，增加视觉吸引力 |
| 风格 | 口语化、亲切感，像朋友推荐 |
| 示例 | 「💡自学 3 个月，我总结了这 5 个最有用的方法」 |

### 抖音标题

| 要素 | 规则 |
|------|------|
| 字数 | 10-20 字（简短有力） |
| 钩子 | 前半句制造悬念或冲突 |
| 风格 | 口语化、有情绪张力 |
| 注意 | 标题是辅助，前 5 秒画面才是关键 |
| 示例 | 「千万别这样做，90% 的人都踩过这个坑」 |

### 公众号标题

| 要素 | 规则 |
|------|------|
| 字数 | 15-30 字 |
| 核心信息 | 放在前 15 字（折叠后可见） |
| 风格 | 可以更深度、更正式 |
| 打开率 | 标题是唯一的打开驱动力 |
| 示例 | 「我研究了 100 篇爆款文章，发现了一个被忽略的规律」 |

## 标题优化检查清单

> [!abstract] 写完标题后，用这个清单逐项检查

- [ ] **一秒理解**：用户能否在 1 秒内理解标题在说什么？
- [ ] **与我有关**：目标用户是否觉得「这和我有关」？
- [ ] **好奇缺口**：标题是否制造了信息缺口，让人想点开看？
- [ ] **关键词**：是否包含了平台搜索关键词？
- [ ] **不是标题党**：内容能否兑现标题的承诺？
- [ ] **字数达标**：是否符合目标平台的字数要求？
