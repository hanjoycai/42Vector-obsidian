# 内容生产系统 - 使用手册

> [!quote] 从这里开始
> 这是你的内容生产系统入口。无论你是第一次使用，还是需要快速回顾流程，都可以从这里出发。

---

## 核心理念

大多数创作者的工作方式是**碎片化**的——灵感来了就写，写完就发，发完就忘。好的内容被浪费，踩过的坑反复踩，爆款无法复现。

这套系统的目标是将你的创作从「碎片化」升级到「系统化」：

- **每一个想法**都有去处，不会丢失
- **每一次创作**都能调用历史素材，站在自己的肩膀上
- **每一次发布**都产生数据，数据反哺方法论
- **每一条方法论**都能指导下一次创作

## 快速开始指南

> [!tip] 3 步上手，立刻开始使用

### 第 1 步：记录想法

当你有任何灵感、选题想法时，告诉 AI：

```
记录选题：关于 [你的想法]
```

AI 会自动将选题追加到 [[00-选题记录]]，包含时间戳和初步分析。

### 第 2 步：深化选题

当你决定深入某个选题时，告诉 AI：

```
深化选题：[选题名称]
```

AI 会自动检索素材库、查找历史内容、建议可复用的框架，并生成初稿到待深化目录。

### 第 3 步：发布复盘

内容发布后，告诉 AI：

```
已发布：[内容标题]，平台：[平台名]
```

AI 会自动归档文稿、提醒你记录数据、并检查是否有素材值得入库。

## AI 快捷命令速查表

> [!info] 以下命令可以直接对 AI 说，AI 会自动执行对应流程

| 命令 | 触发词示例 | 功能说明 |
|------|-----------|---------|
| 记录选题 | `记录选题`、`我有个想法` | 将选题追加到 [[00-选题记录]]，自动添加时间戳 |
| 深化选题 | `深化选题`、`展开这个` | 检索素材库与已发布内容，生成文稿初稿 |
| 生成标题 | `生成标题` | 基于标题方法论 + 平台规则，生成 3-5 个标题选项 |
| 优化开头 | `优化开头` | 基于开头方法论，优化内容前 5 秒的吸引力 |
| 找素材 | `找素材`、`有没有相关的` | 搜索素材库和已发布内容，找到可复用的内容 |
| 数据复盘 | `记录数据`、`数据复盘` | 更新数据统计表，分析表现，检查方法论是否需要迭代 |
| 发布归档 | `已发布`、`归档` | 移动文稿到已发布目录，按月归档，提醒后续动作 |

## 系统价值对比

| 维度 | 碎片化创作 | 系统化创作 |
|------|-----------|-----------|
| 灵感管理 | 想到就忘，灵感流失 | 统一记录，随时回溯 |
| 素材使用 | 每次从零搜索 | 分类入库，一键检索复用 |
| 创作效率 | 每篇重新构思框架 | 复用已验证的框架和方法论 |
| 标题质量 | 凭感觉拍脑袋 | 基于数据验证的标题公式 |
| 开头吸引力 | 随意起笔 | 方法论指导，优化前 5 秒 |
| 发布后动作 | 发完就忘 | 归档 → 数据记录 → 素材入库 → 方法论迭代 |
| 数据利用 | 偶尔看一眼后台 | 结构化记录，定期复盘，驱动决策 |
| 方法论积累 | 全靠记忆和直觉 | 持续沉淀，可传承可迭代 |
| 长期价值 | 内容即用即弃 | 内容资产持续增值，形成飞轮效应 |
