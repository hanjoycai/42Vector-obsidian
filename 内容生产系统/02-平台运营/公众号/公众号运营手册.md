# 公众号运营手册

> [!info] 定位
> 微信公众号是「私域 + 深度内容」平台。核心逻辑：用标题驱动打开率，用深度长文建立信任和专业度。

---

## 平台特征

- **用户画像**：私域读者为主，粘性高，对深度内容接受度强
- **内容形式**：长文为主（1500-5000 字），图文结合
- **分发逻辑**：订阅推送 + 社交分享 + 搜一搜
- **核心指标**：打开率（标题）、读完率（内容质量）、分享率（社交价值）

---

## 打开率优化（标题决定一切）

> [!warning] 关键认知
> 公众号用户在订阅列表中只能看到标题。标题不够吸引 = 内容再好也没人看。

### 标题公式

1. **利益承诺**：「学会这 3 招，XX 效率提升 200%」
2. **好奇心缺口**：「我研究了 100 篇爆款文章，发现了一个规律」
3. **身份标签**：「给 XX 人的一封信」「XX 从业者必读」
4. **时效热点**：结合热点事件 + 你的专业解读
5. **颠覆认知**：「你以为的 XX，其实完全错了」

### 标题规则

- 字数控制在 **15-30 字**（过长会被截断）
- 核心信息放在前 15 个字（折叠后仍可见）
- 避免纯标题党，公众号读者对标题党容忍度低
- 定期 A/B 测试不同标题风格的打开率差异

---

## 深度长文写作策略

### 文章结构

```
[标题] 抓注意力
[开头 100 字] 建立共鸣 / 抛出问题（决定读完率）
[正文主体] 层层递进，每段有核心观点
[金句/案例] 穿插在正文中，增加传播点
[结尾] 升华观点 + 引导行动（关注/分享/留言）
```

### 提升读完率的技巧

| 技巧 | 说明 |
|------|------|
| 短段落 | 每段不超过 3-4 行，降低阅读压力 |
| 小标题 | 每 300-500 字设置一个小标题，方便快速浏览 |
| 加粗重点 | 关键句子加粗，让扫读用户也能获取核心信息 |
| 穿插金句 | 每 500 字左右穿插一句值得截图的金句 |
| 案例故事 | 用真实案例增加可信度和代入感 |
| 视觉节奏 | 图文交替，避免大段纯文字 |

## 发布策略

### 最佳发布时间

- **知识干货类**：早 7:00-8:00（早起学习）、晚 20:00-22:00（深度阅读）
- **观点评论类**：中午 12:00-13:00（午间碎片）、晚 21:00-22:00
- **周末**：上午 9:00-10:00、晚 20:00-22:00

### 发布频率

- 建议每周 **1-3 篇**，质量远重于数量
- 保持固定的发布节奏（如每周二、四），培养读者预期
- 重要内容选择在打开率最高的时段发布

### 摘要与封面

- 摘要（description）是标题的补充，用来激发好奇心或补充关键信息
- 封面图清晰、与内容相关，尺寸比例 2.35:1

---

## 涨粉与留存

### 内容引流

- 每篇文章末尾设置**关注引导**（但不要生硬）
- 系列内容互相链接，形成内容矩阵
- 高质量内容通过其他平台（小红书、抖音）引流到公众号

### 读者运营

- 定期在评论区互动，精选优质留言
- 偶尔发起读者调研，了解内容偏好
- 通过「合集」功能整理系列内容，降低新读者获取成本

## 数据关注重点

| 指标 | 关注点 |
|------|--------|
| 打开率 | 标题吸引力（核心指标） |
| 读完率 | 内容质量和排版节奏 |
| 分享率 | 内容的社交传播价值 |
| 新增关注 | 内容的引流转化能力 |
| 取消关注 | 内容是否偏离读者预期 |
