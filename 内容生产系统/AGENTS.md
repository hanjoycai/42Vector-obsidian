# AGENTS.md — 每次启动必读清单

> [!important] 在处理任何内容生产任务之前，必须先完成以下启动序列。
> 这是会话初始化协议，不可跳过。

---

## Every Session — 启动序列

**依次读取以下文件（顺序不可乱）**：

1. **Read `内容生产系统/SOUL.md`** — 这是你的行为边界，最高优先级安全红线
2. **Read `内容生产系统/USER.md`** — 这是你服务的创作者，了解蔡少的风格偏好
3. **Read `内容生产系统/SOP_GZH.md`** — 这是公众号内容生产的核心工作流，灵活遵守
4. **Read `内容生产系统/CLAUDE.md`** — 这是完整的 AI 自动化触发词与执行步骤定义

---

## 任务路由表

读取完启动清单后，根据用户的触发词判断对应任务：

| 用户触发词 | 任务类型 | 执行依据 |
|-----------|---------|---------|
| `记录选题` / `我有个想法` | 记录选题到选题收集箱 | CLAUDE.md → 流程 1 |
| `深化选题` / `展开这个` | 检索素材库 + 生成初稿 | CLAUDE.md → 流程 2 |
| `生成标题` | 基于方法论生成标题选项 | CLAUDE.md → 流程 3 |
| `优化开头` | 优化前 5 秒 / 前 100 字 | CLAUDE.md → 流程 4 |
| `找素材` / `有没有相关的` | 检索素材库 | CLAUDE.md → 流程 5 |
| `记录数据` / `数据复盘` | 更新数据 + 分析 | CLAUDE.md → 流程 6 |
| `已发布` / `归档` | 移动文稿 + 检查素材入库 | CLAUDE.md → 流程 7 |
| `写文章` / `写稿` / `写公众号` | 从选题到成稿的完整流程 | SOP_GZH.md 5 步法 |

## 核心工作原则（每次任务前默念）

> 1. **先检索再创作** — 打开素材库先搜，别急着写
> 2. **保持蔡少的风格** — 短句、换行、真诚、极客感，禁用 AI 词汇
> 3. **素材必须有出处** — 引用时加 `[[wikilink]]` 标注来源
> 4. **不编造数据** — 素材库没有就说没有，不要捏造
> 5. **平台适配** — 公众号、小红书、抖音的格式和节奏不同，自动调整
