# 选题研究

> [!info] 定位
> 这不是凭感觉选题，而是凭数据。通过对标分析、流量对比、规律挖掘，找到「什么样的选题更容易爆」。
> 选题研究的成果最终反哺到 [[选题方法论]]，形成可执行的选题决策框架。

## 研究方法论

```
选题研究闭环：

  ① 收集数据
     │  自己的内容数据（来自 Dontbesilent 数据统计表.xlsx）
     │  对标账号的内容数据（Dan Koe 等）
     ▼
  ② 分类标注
     │  按选题类型、标题结构、内容形式分类
     │  标注流量数据（播放量、互动率等）
     ▼
  ③ 对比分析
     │  流量好的选题有什么共性？
     │  流量差的选题有什么共性？
     │  对标账号的高流量选题 vs 我的选题有什么差异？
     ▼
  ④ 提炼规律
     │  将数据分析转化为可执行的选题假设
     ▼
  ⑤ 验证迭代
     │  在下一批内容中刻意应用假设
     │  观察数据变化，验证或否定
     ▼
  ⑥ 沉淀方法论
     └──→ 写入 [[选题方法论]]
```
