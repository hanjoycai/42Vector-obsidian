## 数据记录频率建议

### 每条内容发布后（当天/次日）
- 记录基础数据：播放量、点赞、评论、收藏、转发
- 标注内容类型、平台、发布时间
- 初步判断内容表现（超预期 / 符合预期 / 低于预期）

### 每周汇总（周末）
- 汇总本周发布内容的整体数据
- 对比上周同期表现
- 找出本周最佳内容，分析原因
- 更新各平台粉丝数

### 每月深度分析（月初）
- 完成月度数据总览表
- 按维度交叉分析（平台 × 选题 × 时间）
- 提炼关键发现，写入洞察区
- 根据数据调整下月内容策略

## 数据如何反哺方法论

```
数据记录 → 发现规律 → 提炼假设 → 验证测试 → 沉淀方法论
```

**具体流程：**

1. **记录** — 在[[内容数据看板]]中如实记录每条内容数据
2. **发现** — 每月分析时找出高表现内容的共性特征
3. **假设** — 将共性特征转化为可执行的方法论假设
   - 例：「带数字的标题播放量平均高 40%」
4. **验证** — 在下个月的内容中刻意应用该假设，观察数据变化
5. **沉淀** — 验证有效的假设，写入 [[内容生产系统/04-方法论沉淀/README|方法论沉淀]] 模块

> [!important] 数据驱动的关键
> 不要只看单条数据，要看**趋势**。
> 不要只看结果数据，要追溯**过程变量**。
> 不要只记录数据，要产出**可执行的洞察**。
