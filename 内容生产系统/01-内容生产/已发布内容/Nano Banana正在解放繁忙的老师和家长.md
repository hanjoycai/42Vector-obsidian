**完整提示词：**

```perl
构建一款具备以下能力的 AI 语文易错词：易错词库-错别字、汉字学习、拼音练习、语文学习好帮手用户进入后，先选择自己的年级（初一、初二、初三）。默认用户可以输入任意文字，包括单词、短语或整句。结果页将展示：• 用语文写出的自然语言解释•两个例句，并分别附上对应的详细注释•一段轻松、有趣、像朋友聊天一样的用法说明，内容涵盖文化语境、使用场景、 语气、相关词（同义词或外形相似但常被混淆的词）及它们的差别。必须避免教科书式表达，直接进入主题、语言要非常简洁。•一张由 AI生成、能直观呈现该概念的图片•注意错误写法和正确写法的标记界面：红色文字改为用红色框框表示，绿色文字用绿色框框表示。•搜索框为白色背景•错题详情页，支持例如成语的易错字，只需要标记单个错别字即可，或者标记单个容易拼音错误的字•解释可以通过中文官方百科数据，完善解释的文案
支持游戏填词模式，对于成语或者词语组合卡片，默认会缺一个到两个文字，支持输入文字，如果正确就会显示鼓励过关的祝贺 pop效果，错误就会显示正确的文字应该是什么。
同时提供一个聊天功能，用户可以随时就这个易错词提出问题，AI会在对话中继续解释。每个语文易错词或成语都配有目标语言的发音按钮；所有例句也需要具备朗读功能。读音要自然、没有延迟。用户可以将任意结果页保存到“笔记本“，方便日后复习。在笔记本中，还提供一个“编故事”功能：AI会把笔记本里的单词或短语串联成一个小故事，帮助记忆。另有一个“学习模式“：AI会根据笔记本词汇自动生成闪卡。闪卡正面展示易错词及对应概念图；背面展示该词的定义与例句。点击卡片可触发翻面动画。整体风格应明亮、有趣、有活力，视觉上吸睛，并以移动端体验为优先。支持听写模式：家长用户可以上传自己小孩的常见错题库，Excel 文件格式，上传后有一个听写模式按钮，点击启动后，AI 语文老师会随机选取 10 个易错词，然后用语音播放，家长可以设置听写的时间间隔，支持暂停按钮、下一个、上一个按钮切换。注意：易错词详情页的交互设计参考附件中的三个图片，红色标记出易错字，绿色标记出争取的字，不限文字和拼音的错误。
```

**提示词：**

```js
核心配置 (Configuration)[SCENE_THEME] = {在此处填入场景，例如：海底世界 / 消防局 / 超市 / 恐龙公园}[TARGET_AGE] = 5-9 岁 (识字敏感期)绘图提示词 (Prompt Structure)一张儿童识字小报《[SCENE_THEME]》，竖版 A4，学习小报版式，整体加入柔和 3D 立体质感与适度景深，让画面更具沉浸性与空间层次。一、小报标题区（顶部）大标题：顶部居中展示标题：《[SCENE_THEME] 识字小报》。字体风格：大字、醒目、卡通手写体、彩色描边。附加要求：标题文字呈现轻微 3D 浮雕质感，边缘有柔和光影，让标题在页面顶部更突出。装饰元素：在标题周围添加与 [SCENE_THEME] 强相关的贴纸风装饰，颜色鲜艳。附加要求：装饰元素带轻微体积感，视觉上更像“贴在纸上的立体贴纸”。二、小报主体（中间主画面）画面中心是一幅卡通插画风的完整「[SCENE_THEME]」场景，整体构图采用接近 2.5D–3D 效果的绘本风格。整体气氛明亮、温暖、积极、色彩高饱和，同时加入柔光、景深、体积感，让画面具有空间深度与沉浸感。构图要求物体边界清晰，彼此之间留有贴标签的空白，避免拥挤。附加要求：前景—中景—后景分层明显，使标注对象更清晰，场景更立体。场景分区核心区 A (活动)：表现 [SCENE_THEME] 里的核心活动（孩子们或角色正在做什么），动作自然，带轻微 3D 立体造型感。核心区 B (工具)：展示场景特有物品或工具，物体具备简单的 3D 形体光影（非写实，而是绘本级别的立体感）。核心区 C (环境)：体现环境特征（建筑、植被、路标等），背景采用更低对比度与轻微景深，突出前景主体。引导角色1 位可爱的卡通人物（[SCENE_THEME] 的向导/工作人员），带轻微立体与阴影，使其具有温和的空间存在感，正在做欢迎或指引手势。三、必画物体与识字清单 (Generated Content)请务必在画面中清晰绘制以下物体，所有物体采用 清晰轮廓 + 色块分明 + 轻度 3D 塑形：核心角色/设施 (Big Objects):{在此填入 4-5 个核心大物体，如：消防车、云梯、消防员}常见物品/工具 (Small Items):{在此填入 5-8 个具体小物品，如：水枪、灭火器、头盔、手套}环境/装饰 (Environment):{在此填入 3-5 个环境词，如：警报铃、消防栓、大门}四、识字标注规则 (Labeling System)对上述物体贴上中文识字标签：格式：三行制 ① 拼音（带声调） ② 简体汉字 ③ 英文样式：彩色贴纸风（带轻微立体投影，让标签有“纸片贴上去”的空间感）。位置：紧靠对应物体，以引线连接，不遮挡主体。五、画风参数 (Style Parameters)风格：Children's picture book style + Literacy tabloid aesthetic（儿童绘本风 + 识字小报风）附加风格要求：Soft 3D shading, gentle depth-of-field, subtle volumetric lighting（柔和 3D、适度景深、轻体积光）色彩：High Saturation, Warm Tone, Bright（高饱和、暖色、明亮）质量：8k resolution, high detail, clean vector-like lines整体技术特征：flat + soft 3D hybrid illustration（平面插画结合轻 3D 塑形）
```

## 老师的PPT配图以后有救了

从小学老师到大学老师，但凡做过课件都知道，想找一张“精准、高清、带公式”的示意图有多难。

现在用Nana Banana 跑出来的这些教学图，只要来回调整几轮基本可以满足教学使用。当然老师们还是需要做好公式是否清晰且正确，示意图是符合物理定律的，标注也是准确的。 只要Prompt足够清晰： 意味着可以批量生产高质量、无版权风险、中英双语的高质量素材。

  

![图片](https://mmbiz.qpic.cn/mmbiz_gif/y8swr5Nkbyvc6C1xqsStZQd618shQtGG9Kp1TTHCNsBs8HTHqjyALWiaWEylAiaFPuEsovDL7n7iajFFmjibsHParw/640?wx_fmt=gif&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=13)

  

谷歌新推出的【Gemini互动图片】通过视觉和交互方式，来辅助学习者理解复杂的概念比如说，当你在学习消化系统或细胞的各个部分时，有一张可交互的图片，随手点一下，它会弹出详细解释，还能继续追问。

通过视觉和交互，学习者能更直观掌握复杂概念间的关系和运作方式，加深理解；老师也可以作为教学材料使用
